# 如何新增翻译器 / OCR / 文本检测 / 修复模块

> 本指南介绍如何为 BallonsTranslator-lite 添加新模块。
> 模块系统采用**文件自动注册**模式：创建符合命名规则的文件，用装饰器标记类，即可自动发现。

## 1. 架构概览

所有模块位于 `modules/` 下：

```
modules/
├── translators/    →  trans_*.py    (@register_translator)
├── ocr/            →  ocr_*.py      (@register_OCR)
├── textdetector/   →  detector_*.py (@register_textdetector)
└── inpaint/        →  inpaint_*.py  (@register_inpainter)

modules/base.py     →  init_module_registries()，按上述文件名模式自动扫描注册
```

新增模块只需在对应目录下创建 `.py` 文件，无需编辑 `__init__.py`。

## 2. 新增翻译器

### 2.1 文件位置

创建 `modules/translators/trans_myengine.py`。

### 2.2 基础模板

```python
from modules.translators.base import BaseTranslator, register_translator
from typing import List, Dict

@register_translator('MyEngine')
class MyEngineTranslator(BaseTranslator):

    concate_text = True

    params: Dict = {
        'api_key': '',
        'device': {
            'type': 'selector',
            'options': ['cpu', 'cuda'],
            'value': 'cpu'
        }
    }

    def _setup_translator(self):
        self.lang_map['日本語'] = 'ja'
        self.lang_map['English'] = 'en'

    def _translate(self, src_list: List[str]) -> List[str]:
        # 在这里执行翻译
        return src_list
```

### 2.3 关键说明

- `@register_translator('名称')` — UI 上显示的名称
- `params` 字典 — 定义设置面板上的字段（完整控件类型参考见 [config_reference.md](config_reference.md)）
- `concate_text = True` — 文本拼接后传给 `_translate()`（减少 API 调用）；离线模型设为 `False`
- `_setup_translator()` — 初始化 API 客户端、加载模型、填充 `self.lang_map`
- `_translate()` — 接收源文本列表，返回翻译后文本列表
- `updateParam()` — 可选，实时响应参数变更（如切换 device）

```python
        'inpaint_size': {
            'type': 'selector',
            'options': [1024, 2048],
            'value': 2048
        },
        'device': ...
    }

    def _inpaint(self, img, mask, textblock_list=None):
        # 返回修复后的图片
        pass
```

## 6. 多语言注意事项

- 模块 `params` 中的 `"description"` 字段必须写**英文**
- 翻译由设置面板的 `ParamWidget` 统一处理
- 新条目的翻译加到 `translate/zh_CN.ts` 的 `<name>ParamWidget</name>` 上下文中
- 模块内部有 QDialog 子类时，用标准 `self.tr()` 包裹 UI 文本
