# 译文软换行整理 — 设计文档

> 日期：2026-06-25
> 状态：草案（待用户审阅）

## 1. 背景与动机

BallonsTranslator-lite 是减法导向的漫画翻译工具。用户的典型半自动流程是：

跑一遍自动检测 + OCR → 逐个检查 OCR 内容与文本框合规性 → 翻译（软件内或导出原文外部翻译后导入译文）→ 校对、排版、微调字体样式。

**痛点**：LLM 翻译时会"被动模仿"原文换行——默认翻译 prompt 并未要求保留换行（全项目仅 `trans_sakura.py:427` 的 GALTRANSL 模板含"不要擅自增加或减少换行"，其余通用模板不提）。LLM 拿到按行切分的原文（`text` 是 `List[str]`），倾向于把换行结构照搬到译文里。

画布排版器 `SceneTextLayout`（`ui/scene_textlayout.py`）已有自动换行：横排 `WrapAtWordBoundaryOrAnywhere`、按文本框宽度贪心；文本框尺寸固定 = 检测到的原文区域。只要译文不含手动 `\n`，排版完全由框宽决定——这是用户期望的行为。一旦译文被塞入手动 `\n`，行数被强制翻倍 → 高度溢出 → 撑破用户预先调好的文本框，又得回头处理。

## 2. 目标

提供编辑侧"智能整理换行"工具，把译文里无意义的软换行清掉，交还给排版器自动重排。

**非目标**（明确排除）：
- 翻译侧归一化（送 LLM 前折叠原文换行）。本期不做。决策：日译中语义优先，默认应保留语义换行，故翻译侧不自动干预。后期可作独立 spec 加 `pcfg` 开关，默认关。
- 字号自适应到框。独立功能，复杂度高（迭代测量、竖横排差异、字号下限），后期单独 spec。
- 自定义右键菜单授权机制。本期不做，未来选项变多后再做。

## 5. 核心归一化函数

新增 `utils/text_normalize.py`，导出：

```python
QUOTE_PAIRS = [("「", "」")]  # 固定，本期单元素

def normalize_softbreaks(text: str) -> str:
    """按「」分块：块内 \\n → 空格、合并连续空白、剥行首尾空格；
       块与块之间用单个 \\n 分隔；不含「」的文本整体 \\n → 空格。
       不含 \\n 的原样返回（幂等）。
       嵌套「」取最外层配对，内层保留字面。"""
```

### 算法要点

- 用正则定位顶层 `「...」` 段与其外的普通段。嵌套情况取最外层配对；内层 `「」` 保留为字面字符不重复处理。
- 段内：`\n` → 单个空格；连续 `\n` 与空格合并为单个空格；剥行首尾空白。
- 段间拼接：相邻两段（一段 `」` 收尾、下一段非 `「` 开头，或反之）之间补单个 `\n`，避免与段内空格重复产生首尾空格。
- 不含 `「」` 的整体文本：所有 `\n` → 空格、合并连续空白。
- 幂等：再跑一次结果不变。
- 空/非字符串输入原样返回。

无 Qt 依赖、纯函数、易于单元测试。

## 6. 撤销命令 `NormalizeBreaksCommand`

借鉴 `BatchFontformatCommand`（`ui/fontstyle_manager_commands.py:19`）的跨页结构与 `_first_redo` 跳过模式，文本双写参照 `MultiPasteCommand`（`ui/textedit_commands.py:560`）思路。

### 构造

```python
NormalizeBreaksCommand(
    proj: ProjImgTrans,
    scene_manager,                 # 用于当前页 TextBlkItem 同步
    changes: List[Dict],            # 每项 {pagename, block_idx, old_translation, old_rich_text, new_text, squeeze}
    canvas,                         # push_undo_command 入口
)
```

### redo / undo

- redo：对非当前页直接改 `proj.pages[pname][bidx]` 的 `translation` 与 `rich_text`（同步）；对当前页同时改 TextBlkItem 的文档内容以触发重排。
- undo：还原所有命中块的 `translation` 与 `rich_text`，并刷新当前页 TextBlkItem。
- `_first_redo` 标记跳过首次重做（Qt 撤销标准模式，仿 `BatchFontformatCommand:71-73`）。

### squeeze 串联

若 `changes` 项含 `squeeze=True`，redo 文本后对该块调 `SqueezeCommand` 语义（保存旧 `_bounding_rect`，squeeze 后还原用）。实现期二选一：

- A. 把 squeeze 并为同一命令的子步骤（redo 内联 squeeze，undo 自行还原矩形）。
- B. 构造后串联 `SqueezeCommand` 作为独立命令推栈（注意：两步会变成两次 Ctrl+Z，违背"一次回退"目标，故倾向 A）。

→ **倾向 A**：合并为单命令，保证一次 Ctrl+Z 全部还原。

### 文本同步规则

渲染器优先读 `rich_text`（`textitem.py:437-441`：`if not blk.rich_text: setPlainText(translation) else setHtml(rich_text)`）。

用户视角不暴露 HTML（已与用户确认），但后端字段必须双写。命令 redo/undo 要同时保存还原 `translation`（纯文本）与 `rich_text`（HTML）。

**HTML 标签处理**（实现期唯一剩余验证点）：归一化针对 `blk.translation`（纯文本）生成新文本；`rich_text` 由 TextBlkItem 重建（重新 `setPlainText` → `toHtml()`），还是在正则层保留 HTML 标签结构？实现时取验证后选定，并在此文档补记结论。**倾向**：以 `translation` 为源、TextBlkItem 重建 HTML——UI 无需关心标签，逻辑最简，符合"用户视角纯文本"。

## 11. 验收标准

1. 选中一个含 LLM 塞入 `\n` 的横排译块，右键"整理换行" → `\n` 消失、文本按框宽自动重排，框尺寸不变；Ctrl+Z 一次全部还原（含文本与框）。
2. 多气泡合并到一个文本框（含多个 `「...」`）跑右键"整理换行" → 每个 `「」` 块独占一行、块内无软换行，行数 = `「」` 块数。
3. 竖排译块右键两项灰掉；批量对话框对竖排块跳过并在状态栏报"跳过 Y 块（竖排）"。
4. 批量对话框默认"全部页"勾选、列表禁用；取消勾选后可逐页选；应用后选中的所有页横排块被整理、竖排被跳过；Ctrl+Z 一次全部还原。
5. 勾"完成后自动收缩框"时，被整理块框收至内容尺寸，且 Ctrl+Z 还原框尺寸。
6. `i18n_check.py` 通过；QM 编译后中文菜单文案正确显示（无回退英文）。
7. 对不含 `\n` 的译文跑整理 → 无变化（幂等）；对同一译文连跑两次 → 第二次无变化。
