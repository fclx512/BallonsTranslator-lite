# 文本框重排面板设计

## 背景

右侧 TextPanel 的文本框列表目前仅支持拖拽重排。当文本框数量较多时（如 50+），拖拽移动大跨步（如将第 2 位移到第 49 位）操作不便。需要提供更高效、更易发现的重排方式。

## 设计

### 新增位置

`TextPanel`（`scenetext_manager.py`）内，在 [Fold/Source/Trans 切换行] 与 [TextEditListScrollArea] 之间，插入一个 `CollapsibleSection`，默认**折叠**。

布局示意：

```
 TextPanel (QVBoxLayout)
 ├── FontFormat CollapsibleSection
 ├── [Fold] [Source] [Translation]  ← 切换行
 ├── 重排文本框 CollapsibleSection  ← 新增，默认折叠
 │    └── ReorderContent Widget
 │         ├── Row 1: [▲] [▼] [⏫] [⏬]
 │         └── Row 2: Sel info (左) | → Pos: [input] [Go] (右)
 └── TextEditListScrollArea
```

### Row 1：四个基本按钮

| 按钮 | 功能 | 条件 |
|------|------|------|
| ▲ （上移） | 选中块集体上移一位 | 无选中 / 选中全部 / 选中块已在最前 → 禁用 |
| ▼ （下移） | 选中块集体下移一位 | 无选中 / 选中全部 / 选中块已在最后 → 禁用 |
| ⏫ （移到顶部） | 选中块集体移到列表开头 | 无选中 / 选中块已在开头 → 禁用 |
| ⏬ （移到底部） | 选中块集体移到列表末尾 | 无选中 / 选中块已在末尾 → 禁用 |

- 多选时整组移动，选中全部时四个按钮均禁用。
- 实现：调用现有 `RearrangeBlksCommand` / `on_rearrange_blks`，传入计算好的 `(drags_ori, drags_tgt)`。
- 按钮用 `QToolButton` 配图标，尺寸紧凑。

### Row 2：选定信息 + 跳转到指定位置

左右两列布局：

**左列（sel_info_label）**：显示当前选中的文本框信息
- 无选中：标签隐藏或空
- 选中 1 个：`#5`
- 选中 2~5 个：`3,5,7,9`
- 选中 6+ 个：`已选 7 个`

不通过 `self.tr()` 做 i18n，字符串硬编码以保证控件紧凑。

**右列（跳转区域）**：`→ 位置: [QLineEdit] [Go QPushButton]`
- 用户输入目标位置（1-based，范围 1 ~ 总数），按回车或点 Go 执行
- **输入框为空 → Go 按钮 setEnabled(False)**，按回车不响应
- 输入非数字 / 超出范围 → 不执行（或输入校验后在输入框上提示）
- 逻辑：选中块从列表中取出，顺位插入到目标位置之前
  - 例：10 个块，选中 3,4,5 → Go(10) → 结果 [1,2,6,7,8,9,3,4,5,10]
  - 等价于当前拖拽 drop 到第 10 块中线的逻辑
- 无选中时，Go 按钮禁用

### CollapsibleSection

复现有 `CollapsibleSection` 组件：标题 "重排文本框"，默认 `expanded=False`（收起），点击标题展开/折叠带动画。

### 绑定信号

选中信息实时更新：监听 `TextEditListScrollArea.selection_changed` 信号，更新 sel_info_label 和按钮 enabled 状态。

跳转位置执行：组装 `(drags_ori, drags_tgt)`，通过 `rearrange_blks` 信号走入现有 `RearrangeBlksCommand` 流程。

### 键盘快捷键（方案 B 部分）

在 `DEFAULT_SHORTCUTS` / `_ACTION_NAMES` / `_SHORTCUT_GROUPS` 中新增：

| key | 默认键 | 操作 |
|-----|--------|------|
| `move_up` | `Ctrl+↑` | 上移 |
| `move_down` | `Ctrl+↓` | 下移 |
| `move_top` | `Ctrl+Shift+↑` | 移到顶部 |
| `move_bottom` | `Ctrl+Shift+↓` | 移到底部 |

快捷键只在 textEditMode 且选中块时有效。

## 涉及文件

| 文件 | 改动 |
|------|------|
| `ui/textedit_area.py` | TextEditListScrollArea 增加 `move_blks` 方法，供外部调用触发重排 |
| `ui/scenetext_manager.py` | TextPanel 内添加重排 CollapsibleSection |
| `ui/configpanel.py` | DEFAULT_SHORTCUTS / _ACTION_NAMES / _SHORTCUT_GROUPS 增加 4 个快捷键 |
| `ui/mainwindow.py` | 安装/处理新增快捷键 |

## 不做的事

- 不改动画布上的 TextBlkItem 选中逻辑
- 不改动现有拖拽重排
- 不改动 `RearrangeBlksCommand` 内部实现
- 不做 i18n 翻译
