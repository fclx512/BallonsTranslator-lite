# 无字图功能

> 2026-06-30 起开发。当图源存在人工清稿或原生的无字图时，直接用无字图作为导出底图。

---

## 功能概述

漫画汉化中"修图"（抹掉原文）最耗时且质量不稳定。如果图源自带无字版，用它做底图嵌字远比自动修图好。

**核心设计：**
- **OCR / 检测 / 翻译** 仍用有字图（需要辨识原文位置和内容）
- **导出 / 保存** 用无字图做底图（嵌字到干净背景上）
- **完全独立于修图** —— 用户可同时跑修图 + 看无字图标签，互不干扰

**工作流：** 拿到有字+无字两份图源 → 独立工具配对重命名导出到 `notext/` → BT 打开图源自动识别 → 导出用无字图做底图

## 下一步计划

### 第一阶段：深度改造独立配对工具

**定位**：独立脚本，放 `tools/`，保持现有流式布局风格。功能增删 + UI 细节优化。

#### 1.1 自动智能匹配（核心新增功能）

当前 `import_notext_images()` 是无脑顺序填入，用户需要大量手动调整。改为自动按文件名相似度匹配。

**方案：**
- 新增 `auto_match()` 方法：对每个有字图文件名，在无字图列表中找最相似的
- 相似度算法：`SequenceMatcher` 或编辑距离（`difflib` 标准库，零依赖）
- 匹配阈值：≥0.6 自动填入，<0.6 留空（用户手动处理）
- 新增「自动匹配」按钮 → 调用 `auto_match()`；初次导入无字图时也询问是否自动匹配

**细节：**
- 匹配时忽略扩展名
- 相似度过低的无字图保留在"未匹配列表"中（右侧面板）
- 支持手动从"未匹配列表"拖到槽位（后续批次处理）

#### 1.2 槽位状态统计

工具栏新增槽位填充率显示：
```python
self.fill_label = QLabel("0 / 0 已配对")
# 实时更新："12 / 20 已配对"
```
放在工具栏右侧或状态栏突出位置。

#### 1.3 导出改进

- 导出前验证：检测输出路径是否已存在文件 → 警告覆盖确认
- 导出进度条（`QProgressDialog`）—— 当前直接 `shutil.copy2` 无反馈，大量图片时会假死
- 导出完成后不再弹 `QMessageBox`，改为状态栏提示 + 可选"打开文件夹"

#### 1.4 记住上次目录

- 工具运行时读写 `tools/.sort_history.json`（gitignore），保存最近的有字图/无字图文件夹路径
- 下次打开时 `QFileDialog` 默认定位到上次目录
- 窗口位置/大小也写入，下次恢复

#### 1.5 UI 细节优化

**工具栏重排：**
```
[导入有字图] [导入无字图] [自动匹配]  |  [撤销]  |  [补齐] [空格后退] [清除空槽]  |  [导出到notext]
```
分组加微弱分隔线，或用 `|` 留白区分"导入""编辑""导出"三组。

**缩略图缓存管理：**
- 工具关闭时清理 `_thumbnail_cache`（当前永不释放）
- 缩略图尺寸可选：小(120)/中(160)/大(200)，默认 160

**预览弹窗增强：**
- 叠加显示文件名 + 尺寸信息
- 支持滚轮缩放
- 差异叠加模式：半透明叠加有字图在无字图上，红色高亮差异区域（`QPainter.CompositionMode_Difference`）

**快捷键面板：**
- `?` 或 `F1` 弹出快捷键速查表

#### 1.6 功能删减

- **补齐**（`fill_gaps`）：保留，但提示文本修正（当前提示"两个有图槽位"应为"两个无字图槽位"——这是 bug）
- **清除空槽位**：改名「重置空槽」，功能不变
- **更新(F5)**：改名「同步名称」，当前行为是把无字图的 `display_name` 更新为对应有字图文件名 → 保留

#### 1.7 Bug 修复

- `fill_gaps()` 提示文本："有图槽位" → "无字图槽位"（变量语义错）
- `shift_selected_back_one()`：当前按空格将选中图及右侧全部后移 → 行为合理但无视觉预览，增加闪烁高亮提示目标位置

### 第二阶段：主项目最小集成

**只做一件事**：在 BallonsTranslator 中提供启动配对工具的入口。

#### 2.1 工具栏启动按钮

在 `MainWindow` 工具栏中增加一个动作按钮：
```python
# mainwindow.py 或 mainwindow_mixin.py
def on_launch_notext_tool(self):
    tool_path = osp.join(shared.PROGRAM_PATH, "tools", "无字图配对工具.py")
    subprocess.Popen([sys.executable, tool_path])
```

- 按钮文案：「配对无字图」
- 放入现有工具菜单或左栏工具区
- 点击后工具在新窗口启动，不影响主项目
- 如果当前有打开项目且有 `notext/` 目录，可传参自动定位

#### 2.2 打开项目时的通知

在 `openDir()` 或 `ProjImgTrans.load()` 完成后，扫描 `notext/` 并统计匹配数：
```
状态栏: "已加载 20 页，其中 16 页有无字图"
```
仅在 `pcfg.use_notext_images = True` 时显示。
