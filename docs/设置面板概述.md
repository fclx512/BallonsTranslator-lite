### 页面创建机制

原先的代码用 `dlConfigPanel.addGroupedBlock(...)` 将 section 添加到两个 `ConfigBlock`（dl/general）的 vlayout 中，这两个 block 在 `ConfigContent`（QScrollArea）里纵向排列。重构后引入了两个中间类：

```python
class _DeadLayout:
    """存根：addWidget(head_widget) 委托给 _active_panel._add_page（添加为独立页面）"""

class _DeadBlock:
    """存根：addGroupedBlock 委托给 _active_panel._add_grouped_page"""
```

`ConfigPanel._active_panel`（类属性）在 `__init__` 开始时设为 `self`，确保构建期间 `_DeadBlock`/`_DeadLayout` 能找到正确的面板实例。构建期间：

- `dlConfigPanel.vlayout.addWidget(models_group)` → `_add_page(models_group)` → page 0
- `dlConfigPanel.addGroupedBlock(Text Detection, ...)` → `_add_grouped_page(...)` → page 1, 2, 3, 4
- `generalConfigPanel.addGroupedBlock(...)` → page 5, 6, 7, 8

`_wrap_page(content: QWidget) -> QScrollArea` 将每个 section 的 PanelGroupBox 包裹为带 `CONFIGBLOCK_CONTENT_MARGINS`（12,0,0,0?）的滚动页面。

## NavList 分页连线

- `navList.currentRowChanged` → `_on_nav_row_changed(row)`：读取 `_nav_items[row]` 取出 `target`（section_widget），通过 `_page_index[id(target)]` 查到 page index → `pageStack.setCurrentIndex(idx)`。Models 页面特殊处理：`if target is self.models_group: setCurrentIndex(0)`。
- `_nav_select(section_widget)`：遍历 `_nav_items` 定位行，`setCurrentRow` → 间接触发 `_on_nav_row_changed` 切页。
- `focusOnDetect/OCR/Inpaint/Translator`：调用 `_nav_select(sub_block.section_widget)`，不再调用 `scrollToWidget`。
- 已删除：`_on_content_scrolled`（反向同步）、`ConfigContent.scrollToWidget`、`ConfigContent` 类（保留为死代码但不再使用）。

## OverlayModal 机制

### 载体

`ui/overlay_modal.py` 的 `OverlayModal(QObject)`。它在 `cover_widget`（`centralStackWidget`）上方创建一个 `_Scrim(QWidget)`，面板（ConfigPanel）位于 scrim 之上居中。

### 核心参数

```python
_PANEL_W = 1000      # 面板固定宽（cover 小则缩）
_PANEL_H = 700       # 面板固定高
_SCRIM_ALPHA = 0.55  # 遮罩不透明度目标值
_DEFAULT_DURATION = 350  # 动画时长 ms
```

### 动画

scrim 和 panel 各有 `QGraphicsOpacityEffect`，用 QTimer 按 `_detect_interval()`（= `pcfg.animation_fps` 换算的帧间隔）驱动，`QEasingCurve.InOutExpo` 插值。

`pcfg.animation_fps < 0` 或 `duration ≤ 0` 时跳过动画：

- `show()`：直接 `panel_effect.setOpacity(1.0)` + `scrim.set_alpha_target(0.55)`
- `hide()`：直接 `panel.hide()` + 销毁 scrim

在动画过程中收到反向操作（show 时收到 hide，hide 时收到 show）会**平滑反转**（`_reverse` 方法）。

### 关闭路径

- **scrim 点击**：`_Scrim.mousePressEvent` 检查 `_closable`，为 True 时调用 `OverlayModal.hide()`（通过 `on_click_outside` 回调）。子对话框打开期间 `_closable=False`。
- **配置图标再次点击**：`leftBar.configChecker` 互斥 → `setupConfigUI()` → 已在显示时 `_hideConfigOverlay()`。
- **imgTrans 互斥切换**：`leftBar.imgTransChecker` 被点 → `_hideConfigOverlay()`。
- **不设 ESC 关闭**（设计决定）。

### scrim 范围

scrim 只覆盖 `cover_widget`（`centralStackWidget`，即 canvas 区域 + 右侧翻译面板）。**左栏 leftBar、底栏 bottomBar、标题栏 titleBar 在 scrim 外部**，仍可点击。底栏 cfg 按钮点击后可直接切到对应分页，左栏 imgTrans 图标点击会使设置关闭再切换到翻译面板。

## 子对话框 backdrop 屏蔽

7 处 `dialog.exec()` 调用改为经 `_run_modal_dialog(dialog)`：

```python
def _run_modal_dialog(self, dialog) -> int:
    if self._modal_ref is not None:
        self._modal_ref.set_backdrop_closable(False)
    result = dialog.exec()
    if self._modal_ref is not None:
        self._modal_ref.set_backdrop_closable(True)
    return result
```

## i18n 注意事项

1. 所有 UI 文字都用 `self.tr("English")`。
2. ts 中 `<context>` 对应类名。ConfigPanel context 包含 Models、Detect 等字符串。
3. 新增导航行 `label_models = self.tr("Models")` 与 PanelGroupBox 标题共用同一翻译字符串，ts 中无需新条目。
4. `_ShortcutRow` 使用 `self.tr(ACTION_NAMES[id])` 间接调用，i18n_check 始终报 orphan（假阳性）。
5. **QM 编码陷阱**：qm_compile 的 `_iso8859_str()` 须用 utf-8（已修复），否则 `—/→/✓` 被替成 `?` 导致 Qt 哈希查找失败。
6. 编译验证：
   ```bash
   python scripts/qm_compile.py translate/zh_CN.ts translate/zh_CN.qm
   python scripts/i18n_check.py          # 日常
   python scripts/i18n_check.py --ci     # 发版（对 orphan 退出码 4）
   ```

## 已知瑕疵 / 待现场微调

1. **Panel 固定 1000×700**：字体委派网格等宽控件的布局在窄裁切窗口下可能溢出。已在代码中预留 `fit window` 判据（cover 小于 1000 则缩），但整体由 `NavList`（~228px） + `pageStack` 余量共同决定。
2. **`_on_nav_row_changed` 的 Models 特殊分支**：`self.models_group` 未归入 `_page_index`，而是硬编码 `setCurrentIndex(0)`。这是为了保持 `_add_page` 在返回前尚未被被模型化地索引。如 Models 页面变更顺序需同步更新此处。
3. **`_is_canvas_mode`**：读取 `panel.isVisible()` 抑制画布快捷键，行为不变（`mainwindow.py:660`）。
4. **AnimatedScrollBar 未在每页使用**：`_wrap_page` 使用 `AnimatedScrollBar`。建议为每页统一风格。
5. **Models 页外框**：Models 的 PanelGroupBox 顶边与 NavList 顶部无对齐约束，由左右独立布局控制。

## 测试流程（供后续 AI 参考）

### 离屏快速验证（弱模型友好版）

以下脚本模拟了软重建+面板切换+动画隐现等流程，不依赖于真正的 UI 环境（设 `QT_QPA_PLATFORM=offscreen`）。可直接复制为 `.py` 文件执行，之后观察输出或为断言提供结果：

```python
import os
os.environ.setdefault('QT_QPA_PLATFORM', 'offscreen')
import time
from qtpy.QtWidgets import QApplication
from utils.config import load_config, pcfg  # pcfg 是单例

# 预加载 TrueType（辅助函数），加载配置并混洗
app = QApplication([])

# Monkey‑patch 跳过平台窗口的额外初始体（frameless toggle 在 offscreen 会失败）
import ui.framelesswindow as fw
fw.FramelessMoveResize.toggleMaxState = staticmethod(lambda *a, **k: None)

from ui.mainwindow import MainWindow
w = MainWindow(app, load_config())
w.show()
w.resize(1400, 900)        # 模拟合理窗口大小
app.processEvents()

pcfg.animation_fps = -1    # 跳过动画以加快验证

# —— 测试模态显隐
w._showConfigOverlay()
app.processEvents()
assert w.configPanel.isVisible(), "SHOW: panel after build should be visible"
assert w._configModal._scrim is not None, "scrim should exist in cover"
assert w._configModal._scrim._closable, "backdrop should be closable default"

w._hideConfigOverlay()
app.processEvents()
assert not w.configPanel.isVisible(), "HIDE: panel after close should not be visible"

# —— 测试每个导航行都能正确切页
nav = w.configPanel._nav_items
page_stack = w.configPanel.pageStack
prev_page = page_stack.currentIndex()
for target, row in nav:
    if target is None:
        continue
    w.configPanel.navList.setCurrentRow(row)
    app.processEvents()
    current = page_stack.currentIndex()
    assert current != prev_page or current == 0, \
        f"NAV: row {row} should switch page (from {prev_page})"
    prev_page = current
print(f"Page count: {page_stack.count()}, nav rows: {len(nav)}")

# —— 测试 focusOn 路径（底栏 cfg 入口调用）
for fn in ('focusOnDetect', 'focusOnOCR', 'focusOnInpaint', 'focusOnTranslator'):
    getattr(w.configPanel, fn)()
    app.processEvents()
    idx = page_stack.currentIndex()
    assert 1 <= idx <= 4, f"{fn} resulted in page {idx}, expected 1-4"

# —— 测试 backdrop 暂停（模拟子对话框屏蔽）
w._showConfigOverlay()
scrim = w._configModal._scrim
w._configModal.set_backdrop_closable(False)
assert not scrim._closable, "after suspend, _closable should be False"
w._configModal.set_backdrop_closable(True)
assert scrim._closable, "after resume, _closable should be True"

# —— 测试动画路径（非跳过）
pcfg.animation_fps = 60
w._showConfigOverlay()
app.processEvents()
time.sleep(0.6)
app.processEvents()
assert w._configModal._panel_effect.opacity() == 1.0, "anim show should set opacity 1.0"
w._hideConfigOverlay()
time.sleep(0.6)
app.processEvents()
assert not w.configPanel.isVisible(), "anim hide should close panel"

# —— 测试 hideEvent 触发了 save_config（日志可见 "Config saved"）
pcfg.animation_fps = -1
w._showConfigOverlay()
w._hideConfigOverlay()
app.processEvents()

# —— 每页都是 QScrollArea（包裹 `_wrap_page`）
from qtpy.QtWidgets import QScrollArea
for i in range(page_stack.count()):
    assert isinstance(page_stack.widget(i), QScrollArea), \
        f"page {i} should be QScrollArea"

print("ALL CHECKS PASSED")
```

### 人工验收清单

1. **启动**：`python launch.py` 正常打开。
2. **打开/关闭设置**：点 LeftBar 设置图标 → **淡入**（无侧滑）；点遮罩空白区关闭、再点设置图标切换、再点 imgTrans 图标——均应淡出关闭。
3. **分页切换**：NavList 点 Text Detection / OCR / Inpaint / Translator / Models / Project / Typesetting / Interface / Environment → 右侧各自换页，无滚动；NavList 指示条动画正常。
4. **底栏 cfg 入口**：点底栏 4 个 selector 的 cfg → 打开并直接跳到对应页（Mixin `to_*_config` 路径直达）。
5. **子对话框**：打开 Shortcuts / Exclude Fonts / Profile 等任一 → 点遮罩**不应**关闭设置；关掉子对话框后点遮罩应正常关。
6. **保存**：改任意设置 → 关闭面板 → 重启/查 `config.json` 确认落盘。
7. **动画开关**：Interface 区 Animation 切 Off → 开关设置无动画；切回 Auto → 淡入淡出恢复。
8. **快捷键抑制**：设置打开时画布快捷键（T/W/P/Tab 等）应被抑制（`_is_canvas_mode` 返回 False）。
9. **scrim 范围**：设置打开时点 LeftBar imgTrans 图标能响应（关闭设置）、点底栏 cfg 按钮能跳页——确认只压暗中央画布区，LeftBar/BottomBar 可点。
10. **i18n**：中英 UI 切换无明显回退。
