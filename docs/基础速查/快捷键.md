# 快捷键系统指南

> 2026-08-23 并入原技术实现文档《快捷键系统》的动作清单（见文末），该独立文档已删除。

## 架构

快捷键系统由三层构成：

```
DEFAULT_SHORTCUTS (configpanel.py)     ← 默认值定义
        ↓
pcfg.shortcuts (config.json)               ← 用户自定义覆盖
        ↓
MainWindow._install_shortcuts() (mainwindow.py)  ← QShortcut 注册
```

查询优先级：`pcfg.shortcuts` > `DEFAULT_SHORTCUTS`

## 添加新快捷键的步骤

### 1. 在 DEFAULT_SHORTCUTS 中定义默认键

文件：`ui/configpanel.py::DEFAULT_SHORTCUTS`

```python
DEFAULT_SHORTCUTS = {
    'my_action': ['Ctrl+Shift+X'],
    # ...
}
```

键名（action_id）使用 snake_case。值是一个 list，可绑定多个键序列。

### 2. 在 _ACTION_NAMES 中添加显示名称

```python
_ACTION_NAMES = {
    'my_action': 'My Action',
    # ...
}
```

### 3. 将动作分组到 _SHORTCUT_GROUPS

```python
_SHORTCUT_GROUPS = [
    ('GroupName', ['my_action', ...]),
    # ...
]
```

### 4. 注册 QShortcut

**唯一正确的位置：[ui/mainwindow.py](ui/mainwindow.py) 的 `_install_shortcuts()` 方法内**

```python
def _install_shortcuts(self):
    # ...
    self.shortcut_registry['my_action'] = self._make_shortcuts(
        'my_action',            # action_id — 必须与 DEFAULT_SHORTCUTS/_ACTION_NAMES 的 key 一致
        self.my_handler_method, # slot      — MainWindow 上的处理方法
    )
```

`_make_shortcuts()` 内部经 `_get_shortcut_keys()` 解析生效键：`pcfg.shortcuts` 有自定义用自定义，否则用
`default_keys_for(action_id)`（`ui/configpanel.py`，按 `_STANDARD_DEFAULT_KEYS` 走 Qt StandardKey、
其余回退 `DEFAULT_SHORTCUTS`）。默认键已由配置侧单源解析，不再需要调用方传 defaults。

### 5. 编写 handler 方法

handler 是 MainWindow 上的普通方法，不需要判断 sender：

```python
def my_handler_method(self):
    if self._is_canvas_mode():  # 仅在画布模式下响应
        # ... 具体逻辑 ...
```

如果需要在 handler 中识别是按了哪个键触发的，用 `self.sender()`：

```python
def shortcutBefore(self):
    sender = self.sender()
    if isinstance(sender, QShortcut) and sender.key() == QKEY.Key_A:
        if self.canvas.editing_textblkitem is not None:
            return
    # ... 实际逻辑 ...
```

## 必须遵守的规则

### 规则 1：所有快捷键必须在 `_install_shortcuts()` 中注册

❌ 禁止在 `TitleBar`、`LeftBar` 或其他地方调用 `QAction.setShortcut()`。  
✅ 所有键盘快捷键统一经 `_install_shortcuts()` → `_make_shortcuts()` 创建 `QShortcut`。

理由：硬编码的 `setShortcut()` 无法被快捷键编辑器覆盖，用户在界面中修改后不会生效。

### 规则 2：action_id 必须与配置侧定义完全一致

`_make_shortcuts(action_id, slot)` 的 `action_id` 必须是 `DEFAULT_SHORTCUTS` 的 key（同时登记
`_ACTION_NAMES` 显示名、加入 `_SHORTCUT_GROUPS` 分组），否则默认键解析、编辑页显示、reset 都会落空：

```python
# DEFAULT_SHORTCUTS = {'my_action': ['Ctrl+Shift+X']}

# ✅ 正确
self._make_shortcuts('my_action', self.handler)

# ❌ 错误 — action_id 不一致（default_keys_for 解析不到默认键）
self._make_shortcuts('my_action_xxx', self.handler)
```

### 规则 3：用 `QShortcut` 而非 `QAction.setShortcut()`

- `QShortcut` 直接注册在 `MainWindow` 上，可通过 `refreshShortcuts()` 热更新
- `QAction.setShortcut()` 注册在父 widget 上，无法通过配置系统管理

### 规则 4：菜单/工具栏中的快捷键提示

菜单中的 `QAction` 不应该调用 `setShortcut()`（快捷键已在 `_install_shortcuts()` 中注册）。菜单项不会自动显示快捷键提示——目前的设计是让用户在快捷键编辑器中查看。

## 热更新机制

快捷键编辑在设置面板的 **Shortcuts 页**（导航树 General 分组下）进行，编辑后**实时生效**：

```
设置面板 Shortcuts 页某行 +/x/Del/Rst
  → _ShortcutRow.shortcut_changed Signal
  → ConfigPanel._on_shortcuts_edited()  → save_config() + shortcuts_changed Signal
  → MainWindow.refreshShortcuts()
  → 删除所有旧 QShortcut
  → 调用 _install_shortcuts() 用最新 pcfg.shortcuts 重建
```

修改快捷键后立即生效，无需重启、无需关闭设置面板。

### 补充说明

- **平台默认键**：undo/redo/select_all/italic/underline/page_search/delete_blks/zoom_in/zoom_out 在
  `_STANDARD_DEFAULT_KEYS`（`ui/configpanel.py`）里经 `default_keys_for()` 走 Qt `StandardKey` 解析——
  macOS 得到 Command 系原生绑定，Windows 上结果与字面串逐字节一致（`tests/test_shortcut_system.py` 守护）。
- **i18n 坑**：动作名经 `self.tr(_ACTION_NAMES[id])`、分组名经 `self.tr(group_name)` 间接翻译 →
  `i18n_check` 恒报 orphan（已知白名单），需**手工**在 ts 的 `_ShortcutRow`/`ShortcutEditor` context
  维护 `<message>`（AGENTS.md i18n 一节有专述）。
