# AI 辅助标签体系 · 使用说明（测试版）

> 状态：批次 A–D 已实施，2026-09-13 实机验收**结单**。本模块**按需长期维护优化的类型对待**——主体可用，后续在使用中挑痛点逐条改；余项与打磨方向见
> [AI辅助功能_设计与实现](../技术实现/AI辅助功能_设计与实现.md) 的 §17「未落地与待办」，设计背景见同文其余各节。
> 本文是**功能地图**：每节末尾有「测什么」清单，改动或回归时照跑。
> 2026-09-16 补记：泛用工作台批次 A 给标签体系加了「误识别文本」类型与审阅表态 `reviewed`（见「标签清单」下的小节）——它的挂标与数据层在本模块，消费方（工作台队列、批量合并的排除）属泛用工作台，见[AI辅助功能_设计与实现](../技术实现/AI辅助功能_设计与实现.md) 的「工作台」部分。

## 一句话总览

给文字块挂**标签**（程序自动挂 + 人工点一下挂），标签驱动三类事：

1. **画布徽标**——静息态一眼看出哪些块有问题（右上角小色签）；
2. **框级 AI 动作**——选中块点「处理」，AI 单轮出草稿，你确认才写回（可撤销）；
3. **批量管线消费**——翻译时带指示标签的块会收到额外翻译指令。

## 标签清单

| 标签 | 性质 | 来源 | 消费方式 |
|---|---|---|---|
| OCR 置信度低 | 疑点 | 程序自动挂 + 人工 | 「OCR 校正」动作（vision 看图），确认后消除 |
| 误识别文本 | 疑点 | **仅程序**（OCR 后处理钩子） | **无 AI 动作**；出口是工作台「误识别清理」队列的人工审阅（驳回）与一键批量删除。**不提供人工打标途径**，批量合并相邻框时这类框被排除（见下节） |
| 手写体 | 指示 | 人工 | 「OCR 校正」动作 + 管线翻译指令，**处理不消除** |
| 语气/拟声词 | 指示 | 人工 | 管线翻译指令（发声直译），**处理不消除** |
| 译文迷惑 | 疑点 | 人工 | 「重译」动作（可大幅改写），确认后消除 |
| 译文润色 | 疑点 | 人工 | 「重译」动作（保意微调），确认后消除 |

- 疑点 = 一次性任务，AI 处理并「应用」后自动消除；指示 = 块的持久属性，保留。
- 标签随项目 JSON 保存（`utils/textblock.py::TextBlock` 的 `tags` 字段），旧项目自动兼容。
- 标签只出现在**画布交互**里，右侧文本区不涉及。

### 「误识别文本」与审阅表态（泛用工作台批次 A，2026-09-16）

这是标签体系里第一个**没有 AI 动作出口**的类型——AI 看图也认不出「纯数字框是什么内容」，所以它只需要「人确认／驳回」。

- **挂标**：OCR 跑完后由 `utils/block_tags.py::tag_misread_hook`（注册在 `modules/ocr/base.py::OCRBase` 上，覆盖全部 OCR 模块）按正则判定四类子类型：空文本／纯数字／纯符号／**无假名汉字**（最后一类最需要人工过滤，会误伤英文拟声词与外来语）。四类存同一条目的子类型字段，一块可同时命中多类（`utils/block_tags.py::MISREAD_TAG_ID`）。
- **不提供人工打标**：标签工具栏与右键菜单只有人工标签（`utils/block_tags.py::MANUAL_TAG_DEFS`）；这条标签是程序专用的。
- **审阅表态**：驳回＝给该块的程序标签条目置 `reviewed`（`utils/block_tags.py::set_tags_reviewed`，块级、可逆、驳回后条目仍在）。**驳回后重跑 OCR 不会复活**（挂标处跳过带 `reviewed` 的条目）。
- **人工改写原文即知情**：改写该块原文会清掉它的全部程序标签（含已驳回条目）——你既然改过，程序判定就不再作数，重跑 OCR 会重算。
- **队列口径**：队列＝带这条标签的块（按块去重）；待处理数＝队列内块数 − 已驳回块数（`utils/block_tags.py::misread_queue_summary`）。`ocr_low_conf` 不单独入队，它的出口是框级「OCR 校正」动作。
- **批量合并相邻框时被排除**：带**未驳回**误识别标签的框不参与合并（`ui/batch_merge.py::BatchMerge`）；已驳回的框视同普通框参与——否则「标签判错 → 驳回 → 仍被排除」会卡死。

**测什么**：跑一次 OCR 看纯数字／纯符号框是否被挂签；驳回一块后重跑 OCR，标签不复活；驳回后再改该块原文，程序标签整条清掉；合并相邻框时带未驳回误识别标签的框不出现在候选组里。

## 一、画布徽标（批次 A）

带标签的块在**轮廓右上角**显示圆角小签：字形连排、疑点暖红、指示冷蓝、选中时主题色。多标签并挂时字形连排（如 `!✎`）。与左上角序号徽标互不遮挡。

- 显隐开关：设置面板界面页「标签徽标」复选框；右键/饼菜单「标签徽标」勾选项（`utils/config.py::show_tag_badge`）。
- 导出成图不含徽标（渲染前自动隐藏，与序号徽标同一隔离路径）。

**测什么**：开关切换后画布即时生效；导出/渲染结果图无徽标；选中块徽标变主题色、取消后恢复。

## 二、OCR 置信度自动挂标（批次 A）

本地两个 OCR 模型（onnx / mit48px）识别时把每行分数聚合（取**最差行**，整行被过滤丢弃也计入），低于阈值自动给块挂「OCR 置信度低」，分数存进标签条目（不喂给 AI）。

- 阈值：`modules/ocr/ocr_onnx.py::OCR_CONF_TAG_THRESHOLD` 与 `modules/ocr/mit48px_ctc.py::OCR_CONF_TAG_THRESHOLD`，当前均 0.6，**初版猜测值**，待跑分分布后调；设置面板的编辑入口排在后续。
- 重跑 OCR：分数回好的块自动摘掉程序标签；人工确认过的标签不被程序覆写。

**测什么**：跑一次带 OCR 的管线，看难认的气泡是否被挂签；全书翻页扫一眼徽标分布是否符合观感。

## 三、选中跟随工具栏（批次 B 主入口）

选中块时块上方出现浮动工具栏（`ui/tag_toolbar.py::TagToolbar`）：

- 紧凑栏 = 5 个标签切换钮 + `⋯` 展开钮 + （条件出现的）动作钮；
- 展开面板 = 全类标签行（名称 + 疑点/指示标注），再点收回；
- 无选中 / 非文本编辑模式即隐，紧凑与展开一致；
- 多选时标签钮按「全员都带 → 勾选」显示，点一下批量打标；
- 视口滚动时跟随选区重锚。

**测什么**：选中/框选/取消选中；展开收回；多选批量打标；滚动跟随；拖动块时工具栏位置是否合理（当前只在滚动和选中变化时重锚，**缩放后不主动重锚**是已知简化）。

## 四、打标入口四件套

| 入口 | 形态 | 说明 |
|---|---|---|
| 选中工具栏 | 切换钮 | 主入口，见上 |
| 右键菜单 | 「打标」分区 5 条勾选 + 2 条动作 | 按菜单勾选值写入 |
| 饼菜单 | Tagging 分区（同注册表） | 与右键同源 |
| 快捷键 | `1–5` 翻转标签，`E/Q` 跳标签块 | 快捷键编辑器「打标」分组可改 |

- 快捷键是**翻转**语义：多选时「非全员带 → 全挂，否则全摘」。
- 打标不进撤销栈（误点再点即撤），但会标记项目未保存。

**测什么**：四个入口各自打标/取消；`1–5` 在选中块上翻转对应标签；打标签题栏出现未保存状态。

## 五、框级 AI 动作（批次 C）

**触发**：单选块 → 工具栏上的动作钮（块带对应疑点标签才出现），或右键菜单两条动作命令（无标签也能手动触发）。多选时不提供（批量编排留待后续）。

| 动作 | 做什么 | 写回目标 |
|---|---|---|
| OCR 校正 | 发**按行透视纠正的拼图**（`utils/block_actions.py::stitch_line_crops`）+ 每行现有 OCR 文本 + 邻近块上下文给 vision 模型，单轮、无工具 | **原文** |
| 重译 | 走当前翻译器的单框 context 模式（`modules/translators/trans_agent.py::translate_with_context`），带邻近块上下文 + 指示标签指令 + 补充要求 | **译文** |

**流程**（`ui/block_action_card.py::BlockActionCard`）：

1. 点动作 → 块旁弹出确认卡，进入「处理中…」，可点**取消**；处理中就把切图摆出来，手写体可以边等边读；
2. 完成 → 卡片变成**草稿**：OCR 校正的回复能与行对齐时给**逐行行**（勾选=采纳模型改法，取消勾选=保留原行，行内还能直接改写），对不齐则退化成整块可编辑框；
3. 点**应用** → 写回并进**全局撤销栈**（Ctrl+Z 可整步撤），块上的疑点标签自动消除；
4. 点**放弃** → 什么都不动，标签保留。

**三个「非黑箱」入口**：

- **切图预览**：卡片里显示的就是送给模型的同一张图，点一下按原生尺寸放大（滚动查看）——手写体这类模型靠不住的情形，人对着图直接敲；
- **〔↗〕展开**后可见**上下文包**：本次实际送出的原文、邻近块（±2）、生效的标签指令、你的补充要求逐项列出（另注：同页其他块、前页与梗概由翻译器统一注入）；
- **补充要求**：一行输入 + 「重跑」，把只有你知道的信息（语气、人名、称呼、这是拟声词）作为显式字段交给模型；失败的请求也保留人工填写路径。

**保护机制**（§8.9）：处理中可随时取消（vision 请求丢弃结果；重译同时通知 agent 停止）；**切页自动取消并 toast 提示**——未确认的提案不会写入任何数据。

**数据一致性前置**（`ui/mainwindow.py::_sync_block_data`）：画布合并/撤销只改视觉层，数据层要等保存才按画布重建，所以每个框级动作开始前先做一次一致性修复。**这是「合并块只出第一个子块内容」的修复点**——合并后立刻重译，送出去的已是完整合并文本，裁图也是合并后的外框。

**前置条件**：OCR 校正需要一个**能用的**视觉 profile——即同时填了 `api_host`、模型名，且 key 不是空/占位（本地服务如 LM Studio / Ollama 免 key）。在「模型管理」里配好后点该卡片上的**「使用」**，各模块默认跟随它；重译则需要当前翻译器可用（Agent 走完整上下文链路，其他翻译器降级为直译草稿）。

> profile 的选取规则（`utils/profile_manager.py::resolve_profile`）：模块选择器里显式选的可用项优先 → 全局激活的（模型管理页「使用」那个）→ 该模块候选池里第一个可用项。选择器里存的名字若失效（key 被清、模型被删、profile 改名），启动时会自动归位到可用的那个，下拉框显示的永远是实际在用的——所以**配完 key 记得点一下「使用」**，否则各模块只会自动挑「第一个能用」的，未必是你想要的那个。

**测什么**：

- 带「OCR 置信度低」/「手写体」的块点「OCR 校正」→ 看**切图对不对**（应是逐行摆正后的样子，不是原图里那块矩形）→ 逐行取舍（取消勾选一行看是否保留原行）→ 应用 → 原文更新、徽标消失、Ctrl+Z 回退；
- 点切图放大，确认能看清小字；
- 「译文迷惑」块走重译；展开看上下文包是否列全了送出的信息；
- 补充要求填一句（如「语气更冲」）→ 重跑 → 看译文是否跟着变；补充要求在上下文包里出现；
- 合并两个块（右键 Merge）后立刻重译 → **译文应是合并后的整段**，不是其中一个子块的内容；
- 处理中点取消 / 处理中切页；未配 vision profile 时的提示。

## 六、管线消费指示标签（批次 D）

批量翻译（运行对话框/逐页翻译）组装 prompt 时，带**指示标签**的块会收到逐块指令（`modules/translators/agent/prompts.py::build_user_task_message` 的 `instructions` 字段；手写体=结合上下文推断语义、拟声词=发声直译）。疑点标签不阻塞自动管线。

- 仅 Agent 翻译器消费（`modules/translators/base.py::translate_textblk_lst` 按声明透传）；
- 单框翻译「Plain 直译」档**有意**不注入（该档语义就是裸直译）。

**测什么**：给一块挂「语气/拟声词」，批量翻译该页，对比该块译文是否按发声直译。

## 七、带标签块跳转（批次 D）

`E` / `Q`（或右键/饼菜单「下一个/上一个带标签块」）全书循环跳转，跨页自动切页并居中选中（`ui/mainwindow.py::jump_to_tagged_block`）。与徽标显隐配合成「扫过去 → 跳过去 → 处理掉」的校对闭环。

**测什么**：多页挂几个标签，E/Q 循环跳转；全书无标签时命令禁用（不发）。

## 已知边界（可推翻点）

以下是使用侧能直接撞到的边界；**余项总账在[AI辅助功能_设计与实现](../技术实现/AI辅助功能_设计与实现.md) §17**（长期维护优化项都挂在那里，随使用中挑出的痛点逐条改）。

- 置信度阈值 0.6 是猜测值，设置入口后补；
- 工具栏/卡片缩放后不主动重锚（滚动与选中变化时重锚）；
- **逐行取舍只在「行几何与 OCR 文本一一对应」时出现**（OCR 刚跑完的块）；人工改过或合并过的块文本对不上行，退化为整块草稿——不拿行数去凑对齐；
- **逐行筛选暂时不区分「哪行可疑」**：每行分数在两个 OCR 模块里算了但只留了 min（`utils/block_tags.py::apply_ocr_confidence_tag`），要按分数预选可疑行得先把逐行分数留下来，属于数据层改动，暂不动；
- 框级动作 v1 仅单块；批量 AI 编排与工作台任务化（批次 E 方向）见设计 §17（批量编排与全局扫描方向）；
- 确认卡片是单提案 + 逐行/整块编辑 + 补充要求重跑；多候选（一次给两个改法让人挑）按反馈再议；
- 徽标配色/字形为初版设计。
