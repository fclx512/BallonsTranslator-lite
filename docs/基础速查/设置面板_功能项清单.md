## 2. 侧边导航：从树改成卡片

### 2.1 旧样子（2026-09-20 前，`ConfigTable`，已删）

| 事实 | 位置 |
| --- | --- |
| `QTreeView` 子类，宽 180px（`min = max`），`setIndentation(20)`，无边框 | `utils/shared.py::NAVLIST_WIDTH` |
| 组标题字号 = `CONFIG_FONTSIZE_TABLE + 3` = 16pt；叶子项 13pt；行高 = 字号 + 14 | 已删的 `TableItem` / `TreeModel`（`data()` 里算的） |
| 组标题只是「不可选中」（`setSelectable(False)`），其余与叶子项同类（可折叠、可悬停） | 已删的 `TableItem`、`addHeader` / `addSection` |
| **选中态只有粗体**：QSS 把选中背景写成透明 | `config/stylesheet.css` 的 `#ConfigNavList::item:selected`（已删） |
| 悬停态没有专用规则，落到通用 `QTreeView::item:hover` | `config/stylesheet.css` 的 `QTreeView::item:hover` |

### 2.2 为什么不好看（用户观感：明显是列表样式没调好）

1. **层级差只有一个字号**：标题与叶子项共享同一条悬停规则、同一套 padding、同一套行高算法，差的只是 +3pt 和折叠箭头——读起来像「列表里一条更大的项」，不像分组标题。
2. **两条强调规则打架**：组标题是 16pt 常规字重，选中的叶子项是 13pt 粗体，同屏时都像「加粗文字」，看不出哪个是分组、哪个是当前位置。
3. **标题行会跟着鼠标变底色**：扫过组标题时它表现得和叶子项一样可点（实际是折叠）。

**结论：树/列表这条路走不通**——只要还是列表，组标题与项就逃不开共用一套 item 规则，所以整体弃用树控件，改卡片（用户拍板）。

### 2.3 定案：卡片式导航条（已实现）

```
ConfigNavRail（QScrollArea，宽 180，背景＝凹陷色）
└─ ConfigNavGroup × 2（分组卡：@widgetBackgroundColor + 1px @borderColor + 圆角 7）
   ├─ 居中标题 QLabel#ConfigNavGroupTitle（16px 粗体，不可点、不悬停）
   └─ ConfigNavItem × N（可勾选 chip：1px 半透明描边 + 圆角 5）
        hover  → @hoverBackgroundColor
        checked→ @accentPrimary20Solid 底 + @accentPrimary 描边（当前位置一眼可见）
```

- 一个 `QButtonGroup` 横跨所有分组 → 同时只有一项 checked；点已选中项仍重发 `section_pressed`（底部栏齿轮依赖，见 `docs/技术实现/设置面板概述.md`）。
- **保持旧 API**，所以分页连线一行没动：`section_pressed` / `addHeader` / `addSection` / `section_items` / `setCurrentSection`。
- 导航条与页面区共用同一片凹陷底（`#ConfigPanel`），卡片浮在上面 → 不再需要"导航条与页面区的分隔线"这件事。
- 契约与回归由 `tests/test_config_nav_rail.py` 钉住（分组数 / 项数 / 点选切页 / 唯一选中 / 重发语义 / `focusOn*`）。

**被否掉的候选**（留档，别再回头试）：给树加组标题胶囊条 / 选中态改实底 / 只调导航条底色——前两条仍要跟 `QTreeView::item` 那套规则缠斗（族性/悬停/选中三条规则互相覆盖），第三条只解决"导航与页面糊在一起"。**只要还是列表就在这个坑里**，所以整控件换掉。

## 3. 页面内分节：从裸标题改成卡片

### 3.1 旧样子

- 分节标题 = 一行 13pt 粗体 `QLabel`（`ui/custom_widget/section_header.py::ConfigSectionHeader`，已退出设置页），**无边框、无底色、无分隔线**，内边距 `(16, 8, 16, 4)`。
- 该控件的 docstring 明写「intentionally lightweight (no background, no border)」——轻量是有意的，但在有 5~6 个节、每节 2~9 行的页面上，节与节之间**只剩粗体 + 上方 8px 空隙**两个信号，扫读时找不到锚点。
- 正文行字号与标题同为 13pt（只差字重），标题与表单行在视觉上属于同一层。

### 3.2 仓库里已有的「分组」形态（卡片化的素材）

| 形态 | 实现 | 用法 |
| --- | --- | --- |
| 带标题分组框 | `ui/custom_widget/view_panel.py::PanelGroupBox`（QSS 规则 `PanelGroupBox`） | **分节卡就复用它**（`compact` 变体）；模型管理页/临时工作台页的页框也用它 |
| 浅边框容器 | `ui/custom_widget/group_frame.py::GroupFrame` | 快捷菜单页预览区、若干对话框 |
| 区块胶囊条 | `ui/custom_widget/view_panel.py::ExpandLabel`（`capsule=True`） | 画布右栏面板的区块标题 |

### 3.3 每页分节数（卡片化的实际负担）

| 页面 | 卡数 | 分节（中文 / 英文源串） | 每节行数 |
| --- | --- | --- | --- |
| 模型管理 | 3 | 模型加载 / Model Loading；管理 / Management；模型文件 / Model Files | 2；3；表格 + 动作行 + 状态条 |
| 项目 | 4 | 启动 / Startup；输出 / Output；备份 / Backup；临时项目 / Temporary Projects | 1；4；1；1 |
| 嵌字 | 6 | 默认字体格式 / Default Font Format；字体 / Fonts；文本格式 / Text formatting；文本格式预设 / Text Format Presets；快捷符号面板 / Quick Symbol Palette；竖排文本 / Vertical Text | 5（两行网格）；2；3；1 提示 + 4；2；8（含 4 个子行） |
| 界面 | 3 | 外观 / Appearance；画布 / Canvas；原文对照 / Original Compare | 1；9（+1 子行）；1 |
| 应用 | 4 | 更新 / Updates；外部编辑器 / External Editor；工作台提示 / Workbench Prompts；导入导出 / Import / Export | 3 + 1 警告行；1（两行布局）；2；3 |
| 工作台 | 1 | 批量任务 / Batch Tasks | 2 |

| 快捷菜单 | — | 无分节卡：工具卡 → 分隔线 → 预览框 → 命令调色板 → 画布选项调色板 | 页内已有自绘容器 |
| LLM 配置 | — | 无分节卡：工具栏 + 卡片列表；卡片内部另有「连接信息 / 通用参数 / 三个能力分节」 | 卡片形态，未纳入 |
| 管线 | 每标签 1~2 | 各标签内：分节卡「参数 / Parameters」（`ui/module_parse_widgets.py::ModuleConfigParseWidget`），翻译器标签另有「API Profile」卡（排在参数卡之前） | 参数行数随模块变；API Profile 1 行 |

> 设置面板是固定 1000×700 的模态浮层（`ui/overlay_modal.py` 的 `_PANEL_W` / `_PANEL_H`）——嵌字页（6 卡 / 约 24 行）与应用页（5 卡）是高度最紧的两页，卡片间距因此收在 10px。

### 3.4 定案：分节卡 + 凹陷工作面（已实现）

- **一个分节 = 一张 `PanelGroupBox`（`compact` 标题）**，行物理上在卡里；构建入口 `ui/configpanel.py::_section_body`（用法见 `docs/基础速查/设置面板排版思路.md` §2.2；它现在只是 `ui/custom_widget/view_panel.py::add_section_card` 的薄封装，管线面板也要建卡、又不能反向 import `ui/configpanel.py`）。21 处旧标题全部换成它，另加模型文件节、快捷键页 8 组、以及 2026-09-21 补上的管线四个标签（「参数」+ 翻译器的「API Profile」）。
- **浮起不靠投影**：`QGraphicsEffect` 在本仓有两处实测坑（Python 子类化的 effect 在虚拟回调里抛异常会被 PyQt 答以 `qFatal`；`QGraphicsOpacityEffect` 进 `QScrollArea` 毁渲染缓存）——卡片浮起改用**三层色调**：面板与页面底 `@emptyContentBackgroundColor`（凹）+ 卡片 `@widgetBackgroundColor`（浮）+ 1px `@borderColor` 描边，卡片之间露出的凹陷色就是"阴影槽"。
- 顺带退役的旧件：`#CompactDelegationFrame`（嵌字页「默认字体格式」节内框，卡片已提供框）、`#ConfigNavList`（旧导航）、设置页与管线标签页里的全部 `ui/custom_widget/section_header.py::ConfigSectionHeader` 调用。**该类现无应用内调用者**（只剩 `scripts/style_showcase.py` 的展示行），2026-09-21 决定留作控件库原语、不删；下次审计要收就删类 + 展示行 + 导出三处。
- 契约由 `tests/test_config_section_cards.py` 钉住（每页卡数 / 卡不空 / 行在卡内 / 子行显隐语义 / 管线标签页也套卡），描边与凹陷归 `tests/test_config_card_painting.py`（含管线阶段面板不得画底色一条）。

**被否掉的候选**：只加细线分隔（密集表单里像表格行分隔线）、只调字号字重（治标，多节页仍糊）、给每节加投影（见上）。
