### 2026-07-12 — P1#6 LLM 配置独立页面（方案 A：内联表单）

**背景：** 卡牌 UI 尝试被用户撤回后，协商确定方案 A：将 `ProfileManagerDialog` 的编辑表单搬到页面内，左右 splitter 改为顶部工具栏 + 全宽表单。

**改动文件：**
- `utils/profile_manager.py` — 新增 `ProfileManagerWidget`（QWidget）：
  - 顶部工具栏：`QComboBox` 切换 profile + [+ Add] [Delete] [Restore Builtins] 按钮
  - `QScrollArea` 内含 4 组编辑表单（Basic Settings / Connection & Rate Limiting / Translation Settings / OCR Settings）
  - 自动保存：切换 profile / 添加 / 删除 / 离开页面时落盘
  - 发出 `profiles_changed` 信号
- `ui/configpanel.py` — 占位页替换为 `ProfileManagerWidget`；连接信号；移除 `_open_profile_manager`（死方法）

**布局对比：**
| 方案 | 结构 | 优点 | 缺点 |
|------|------|------|------|
| 原 dialog | 左右 splitter（220px 列表 + 表单） | 列表直观 | 页面宽度 ~520px 塞不下 |
| 方案 A（当前） | 顶部 combo 工具栏 + 全宽表单 | 横向空间充分利用 | 切换 profile 需要展开 combo |

**涉及文件：** `utils/profile_manager.py`、`ui/configpanel.py`
