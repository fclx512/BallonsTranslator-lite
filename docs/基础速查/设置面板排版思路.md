# 设置面板排版思路

> 给未来维护 AI 的参考：本项目设置面板从“堆叠卡片”改为“两列表单”后的布局约定。
> 形成于 2026-08-13 对项目 / 界面 / 模型 / 嵌字 / 应用 5 个设置页的统一重构。

---

## 1. 核心原则：把设置页当成表单，而不是卡片堆

旧模式的问题：

- 每个选项用一个 `ConfigSubBlock(name=..., widget)` 垂直堆叠，标签在控件上方。
- 结果是空白大、控件左边缘不齐、复选框像“标题 + 选项”两段文字。
- 不同控件（下拉框、输入框、复选框）各自为政，视觉上松散。

新模式的核心：

- **左列标签，右列控件**，所有控件从同一条竖线开始。
- **标签固定宽度**（默认 110px），右对齐，带 `?` 帮助按钮时仍对齐。
- **章节头只负责分组**，不再承载说明；说明放到 `?` 气泡里。
- **垂直间距压紧**，但保留可读性。

---

## 2. 使用 `ConfigFormRow` 和 `_section_header`

在 `ui/configpanel.py` 中已经封装好两个辅助：

### 2.1 `ConfigFormRow`

```python
ConfigFormRow(
    label: str,          # 左列标签；不需要标签时传 ""
    widget: QWidget,     # 右列控件
    note: str = None,    # 可选帮助说明（会渲染为右侧 ? 按钮）
    label_width: int = 110,
)
```

约定：

| 场景 | 写法 |
|------|------|
| 下拉框/输入框/按钮 | `ConfigFormRow(self.tr("标签"), 控件, note=...)` |
| 单个复选框（本身就是完整描述） | `ConfigFormRow("", 复选框, note=...)` |
| 子选项需要缩进 | 用空标签 + 外部 wrapper 设置左外边距 |

示例：

```python
# 下拉框
self.rst_imgformat_combobox = ConfigComboBox(scrollWidget=self)
self.rst_imgformat_combobox.addItems(["PNG", "JPG", "WEBP", "JXL"])
project_layout.addWidget(
    ConfigFormRow(
        self.tr("Result image format"),
        self.rst_imgformat_combobox,
        note=self.tr("<p>输出格式说明...</p>"),
    )
)

# 复选框
self.seq_badge_checker = ConfigCheckBox(self.tr("Show sequence number on text blocks"))
interface_layout.addWidget(
    ConfigFormRow(
        "",
        self.seq_badge_checker,
        note=self.tr("<p>序号徽标说明...</p>"),
    )
)
```

### 2.2 `_section_header`

```python
config_mgmt_layout.addWidget(_section_header(self.tr("Updates")))
```

- 等价于 `ConfigSectionHeader`，但上下 margin 减半（`16, 8, 16, 4`）。
- 仅用于页面内分节，不要把说明文字写进章节头。

## 3. 页面容器约定

每个设置页用一个 `QWidget` + `QVBoxLayout`：

```python
page_widget = QWidget()
page_layout = QVBoxLayout(page_widget)
page_layout.setContentsMargins(0, 0, 0, 0)
page_layout.setSpacing(0)
```

`ConfigFormRow` 和 `_section_header` 自身已经带了合适的内边距，页面容器不要再额外加间距。

---

## 4. 控件宽度约定

按输入类型固定宽度，避免无意义拉伸：

| 控件类型 | 推荐宽度常量 | 例子 |
|----------|-------------|------|
| 短数字 / 百分比 / 复选框 | `CONFIG_COMBOBOX_SHORT` | 质量、不透明度预设 |
| 中等枚举下拉框 | `CONFIG_COMBOBOX_MIDEAN` | 动画 FPS、预设值输入框 |
| 长文本下拉框 | `CONFIG_COMBOBOX_LONG` | 标点位置、竖排拉丁长度 |
| 按钮 | 不固定，按内容自适应 | 导出配置、卸载模型 |

如果控件是 `QLineEdit` 等会拉伸的，手动 `setFixedWidth(...)`，不要依赖 `addStretch()` 推过去。

---

## 5. 子选项缩进

子选项（如“同样应用于横排文本”）需要与父选项的控件列对齐。

`ConfigFormRow` 内部结构：

```
| 16px 左 margin | 110px label | 8px 间距 | 控件 | ... |
```

所以控件左边缘距离行外边缘是 `16 + 110 + 8 = 134px`。子选项 wrapper 的左外边距应设为 134px：

```python
halfwidth_horizontal_wrapper = QWidget()
halfwidth_horizontal_wrapper.setContentsMargins(134, 0, 0, 4)
hw_layout = QHBoxLayout(halfwidth_horizontal_wrapper)
hw_layout.setContentsMargins(0, 0, 0, 0)
hw_layout.addWidget(self.halfwidth_horizontal_checker)
hw_layout.addStretch()
ts_layout.addWidget(halfwidth_horizontal_wrapper)
```

如果更改了 `ConfigFormRow.label_width`，这里要同步改。

---

## 6. 特殊：网格布局仍可用

当一组相关控件数量多、按两列排布更节省空间时（如“默认字体格式”的 5 个下拉框），可以保留 `QGridLayout`：

- 外层容器用 `ConfigSubBlock(..., content_margins=(16, 4, 16, 4))` 保持与 `ConfigFormRow` 对齐。
- 网格内部的水平/垂直间距设为 8~16px，不要太散。
- 不要把章节标题已有的说明再重复写成一段 label。

## 7. i18n 注意事项

- 所有 UI 文字必须包在 `self.tr(...)` 里。
- **`self.tr()` 参数必须是单个字符串字面量**，不要跨多行做隐式拼接（如 `"part1 " "part2"`）。`scripts/i18n_check.py` 识别不了这种拼接，会报缺失或孤儿。
- 长说明可以换行，但必须是**一个完整字符串字面量**：

```python
# 正确
note=self.tr(
    "<p>这是一段很长的说明，可以换行写，但仍然是一个字符串。</p>"
),

# 错误
note=self.tr(
    "<p>这是第一段 "
    "这是第二段</p>"
),
```

- 新增/修改字符串后执行：

```bash
python scripts/qm_compile.py translate/zh_CN.ts translate/zh_CN.qm
python scripts/i18n_check.py
```

## 8. 反模式

| 反模式 | 问题 | 正确做法 |
|--------|------|----------|
| `ConfigSubBlock(checkbox, name="标题")` | 标签和复选框文字分离，像两段说明 | `ConfigFormRow("", checkbox, note=...)` |
| `ConfigSubBlock(widget, name="标签")` + `vertical_layout=True` | 标签在上、控件在下，空隙大 | `ConfigFormRow("标签", widget, note=...)` |
| 输入框 `addStretch()` 撑满 | 长输入框不整齐 | 给输入框固定宽度 |
| 章节头里塞说明文字 | 视觉噪音 | 说明放到 `?` 气泡 |
| 每个选项一个 `ConfigSectionHeader` | 标题过多、留白过多 | 相关选项归到同一 section |

---

## 9. 快速修改清单

向设置面板新增一项时：

1. 找到目标 section，没有就 `_section_header(...)` 新建一个。
2. 用 `ConfigFormRow` 包裹控件；复选框用空标签。
3. 需要说明时传 `note=`，不要写死 label 描述。
4. 给输入类控件设固定宽度。
5. 在 `translate/zh_CN.ts` 的 `ConfigPanel` context 添加对应条目。
6. 编译 qm 并跑 `i18n_check.py`。
