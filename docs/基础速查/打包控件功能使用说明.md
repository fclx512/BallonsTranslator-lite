## 样式生效机制：全局兜底 vs 类名选择器

`config/stylesheet.css` 有两套生效机制，决定了"写 Qt 原生类会不会掉样式"：

**1. 全局类型选择器兜底** —— 写 Qt 原生类就自动生效，无需封装类：
`QPushButton`、`QRadioButton`、`QMenu`、`QTabBar`、`QScrollBar`（所有滚动条）、
`QListWidget`/`QTreeView`（含 item 选中态）、`QToolTip`、`QSplitter`、`QProgressBar`，
以及 `QComboBox`/`QLineEdit`/`QPlainTextEdit` 的基础款（直角边框）。这些随手写也不会错。

**2. 类名/objectName 选择器** —— 只匹配封装类名，写原生类会**静默掉样式**
（不报错、能跑，只是和全应用风格不一致）。输入类控件必须用封装类：

| 场景 | 必须用 | 原生写法的后果 |
|------|--------|---------------|
| 下拉框 | `ui/custom_widget/combobox.py::ConfigComboBox` / `ui/custom_widget/combobox.py::ParamComboBox` / `ui/custom_widget/combobox.py::SmallComboBox` | 得到基础款直角样式，与圆角输入风格不符；且无防滚轮误触 |
| 数字/浮点输入 | `ui/custom_widget/spinbox.py::NoArrowsSpinBox` / `ui/custom_widget/spinbox.py::NoArrowsDoubleSpinBox` | **完全无 QSS 规则** → Windows 原生箭头，深色主题下突兀 |
| 单行输入 | `ui/custom_widget/text_input.py::ConfigLineEdit` | 只有基础款边框，非圆角输入款 |
| 多行输入 | `ui/custom_widget/text_input.py::ConfigTextEdit` | `QTextEdit` 无任何全局规则（全局规则只覆盖 `QPlainTextEdit`）→ 完全原生外观 |
| 复选框 | `ui/custom_widget/checkbox.py::ConfigCheckBox`（自动设 objectName） | 指示器走原生渲染（`QDialog` 内有 catch-all 兜底，对话框外没有） |
| 分组/容器/分隔线 | `ui/custom_widget/group_frame.py::GroupFrame` / `ui/custom_widget/widget.py::SeparatorWidget` / `ui/custom_widget/widget.py::Widget` | 无边框无圆角 |

**原则：新建输入类控件一律 `from ui.custom_widget import …`，不要直接实例化
`QComboBox`/`QSpinBox`/`QLineEdit`/`QTextEdit`。** 封装类名即 QSS 选择器名，
可对照 `config/stylesheet.css` 确认样式是否命中。

**目视工具**：`scripts/style_showcase.py`（仓库根目录运行，或直接双击
`scripts/style_showcase.bat`）——Tab1 原生 vs 封装对照，Tab2 按「用在哪个面板」分区的
全部控件（封装类 + 应用层复合控件）。
每行带**样式来源徽章**（类名 / objectName / 自绘 / 内联 / 全局兜底 / 无规则）
与 `路径::符号`，一键复制；顶部搜索框 + 左侧目录跳转，可按样式来源筛选，
支持亮/暗主题切换与状态矩阵（正常 / 禁用 / 悬停 / 聚焦）。看到不顺眼的控件，
复制那一行的 `路径::符号` 即可直接指定优化目标。

新增控件时在该脚本 `_sections()` 对应分区的 rows 列表追加一行
`Row(说明, "路径::符号", 工厂函数)`；无法离线实例化的控件登记到文件中部
`EXCLUDED` 字典（会渲染成「未纳入展示」分区）。`scripts/check_showcase.py`
（已并入 `scripts/verify.py` 每次执行）会比对 `ui/custom_widget/__init__.py`
导出清单与展示/排除名单，新增导出而没登记即失败。

## 核心模式

### 模式 A：ConfigSubBlock 禁用自动变灰

`ConfigSubBlock`（`ui/configpanel.py::ConfigSubBlock`）的 `changeEvent` 在禁用时自动将 `name_label` 文字变灰（`@disabledForegroundColor`），启用时恢复。

```python
# 禁用 — label 自动变灰，子控件 Qt 自带禁用渲染
some_sublock.setEnabled(False)
```

无需额外写 stylesheet。`?` 帮助按钮不受影响。

### 模式 B："—" 占位符

禁用数值字段时用 "—" 替代数值，表明"不适用"：

```python
field_widget.blockSignals(True)
field_widget.setText("—" if not enabled else restore_value)
field_widget.blockSignals(False)
```

必须 `blockSignals` 防止 textChanged 触发持久化。

### 模式 D：主题色取值

`get_theme_color(key)`（`ui/misc.py`）从当前主题解析任意 `@variable` 颜色：

```python
from ..misc import get_theme_color
success = get_theme_color(key="@successColor")
label.setStyleSheet(f"color: {success.name()};")
```

常用 key：`@successColor` / `@warningColor` / `@dangerColor` / `@accentPrimary` / `@borderColor`。该函数自动切换 dark/light 主题。

### 模式 E：Blender 式拖拽调值的两个特例

`NoArrowsSpinBox`/`NoArrowsDoubleSpinBox`/`SizeComboBox` 的默认交互是「箱体直拖 + 拖拽中静默改显示、松手经 `drag_finished` 提交一次」。按下区由 `DragAdjustMixin` 挂在内部 `lineEdit` 的事件过滤器上（`_install_drag_edit_proxy()`）——数值框的编辑区几乎铺满整个控件，鼠标按下先落到 `QLineEdit` 子控件、不会冒泡到宿主，只重载 `mousePressEvent` 的话只有边框那几像素能拖，其余区域仍是原生的文本选区行为。两处数值网格没有直接沿用默认形态：

- 变换面板 `ui/text_engine/transforms/panel.py::CommittedTransformControl`：「label 拖拽 + 画布实时预览 + 松手提交」的独立状态机——拖拽中途即更新模型，预览不进撤销栈。
- 效果卡 `ui/text_engine/effects/cards.py::EffectNumericControl`：「箱体直拖 + 实时预览 + 松手提交」（2026-09-08 起），label 退为纯描述文本。

`PageRangeSpinBox` 不在其列：它右端有 chevron 步进按钮、按下区已被按钮占用，页码是离散序号，拖动调值没有意义。

### 画布浮层面板：RailDockPanel vs FloatDropPanel

**`RailDockPanel`**（`ui/custom_widget/rail_dock_panel.py`）——画布区浮层面板，主窗口内子控件：

- 展开硬连接锚定窄栏左侧：右缘 + 顶部固定，宿主缩放/窄栏移动自动重锚；
- 左下角手柄拉伸，尺寸下限随内容布局；
- Esc/× 关闭、不自动关；开合记忆在 `pcfg`。

**`FloatDropPanel`**（`ui/custom_widget/float_drop_panel.py`）——按钮锚定下拉浮层（`ui/global_search_widget.py` 格式条件用）：

- 宿主为 `window.centralWidget()`（打开时惰性解析），左缘钉在锚点所在侧栏右缘、向画布方向按内容展开；
- 不参与布局、不撑宿主最小尺寸；内容自带滚动；
- Esc/×/再点锚点关闭；无开合记忆、无拉伸手柄；QSS 复用 `RailDock*` objectName。

选型：需要开合记忆与拉伸的常驻面板用 `RailDockPanel`；轻量下拉浮层用 `FloatDropPanel`。

## 新增原则

1. 优先考虑能否在现有类中通过 `changeEvent` / CSS 等方式自动处理
2. 若无法自动，再考虑辅助方法或独立函数
3. 新控件添加到 `ui/custom_widget/`，在 `__init__.py` 导出，并在上表追加一行
4. 同步在 `scripts/style_showcase.py` 的 `_sections()` 追加展示行（无法离线展示的在 `EXCLUDED` 字典登记原因）；`scripts/check_showcase.py` 会校验，漏登记即失败
