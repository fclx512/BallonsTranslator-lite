# 新增设置项路线参考

> AI 快捷参考：如何向应用添加一个由配置控制的显隐/开关设置项。
> 基于 2026-06-30 新增"文本框序号徽标开关"的实际工作路线抽象而来。
> 各节按实施顺序排列。

---

## 路线全景（5 层）

```
Config (数据层) → Render (渲染层) → UI (控件层) → Signal (通信层) → i18n (翻译层)
```

每层只触及一个文件，按序推进，互不绕回。

---

## 1. 数据层 — `utils/config.py`

在 `ProgramConfig` 类末尾（其他 display 类偏好后）添加字段，默认值设为 `True`（除非用户另有要求，否则保持现有行为）：

```python
# 注释：默认 True = 不影响旧用户
show_seq_badge: bool = True
```

**定位：** `ProgramConfig` 类在约 L136-229。新增字段接在最后一个开关之后。

**原则：** 不要在已有字段中间插行，避免 merge 冲突。统一放在类尾。

---

## 2. 渲染层 — `ui/textitem.py`（或实际绘制文件）

### 2.1 找到绘制位置

用 Grep 搜目标功能的绘制调用点。关键词试：
- 中文搜索：`序号`、`徽标`、`顺序`
- 英文搜索：`badge`、`seq_badge`、`index`、`order`

### 2.2 修改守卫条件

```python
def _draw_seq_badge(self, painter: QPainter):
    from utils.config import pcfg  # 懒加载，避免循环导入
    if self._hide_badge or not pcfg.show_seq_badge:
        return
```

**原则：** 用 `from utils.config import pcfg` 懒导入（参照 textitem.py 内已有的多处调用模式），不在文件顶 import。

### 2.3 连带确认 canvas 渲染路径

`canvas.py` 中 `grab_screenshot` 等方法会用 `item._hide_badge = True` 临时隐藏徽标。新增的 `pcfg.show_seq_badge` 是**永久层**，`_hide_badge` 是**临时层**，两者是 OR 关系——各自独立工作，互不冲突。

## 3. 控件层 — `ui/configpanel.py`

### 3.1 找到目标 Section

Interface 区在 `__init__` 中构造约 L1812-1937，末尾还有 stretch。新增项插在 Original Compare toggle 之后、`self.interface_block` 注册之前。

### 3.2 添加 CheckBox

按现有模式三步走：

```python
# a) 创建 checkbox
self.seq_badge_checker = QCheckBox(
    self.tr("Show sequence number on text blocks")
)
self.seq_badge_checker.setChecked(pcfg.show_seq_badge)
self.seq_badge_checker.stateChanged.connect(self.on_seq_badge_changed)

# b) 包裹 ConfigSubBlock
seq_badge_sublock = ConfigSubBlock(
    self.seq_badge_checker, name=self.tr("Sequence Badge"),
    note=self.tr("Displays the block sequence number at the top-left corner "
                 "of each text block on the canvas. Disable to avoid occlusion "
                 "when working with small fonts."),
)

# c) 加入 layout
interface_layout.addWidget(seq_badge_sublock)
```

**原则：** 设置面板统一按“两列表单”排布，优先使用 `ConfigFormRow`；旧模式 `ConfigSubBlock(name=..., widget)` 仅在需要非表单布局时保留。详见《设置面板排版思路》。

如果确实需要用 `ConfigSubBlock`，有备注说明时传 `note=` 参数。

### 3.3 添加槽函数

```python
def on_seq_badge_changed(self):
    pcfg.show_seq_badge = self.seq_badge_checker.isChecked()
    self.seq_badge_changed.emit()  # 通知 MainWindow 刷新画布
```

### 3.4 添加 Signal

```python
class ConfigPanel(Widget):
    # ...
    seq_badge_changed = Signal()
```

## 4. 通信层 — `ui/mainwindow.py`

### 4.1 导入 TextBlkItem

```python
from .textitem import TextBlkItem
```

### 4.2 连接 Signal

```python
self.configPanel.seq_badge_changed.connect(self._on_seq_badge_changed)
```

放在 `setupUi()` 末尾其他 config 连接之后（~L586）。

### 4.3 编写 Handler

```python
def _on_seq_badge_changed(self):
    """Force canvas text items to repaint so seq badge appears/disappears."""
    if not self.canvas:
        return
    for item in self.canvas.textLayer.childItems():
        if isinstance(item, TextBlkItem):
            item.update()
```

**说明：** `pcfg.show_seq_badge` 已在 ConfigPanel 槽中立即更新。只需让画布上的 `TextBlkItem` 重绘即可使 `_draw_seq_badge` 重新检查新值。

## 验证清单

| 检查项 | 方法 |
|--------|------|
| i18n 无硬编码中文 | `i18n_check.py` 第一行报 "None found" |
| i18n 无缺失条目 | `i18n_check.py` 只出现预存孤儿/格式描述串 |
| qm 可编译 | `qm_compile.py` 输出 `Compiled N translations` |
| 预设 `True` 不影响旧用户 | 新建 config.json 无需手动开启 |
| 开关即时生效 | 切关→画布徽标立即消失；切开→立即出现 |
| 保存落盘 | 关面板后 `config.json` 含 `"show_seq_badge": false` |
| 导出图不沾开关 | `canvas.py` 的 `_hide_badge` 临时层独立工作 |
