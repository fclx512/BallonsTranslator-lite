# 备注演示动画使用说明

设置页问号备注弹层（`ui/configpanel.py::ConfigNotePopup`）支持在文字上方播放一段**代码生成的演示动画**，用于纯文字讲不清的操作类说明（如下拉切换后的视觉效果变化）。首个实例是「标点位置」备注（`anim="punctuation_position"`）。本文是该流程的参考，新增功能动画照此走。

## 适用判断

不是所有备注都值得配动画，按信息形态选载体：

- **纯文本够用**：概念解释、布尔开关类选项（开关本身在页面上就有即时反馈）——保持现状，不加动画。
- **静态左右对比就够**：效果是"两个状态的差异"且差异一眼可读（如画布块序号开关）——理想载体是一张两栏对比图。**该形态尚未实现**，做之前先在本文档补设计；当前可临时用动画的"定格两帧"替代。
- **需要动画**：效果有"过程"（移动、展开、飞入）或操作有"步骤"（打开下拉 → 选择 → 生效）——按下方管线做。

动画是烘焙像素，**内嵌文字不走 i18n**，统一直书中文（本 fork 的主要受众）。

## 一个动画 = 三件套

1. **场景**：`scripts/gen_help_anim.py::SCENES` 里注册一个 `QWidget` 子类，负责画整段演示。
2. **产物**：`config/help_anims/<key>.webp`，无损动画 WebP，随仓库分发。
3. **挂载**：对应设置项的 `ConfigSubBlock`/`ConfigFormRow` 加 `anim="<key>"`，问号弹层自动在文字上方播放。

## 制作管线（scripts/gen_help_anim.py）

运行：

```bash
./ballontrans_pylibs_win/python.exe scripts/gen_help_anim.py --scene <key> [--dump-frames DIR]
```

编写新场景的规则：

- **帧号确定性步进**：所有动画状态（光标位置、下拉展开度、标点位移……）在 `set_state(帧号)` 里按帧号推算，不依赖真实时钟——产物可复现，界面改版后重跑脚本即再生成。缓动用模块内的 `out_cubic`。
- **样式复用真实实现**：主进程里 `app.setStyleSheet(ui/misc.py::parse_stylesheet(...))` + 用户主题，组合框等直接用 `ui/custom_widget` 封装控件，保证与设置页观感一致；取主题色用 `ui/misc.py::get_theme_color`。
- **置顶覆盖层**：光标/下拉列表等要盖在真实子控件上的元素，画在一个透明覆盖子 widget 上（见 `scripts/gen_help_anim.py::PunctuationScene` 的 `_paint_overlay`）。**覆盖层必须显式 `setStyleSheet("background: transparent;")`**——裸 `QWidget` 会被全局 QSS 的 `QWidget { background-color }` 规则填实，把下面的控件全盖住。
- **竖排/标点类场景**：标点两种摆放的权威规则在 `ui/text_engine/vertical_layout.py::updateDrawOffsets`（居中 = 字符框正中；靠边 = 墨迹贴字符框右上角；`！？：；` 两种模式都居中），照它画，不要凭感觉。
- **文字逐字定位**：`QFontMetricsF.tightBoundingRect` 取墨迹框，`drawText` 的参数是**基线坐标**（目标墨迹左上角减去墨迹偏移，**只减一次**——重复减会导致整列字下坠错位，首个场景踩过）。
- **offscreen 字体坑**：`QT_QPA_PLATFORM=offscreen` 平台不读系统字体注册表，必须同时设 `QT_QPA_FONTDIR=C:/Windows/Fonts`，否则中文全是豆腐块（脚本已内置）。
- **编码参数**：Pillow `save(..., lossless=True, method=6, loop=0, exact=True)`。纯色 UI 内容下无损 WebP 连 GIF/MP4 都小（实测 33 帧 460×262 ≈ 40 KB，调研数据见 `scripts/README.md` 该脚本的登记行）；有损 WebP 在平坦色块上反而是负优化，不用。

## 接入（ui/configpanel.py）

- 动画落盘路径由 `ui/configpanel.py::_help_anim_path` 解析（`config/help_anims/<key>.webp`），文件缺失时弹层静默跳过动画，不影响纯文本。
- 数据流：`ConfigSubBlock(note=..., anim=...)` / `ConfigFormRow(note=..., anim=...)` → `ui/configpanel.py::_make_note_btn` → `ConfigNotePopup(anchor, text, anim_path)`。目前只有标点位置挂了 `anim`，其余备注保持纯文本。
- 播放行为：无限循环（loop 写在 webp 元数据里）；弹层关闭即停（`ConfigNotePopup.hideEvent`）；全局动画关闭（`pcfg.animation_fps < 0`）时只显示静态首帧。

## 验收

1. `--dump-frames` 导出逐帧 PNG，重点核对：文字无豆腐块、动效起止状态正确（如居中帧 vs 靠边帧）、无控件重叠裁剪、光标轨迹自然。
2. 真机点问号确认弹层内播放、关闭即停。
3. `scripts/verify.py` 全绿（改 `ui/configpanel.py` 会自动触发启动冒烟）。
