# 配置导入导出指南

## 功能入口

设置面板 → General → **配置管理**

## 导出配置

导出当前 `pcfg`（`ProgramConfig`）为 `.json` 文件。

### 导出选项

| 选项 | 默认 | 说明 |
|------|------|------|
| 导出时排除 API 密钥 | 勾选 | `model_profiles` 中的 `api_key` 和 `proxy` 字段被置空，保留结构 |

### 导出格式

```json
{
  "_export_meta": {
    "version": 1,
    "app_version": "0.3.0",
    "exported_at": "2026-07-17T12:00:00",
    "excluded": [
      "module.model_profiles[].api_key",
      "module.model_profiles[].proxy"
    ]
  },
  "module": { ... },
  "global_fontformat": { ... },
  "shortcuts": { ... },
  ...
}
```

- `_export_meta` 记录导出元信息（版本、时间、排除项），导入时用于兼容性判断。
- 其余字段与 `config/config.json` 结构一致。

### 敏感信息

默认导出会剔除 `model_profiles` 中每个 profile 的 `api_key` 和 `proxy` 字段（保留其他所有字段）。取消勾选「导出时排除 API 密钥」可包含原始凭证，**不建议用于分享场景**。

## 导入配置

从之前导出的 `.json` 文件恢复配置。

### 导入流程

1. 选择 `.json` 文件
2. 系统比对导出文件中的 key 与当前 `ProgramConfig` schema
3. 显示兼容摘要对话框：
   - ✅ 成功匹配的项目
   - ⚠️ 导出中有但当前 schema 没有的 key（来自未来版本，将被静默忽略）
   - ℹ️ 当前 schema 有但导出中没有的 key（保持当前值不变）
4. 确认后合并到 `pcfg` 并自动保存
5. 关闭并重新打开设置面板以刷新界面

### 兼容性机制

| 场景 | 行为 |
|------|------|
| 相同版本导入/导出 | 全部字段匹配 |
| 新版导出 → 旧版导入 | 未知 key 被 `@nested_dataclass` 静默忽略 |
| 旧版导出 → 新版导入 | 缺失字段取当前默认值 |

未来在 `ProgramConfig` 中增删字段时，导入功能会自动报告差异，无需修改导入代码。

## 技术实现

### 关键函数

| 函数 | 位置 | 作用 |
|------|------|------|
| `export_config()` | `utils/config.py` | 序列化 + 过滤 + 原子写入 |
| `import_config()` | `utils/config.py` | 读取 + schema 比对 + 合并 + 保存 |
| `_compare_export_schema()` | `utils/config.py` | 递归比对导出 JSON 与当前 schema |

### 过滤逻辑

```python
EXPORT_SENSITIVE_KEYS = {"api_key", "proxy"}
```

遍历 `module.model_profiles` JSON 数组，将每个 profile 中的敏感 key 置空。

### 写入安全

复用 `save_config()` 的原子写入模式：`.tmp` + `os.replace()`。

### 配置文件导入后

`import_config()` 调用 `pcfg.merge(constructed)` 合并，然后调用 `save_config()` 持久化。UI 需重新打开设置面板以刷新显示。
