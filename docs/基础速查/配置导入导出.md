# 配置导入导出指南

## 功能入口

设置 → 应用 → **导入导出**

## 导出配置

导出当前 `pcfg`（`ProgramConfig`）为 `.json` 文件。

### 导出选项

| 选项 | 默认 | 说明 |
|------|------|------|
| 导出时排除 API 密钥 | 勾选 | 清空模型配置和引擎参数里的密钥、轮换密钥和代理，保留其他字段 |

### 导出格式

```json
{
  "_export_meta": {
    "version": 1,
    "app_version": "0.3.0",
    "exported_at": "2026-07-17T12:00:00",
    "excluded": [
      "module.model_profiles[].api_key",
      "module.model_profiles[].proxy"
    ]
  },
  "module": { ... },
  "global_fontformat": { ... },
  "shortcuts": { ... },
  ...
}
```

- `_export_meta` 记录导出元信息（版本、时间、排除项），导入时用于兼容性判断。
- 其余字段与 `config/config.json` 结构一致。

### 敏感信息

默认导出会检查现行模型配置、旧模型配置和引擎参数中的凭证。模型配置无法解析时，脱敏导出会失败。取消勾选「导出时排除 API 密钥」会保留原始凭证。

## 导入配置

从之前导出的 `.json` 文件恢复配置。

### 导入流程

1. 选择配置 JSON。程序比对字段后立即应用并保存。
2. 保存成功后，摘要列出不识别的字段和文件里缺少的字段。
3. 关闭并重新打开设置面板，查看导入结果。

文件里缺少的字段按当前版本的默认值构造。当前界面的摘要仍称这些字段保留原值，实际导入时可能重置。

导入带 `model_profiles` 的文件会替换当前的模型配置列表。导入默认脱敏的导出文件时，空的密钥和代理值也会写入。

### 兼容性机制

| 场景 | 行为 |
|------|------|
| 相同版本导入/导出 | 全部字段匹配 |
| 新版导出 → 旧版导入 | 未知 key 被 `@nested_dataclass` 静默忽略 |
| 旧版或部分配置导入 | 缺失字段取当前版本默认值 |

未来在 `ProgramConfig` 中增删字段时，导入功能会自动报告差异，无需修改导入代码。

## 技术实现

### 关键函数

| 函数 | 作用 |
|------|------|
| `utils/config.py::export_config` | 序列化、过滤与原子写入 |
| `utils/config.py::import_config` | 读取、比对字段、合并与保存 |
| `utils/config.py::_compare_export_schema` | 递归比对导出 JSON 与当前配置结构 |

### 过滤逻辑

```python
EXPORT_SENSITIVE_KEYS = {"api_key", "multiple_keys", "proxy"}
```

过滤只作用于导出的数据副本。排除字段记录在导出元信息中。

### 写入安全

导出使用临时文件和 `os.replace()` 写盘。导入经 `utils/config.py::save_config` 写盘，保存失败时恢复本次会话的原配置并显示失败。

### 配置文件导入后

`utils/config.py::import_config` 先按当前配置类构造完整对象，再合并到当前配置。
