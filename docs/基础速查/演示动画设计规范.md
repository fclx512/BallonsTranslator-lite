# 演示动画设计规范

本文是弹层（`scripts/gen_help_anim.py`）与 README 大画幅（`scripts/gen_readme_anim.py` / `scripts/gen_readme_showcase.py`）两条演示动画流程**共用**的设计规范：检查点流程、真实控件硬约束、风格令牌与口味规则。管线机制、编码参数与验收步骤见 [备注演示动画使用说明.md](备注演示动画使用说明.md) 与 `scripts/README.md` 各登记行，本文不重复。

## 检查点流程：先审再产

审美不可控的解法不是事后返工，而是把「做完才发现难看」变成「动手前就看到」。新场景（尤其大画幅）走两道人工检查点：

1. **拍点表（写代码前，会话内确认）**：出一张表——拍点 / 帧段（尽量用 `scripts/anim_kit.py::RhythmProfile` 档位表达）/ 动作 / 字幕 / 镜头（大画幅），用户确认后再动手。拍点表是流程材料、不进仓库。
2. **风格帧小样（整段生产前）**：`--storyboard` 把关键帧渲成一张联络表 PNG（`scripts/anim_kit.py::storyboard_keyframes` = 场景全部 `F_*` 拍点 + 首尾帧；输出默认 `build/anim_storyboard/`，gitignore、用完即弃），确认构图与节奏后才 `save_webp` 整段生产。
3. 生产与验收照既有流程（`scripts/verify.py`、逐帧像素回归、真机目视）。

**技术验收与口味评审分离**：自动检查器（`scripts/check_anim_rhythm.py` / `scripts/check_anim_cursor.py`）只管硬指标；观感好坏由用户终审，agent 不自行判定「好看」。

## 硬约束：动画里的功能必须真实存在且行为正确

动画是产品的承诺，画出来的东西必须真的存在、真的这么表现：

- **交互落点必须等于真实控件几何，禁止手填像素坐标**。统一入口：`scripts/anim_kit.py::widget_scene_center`（控件）、`scripts/anim_kit.py::graphics_item_scene_rect`（画布图元）、`scripts/anim_kit.py::PopupPalette` / `scripts/anim_kit.py::PopupDropdown`（手绘弹层的布点方法）。
- **允许手绘的只有两类**：① 真实弹层（下拉列表、色板对话框）是顶层窗口、`grab()` 抓不进场景，其展开态可手绘，但必须照真实控件样式画、且**几何与落点同体**（同一对象既出绘制又出落点，即 `PopupPalette`/`PopupDropdown` 模式）；② 示意漫画页与文本块，画法照真机引擎（大画幅直接用 `ui/textitem.py::TextBlkItem`，弹层用引擎镜像常量 + 轮廓小件）。
- **引擎镜像常量不是风格自由度**：`TEXTRECT_*`、徽标底色、黄框、手柄等照抄真实 UI 的常量，改值等于画一个产品里不存在的东西。
- **行为叙事以真实实现为准**：改前/改后文案讲的是真实开关的行为差异；竖排/标点类几何照引擎规则画（见使用说明「竖排/标点类场景」节），有疑问以引擎/设置实现为准，不凭感觉。

## 风格令牌

跨场景的观感语言（颜色/圆角/字号/明暗口径）收敛在 `scripts/anim_kit.py::AnimStyle`，经 `scripts/anim_kit.py::AnimScene` 的 `style` 类属性（默认 `scripts/anim_kit.py::DEFAULT_STYLE`）下发。**场景只消费 `self.style`，禁止再手填同类散值**；要换风格覆写类属性，不改散点。

令牌不收两类值：内容几何（格子尺寸、块布局等，每场景自声明）与引擎镜像常量（见上节）。

## 口味规则

- **一拍一个信息点**。动作过程自明的（拖手柄、光标移动）不配文案——「过程说明」类第三段文案不设。
- **字幕直白**：讲用户看得懂的现象，不写代码抽象名；弹层画幅下控制在两条、每条 2 行内。
- **场景形态先选对**：复选框单点叙事走 `scripts/gen_help_anim.py::CheckboxDemoScene` 预设，叙事不匹配（下拉、多拍、拖拽）就自由组装（样本 `scripts/gen_help_anim.py::PunctuationScene`）——硬套预设是「观感莫名其妙」的来源。
- **节奏走档位**：时间轴用 `RhythmProfile` 档位表达，别逐场景手填帧号常量。
- **大画幅先定版式再填内容**：构图（一镜到底巡礼 / 分屏对比 / 局部放大步骤式）在拍点表阶段就声明；版式模板库待真实需求逐个沉淀，暂不预建。
- **禁止 emoji 作为 UI 图标或状态内容**（项目 UI 风格总则，动画同样适用）。
