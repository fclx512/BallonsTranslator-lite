# 侧栏图标 + 画布浮层面板

> 2026-08-23 定稿。三版演进：行号槽/独立浮窗（已废）→ 镜像覆盖格式区的停靠浮层（已废）→ **当前版：锚定窄栏左侧的画布区浮层**。本文只描述当前版。

## 布局总览

```text
┌────────────────────────────────────────────┐
│                  画布区                      │
│   ┌──────────────┐ ┌────────────────────┐  │
│   │ 注解浮层      │ │▐│ 格式编辑区        │  │
│   │ (RailDockPanel)│ │窄│ (GroupFrame)    │  │
│   │ 硬连接/左下角拉伸│ │栏│                 │  │
│   └──────────────┘ └─┴────────────────────┘  │
│                    ┌──────────────────────┐  │
│                    │ [Edit|Source|Trans]  │  │
│                    │ 文本框行卡片列表       │  │
│                    └──────────────────────┘  │
└────────────────────────────────────────────┘
```

- 上行：`ui/panel_rail.py::PanelRail`（26px 功能图标列）+ 格式区 `GroupFrame#formatOuterFrame`，见 `ui/scenetext_manager.py::TextPanel`。
- 下行：文本编辑区 `GroupFrame#textEditOuterFrame`，三开关工具栏（Edit/Review | Source | Translation）与行卡片列表同框居中。
- 行编号/选中锚色/拖拽发起都保留在行卡片内（`ui/textedit_area.py::TransPairWidget` 的 `badge_vp`/`badge_drag`/`accent_bar`/`drag_area`）。

## RailDockPanel（画布浮层）

`ui/custom_widget/rail_dock_panel.py::RailDockPanel`，入口在 `ui/text_panel.py::FontFormatPanel` 的 `install_annotation_launcher`（内容 = `AnnotationFormatGroup`，懒创建）。

- **宿主**：`rail.window().centralStackWidget` 的子控件——窗口内浮层而非独立 OS 窗口，随主窗移动、始终压在画布页之上；切页/切右侧面板时由 `on_textpanel_visibility` 随隐随复（保留开合状态）。
- **展开锚定**：`_anchor_to_rail()` 把面板放到窄栏左侧 8px、与窄栏顶对齐——即画布区右缘，不占用文本编辑区；右缘+顶部固定锚定（PS 式硬连接）。
- **不可自由拖拽**：标题栏不是拖拽把手；只有左下角 `_ResizeGrip` 拉伸尺寸（面板从锚定右缘向左展开，自由角在左下角，光标 `SizeBDiag`）。位移/尺寸都夹取在宿主范围内。
- **位置补偿**：宿主窗口缩放、窄栏移动时经事件过滤器自动重锚，不会错位到其他地方，无需重开刷新位置。
- **尺寸下限**：随内容布局（`_min_size()` = 显式最小值与布局 minimum 的较大者），拖拽再小也压不成一条线。
- **不自动关闭**：只响应窄栏图标 toggle、标题栏 ×、Esc；进入全局模式时浮层保持打开仅内容置灰（`_sync_annotation_controls`）。
- **记忆**：开合状态 `pcfg.annotation_dock_open`；位置始终回锚点，尺寸由用户调整并会话内保持。
- **内部控件**：注解控件统一用自定义控件库（`SmallComboBox` / `ConfigLineEdit` / `NoBorderPushBtn` / `SmallParamLabel`），与全应用主题一致。
- 窄区域不用边框/底色：窄栏本身透明，浮层靠 `#RailDockHeader` 标题条底色分层（`config/stylesheet.css`）。

## 行卡片常驻样式（无模式切换）

编辑/审阅切换功能与 UI 已整体删除（含相关配置字段）。行卡片 `ui/textedit_area.py::TransPairWidget` 常驻左侧 22px 拖拽列 + 编号徽章（`QLabel#TextBlockIndexBadge`，透明底、主题文字、垂直居中），文本框恒为整块多行（`QTextEdit::WidgetWidth` + 45px 最小高）。

## 字体/字重下拉定宽

`ui/text_panel.py`：`WidePopupComboMixin`（`showPopup` 前把弹出视图最小宽度抬到最长条目宽）+ 字体框/字重框 3:2 布局拉伸（`FontFamilyComboBox`/`FontStyleComboBox`）。闭合态宽度恒定不随内容伸缩，展开的列表完整显示不裁剪。
