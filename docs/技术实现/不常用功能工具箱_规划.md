# 不常用功能工具箱收纳规划

> 状态：**规划记录，未启动、无排期**（2026-09-06 用户提出）。动机：整理换行这类「极少用到但需要时刚需」的功能目前散在顶栏 Tools 菜单里，用时不记得入口；用户倾向以工具箱的收纳方式整合。

## 一、方向

以「工具箱」形式收纳不常用功能：需要用哪个就**激活它**，然后就地呈现该工具的功能项（编辑选项/参数），用完即退出——而非每个功能各占一个独立对话框入口。

取向对齐 fork 总纲：入口收敛、交互路径不因收纳变长（激活即用，不是「打开工具箱 → 找功能 → 再跳对话框」三层跳转）。

## 二、候选功能（待定）

- 整理换行（`ui/normalize_breaks_dialog.py::NormalizeBreaksDialog`）
- 高级对齐（`ui/point_align_dialog.py::PointAlignDialog`）
- 区域合并、路径重排、Quick Symbol、无字图配对等其余 Tools 菜单项是否纳入：实施前逐个评估。

## 三、边界与耦合

- **与撤销体系无耦合**：纯入口层重组，命令层（`ui/textedit_commands.py` 等）不动；撤销阶段4第二批的确认弹窗按命令归属照常生效。
- 撤销阶段4三批与本文档互不阻塞；工具箱启动时需重估当时的功能清单。
- 交互形态（工具箱承载位置：浮层面板 / 画布模式切换 / 其他）**未定**，启动前需与用户对齐一次草图或原型。
