# 反向移植 i18n 补充计划（交接文档）

> 交接对象：下一个对话的模型/助手。本批反向移植的三个 PR（快捷键 / 序号徽标 / 路径重排）只提供简体中文翻译，其余语言全部回退英文，需补充一个独立的 i18n PR 补齐。
> 相关现状详见 `docs/技术实现/反向移植_工作进度交接.md` 第三节（功能详情）。

## 一、背景与目标

批次：PR1 快捷键（`feat/backport-shortcuts`）、PR2 序号徽标（`feat/backport-seq-badge`）、PR3 路径重排（`feat/backport-path-reorder`）。

**已确认事实（2026-08-18）：**
- 三个 PR 的 `.ts` 条目里只有简体中文（`zh_CN`）有翻译；`zh_TW` 仅 reorder 的 12 条已译；其余 6 语言（`fr_FR`/`ko_KR`/`ru_RU`/`es_MX`/`pt_BR`/`hu_HU`）全部为空翻译（`type="unfinished"`）→ Qt 运行时回退英文源串。
- **根因不是 context/机制问题**（`_ShortcutRow`/`ShortcutEditor` 上下文与源串匹配完全正确，zh_CN 全量渲染正常）；单纯是**源仓库（fork lite）只有 zh_CN.ts（纯中文应用），没有其他语言的现成翻译可搬**。
- i18n 扫描规则：PR 只提交 `.ts`，不提交 `.qm`（上游作者明确）。补完翻译后本地编译 qm 自验即可。

## 二、用户已拍板的规则（必须遵守）

1. **`Del`（删除按钮）与 `Rst`（重置按钮）不译，是预期效果**——翻译会撑破按钮排版或被裁剪显示。**禁止为这两个字符串添加任何语言的翻译条目**（现状 ts 里就没有它们的条目，保持现状）。
2. i18n 补充做成**一个独立 PR**（不并入 PR1-3），由用户在下一个对话实施。
