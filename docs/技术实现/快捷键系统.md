# 快捷键系统（fork 自研）— UI 与功能实现参考

> 用途：反向移植候选功能（见 `docs/技术实现/反向移植_规范.md` §4）时，多数需要与快捷键
> 产生关联。本文件是 fork 侧快捷键系统的**现状快照**（2026-08-08），供移植时核对已有
> 动作、复用绑定模式、评估"快捷键编辑器"是否随功能一并搬上游。
>
> 快读入口：先看 §2 动作清单表，再按需读 §4 实现细节。

## 1. 概述

fork 的快捷键系统是**配置驱动 + 可编辑**的，三层结构：

```
DEFAULT_SHORTCUTS (ui/configpanel.py)        ← 默认值定义（action_id → 键序列列表）
        ↓ 未覆盖时 fallback
pcfg.shortcuts (config.json)                      ← 用户自定义覆盖（action_id → 键序列列表）
        ↓ _get_shortcut_keys() 解析
MainWindow._install_shortcuts() (ui/mainwindow.py)← 生成 QShortcut 注册到 MainWindow
```

- 查询优先级：`pcfg.shortcuts` 有值用自定义，否则用 `DEFAULT_SHORTCUTS`。
- `shortcuts` 值为 list，一个动作可绑多个键序列；空 list = 显式禁用。
- 所有快捷键在设置面板 **Shortcuts 页**编辑，**实时生效**（见 §3.3 热更新链）。

**与上游的本质差异**（v1.5.10 对照）：

| 维度 | fork | 上游 |
|------|------|------|
| 注册方式 | 配置驱动，`_install_shortcuts()` 统一注册 | 硬编码 `QShortcut` 写在 `mainwindow.py` |
| 用户编辑 | 设置面板 Shortcuts 页，可改/加/禁用/重置 | 无编辑器，用户无法改 |
| 持久化 | `pcfg.shortcuts` → `config.json` | 无 |
| 动作清单 | 36 个（见 §2） | 约 17 个硬编码（A/D/W/Zoom/Del/Ctrl+D/Space/SelectAll/Escape/Bold/Italic/Underline + H/R/J/B 工具），另有 titleBar trigger 与 canvas `keyPressEvent` 兜底 |

## 3. UI 结构（设置面板 Shortcuts 页）

### 3.1 入口与页面注册

- 入口：设置面板（OverlayModal）导航树 **General → Shortcuts**（位于 Interface 与 App 之间）。
- 注册方式：`self._add_page(self.shortcuts_editor)` — 与 LLM Profile 页同款平铺模式，
  页面由 `_wrap_page` 统一提供 `QScrollArea` + `ConfigScrollBar` 滚动。
- `ShortcutEditor`（`ui/configpanel.py::ShortcutEditor`）是纯平铺 widget，**不自带滚动**。

### 3.2 页面布局

```
┌──────────────────────────────────────────────────────┐
│ ┌─ Navigation ─────────────────────────────────────┐ │
│ │ [Page Up        ] (A)(x)                [+][Del][Rst] │
│ │ ────────────────────────────────────────────────── │
│ │ [Page Down      ] (D)(x)                [+][Del][Rst] │
│ └──────────────────────────────────────────────────┘ │
│ ┌─ View ───────────────────────────────────────────┐ │
│ │ …                                                  │ │
│ └──────────────────────────────────────────────────┘ │
│ …（Edit / Tools / Reorder / Search / General 同构）…   │
└──────────────────────────────────────────────────────┘
```

每个分组 = `PanelGroupBox`，组内行间用 1px 分隔线（`s['add_bdr']` 色）。每行 `_ShortcutRow`
（`ui/configpanel.py::_ShortcutRow`）三列：

| 列 | 内容 |
|---|---|
| 左（140px） | 动作名 `QLabel`（`self.tr(_ACTION_NAMES[id])` 间接翻译） |
| 中（伸展） | 快捷键 pills：每个键一个圆角胶囊（键文本 + 红色 `x` 关闭钮）；无键时显示斜体 "— None —" |
| 右（86px） | `+`（添加）、`Del`（清空禁用）、`Rst`（恢复默认）三个小按钮 |

### 3.3 交互与热更新链

```
Shortcuts 页某行：+ / pill 的 x / Del / Rst
  → _ShortcutRow.shortcut_changed Signal
  → ShortcutEditor.shortcut_changed（透传）
  → ConfigPanel._on_shortcuts_edited()     ← `ui/configpanel.py::_on_shortcuts_edited`
       ├─ save_config()                    ← 立即持久化
       └─ shortcuts_changed Signal
            → MainWindow.refreshShortcuts()（`ui/mainwindow.py::refreshShortcuts`）
                 ├─ 删除 shortcut_registry 全部旧 QShortcut
                 └─ 重建 _install_shortcuts()
```

**实时生效**，无需关闭设置面板、无需重启（2026-08-08 页面化重构后行为；此前是
`ShortcutDialog` 关闭才刷新）。

添加键的交互：点 `+` 在行内插一个 `QKeySequenceEdit`（120×24），`editingFinished` 时
把 `keySequence().toString()` 追加进 `pcfg.shortcuts[action_id]` 并重建 pills。

## 4. 功能实现要点

### 4.1 数据定义（均在 ui/configpanel.py）

| 常量 | 符号 | 作用 |
|---|---|---|
| `DEFAULT_SHORTCUTS` | `ui/configpanel.py::DEFAULT_SHORTCUTS` | `action_id → [键序列]` 默认值 |
| `_ACTION_NAMES` | `ui/configpanel.py::_ACTION_NAMES` | `action_id → 英文显示名`（供 UI 与 i18n） |
| `_SHORTCUT_GROUPS` | `ui/configpanel.py::_SHORTCUT_GROUPS` | `(分组名, [action_id...])` 有序分组 |

### 4.2 键解析与注册（ui/mainwindow.py）

```python
def _get_shortcut_keys(self, action_id, defaults):
    """用户配置优先，否则用默认值。空 list = 禁用。"""
    if action_id in pcfg.shortcuts:
        keys = pcfg.shortcuts[action_id]
        return keys if isinstance(keys, list) else ([keys] if keys else [])
    return list(defaults)

def _make_shortcuts(self, action_id, defaults, slot):
    return [QShortcut(QKeySequence(k), self)  # 每个键序列一个 QShortcut
            for k in self._get_shortcut_keys(action_id, defaults)]
```

- `_install_shortcuts()`（`ui/mainwindow.py::_install_shortcuts`）逐个 action 调 `_make_shortcuts` 存入
  `self.shortcut_registry[action_id]`（list[QShortcut]）。
- `refreshShortcuts()` 全量重建（删旧建新），handler 槽无需 disconnect（QShortcut 被
  `deleteLater` 后连接自然失效）。
- **工具类动作特殊处理**：`hand/rect/inpaint/pen` 四个走 `drawpanel_info` 字典循环，
  slot 用 `partial(drawingPanel.shortcutSetCurrentToolByName, tool_name)`，并在
  drawingPanel 上写 `setShortcutTip` 显示提示。

### 4.3 持久化（utils/config.py）

- `ProgramConfig.shortcuts: Dict[str, List[str]]`，随 `config.json` 保存。
- 修改 `pcfg.shortcuts` 后必须 `save_config()`（`_on_shortcuts_edited` 内已做）。
- 兼容：旧 `config.json` 无 `shortcuts` 字段时走默认值；值可能是单字符串（老数据），
  `_get_shortcut_keys` 做了 list 归一化。

### 4.4 关键规则（移植时勿破坏）

1. **所有快捷键必须经 `_install_shortcuts()` 注册**，禁止 `QAction.setShortcut()` /
   散落的 `QShortcut` — 否则快捷键编辑器无法覆盖。
2. `_make_shortcuts(action_id, defaults, slot)` 的 `action_id`/`defaults` 必须与
   `DEFAULT_SHORTCUTS` 完全一致（否则用户 reset 后默认值对不上）。
3. **i18n 坑**：动作名经 `self.tr(_ACTION_NAMES[id])`、分组名经 `self.tr(group_name)`
   间接翻译 → `i18n_check` 恒显示 orphan，需**手动**在 ts 的 `_ShortcutRow` /
   `ShortcutEditor` context 维护 `<message>`（AGENTS.md i18n 一节有专述）。
4. handler 内识别触发键用 `self.sender()` + `QShortcut.key()`（如 `shortcutBefore`
   区分 A/PgUp），或用 `partial` 传参（工具类）。

## 5. 新增/绑定一个快捷键的完整步骤

以给某个（待移植的）功能 `my_action` 加快捷键为例：

1. `DEFAULT_SHORTCUTS['my_action'] = ['Ctrl+Shift+X']`（`ui/configpanel.py::DEFAULT_SHORTCUTS`）
2. `_ACTION_NAMES['my_action'] = 'My Action'`（`ui/configpanel.py::_ACTION_NAMES`）
3. 把 `my_action` 加进 `_SHORTCUT_GROUPS` 对应分组（`ui/configpanel.py::_SHORTCUT_GROUPS`）
4. `_install_shortcuts()` 中：`self.shortcut_registry['my_action'] =
   self._make_shortcuts('my_action', ['Ctrl+Shift+X'], self.on_my_action)`
5. 写 handler `def on_my_action(self): ...`（MainWindow 方法）
6. i18n：ts 的 `_ShortcutRow` context 加 `<source>My Action</source>`
7. `qm_compile.py` 编译 + `i18n_check.py` 验证

**无默认键的动作**：第 1/4 步 defaults 传 `[]`，用户在 Shortcuts 页自行绑定。

## 6. 移植到上游的适配点

> 上游 v1.5.10：`ballontranslator/ui/mainwindow.py` 内硬编码 `QShortcut`（约 17 个：
> A/PgUp/D/PgDown/W/ZoomIn/ZoomOut/Ctrl+D/Space/SelectAll/Escape/Bold/Italic/Underline/
> Delete + drawingpanel H/R/J/B），**无编辑器、无配置驱动**。详见 §1 差异表。

按移植目标分两种情况：

### 6.1 只移植"某功能 + 其快捷键"

- 上游已有对应硬编码 `QShortcut`：直接复用其 style（`QShortcut(QKeySequence(...), self)` +
  `activated.connect`），不要引入 fork 的注册器/编辑器。
- 上游无该快捷键：在 `mainwindow.py` 的快捷键块内照抄一行即可；若功能有默认键，记得
  与 fork 的 `DEFAULT_SHORTCUTS` 默认值保持一致（降低未来统一编辑器时的迁移成本）。
- handler 迁移：fork handler 里对 `_is_canvas_mode()`/`editing_textblkitem` 的守卫逻辑
  要随迁（上游同类 handler 结构相同，可对照）。

### 6.2 把"快捷键编辑器 + 配置驱动体系"整体移植（大工程，慎重）

这是 B 类大改，涉及：

- 上游 `utils/config.py` 无 `shortcuts` 字段 → 新增字段 + 默认值（遵守上游 JSON 向后
  兼容红线：旧配置无此字段时安全 fallback）。
- 上游 `mainwindow.py` 全部硬编码 `QShortcut` 需改走 `_make_shortcuts`（约 17 处 +
  drawingpanel 循环）——注意上游用 `QKeySequence.StandardKey`（如 `ZoomIn`）而非
  字面串，fork 的 `DEFAULT_SHORTCUTS` 用的是字面串（`Ctrl++`），映射时需换算。
- 设置面板上游是"单页滚动"（fork 页面化是 C 类自研，**不要**把 Shortcuts 页结构照搬），
  编辑器可做成独立 `QDialog` 形式（即 fork 2026-08-08 之前的样子）。
- i18n：上游 9 语言 `resources/translate/`，用上游 `update_translation.py` 或手工加
  `<message>`；`_ShortcutRow`/`ShortcutEditor` context 的间接翻译同样要手动维护。
- 若只求编辑器而暂不动硬编码快捷键，可先做"只读清单页"——列出上游现有硬编码动作
  （这正是"上游开发者自己都可能遗忘的快捷键"盘点：跑 `rg "QShortcut" ballontranslator/`
  可全量列出）。
