# 窄栏浮层面板改版计划

> 状态：**形态定稿（2026-09-06），待实施**。用户定调：窄栏挂载的浮层面板整体「太潦草」，需要彻底改进，可接受重写控件与排版。三个形态问题（连字排法 / 着重号排法 / 浮层分合）已拍板，见第三节。

## 一、范围

28px 窄栏（`ui/panel_rail.py::PanelRail`）挂载的五个浮层（容器 `ui/custom_widget/rail_dock_panel.py::RailDockPanel`，开合记忆在 pcfg）：

| 浮层 | 内容件 | 现状评估 |
|------|--------|----------|
| 注解 | `ui/text_panel.py::AnnotationFormatGroup` | Ruby 小节 + 连字区，旧式小标签叠放 + FlowLayout 拼排，**本改版重写** |
| 着重号 | `ui/text_panel.py::EmphasisFormatGroup` | FlowLayout 单元横排，仅两个下拉，**本改版重写** |
| 变换 | `ui/text_engine/transforms/panel.py::TransformParameterPanel` | **排版参照规范本尊**，基本达标，改版时作为基准不动或微调 |
| 文本样式（→效果） | `ui/text_style_dock.py::TextStyleGroup` | 随批次②效果面板**整体取代**，不投入改版；效果面板按新规范首写 |
| 历史 | `ui/history_panel.py::HistoryPanel` | 二期已紧凑化（分组模型+delegate 自绘），暂列不动 |

挂载关系：两个内容件由 `ui/text_panel.py::FontFormatPanel` 创建（隐藏子件），经 `install_annotation_launcher` / `install_emphasis_launcher` 装进 RailDockPanel 浮层——重写内容件不碰容器机制。

容器本体（RailDockPanel 硬连接锚定、三向隐形拖拽手柄、Esc/× 关闭、开合记忆）2026-09-06 刚打磨过（97837c7），机制层不动，改版聚焦**浮层内容件的控件与排版**。

## 二、现状问题

- 两代排版语言并存：注解/着重号是「小标签叠控件上方 + FlowLayout 自动换行 + SmallComboBox（AdjustToContents 宽度随内容漂移）」旧式拼排；变换面板是「标签右对齐 + 22px 定高输入框 + 网格行」规范。并排打开观感割裂。
- 小节标题、分隔线、间距各家一套：注解用加粗小标签 + `fmtGroupSeparator` 分隔线，着重号连小节标题都没有。

## 三、形态定稿（2026-09-06 与用户对齐）

### 3.1 排版规范（对齐 TransformParameterPanel）

- 标签右对齐 | 输入框的行式网格；输入框 22px 定高、列宽受控（不用 AdjustToContents 漂移宽度）。
- 小节标题、分隔线样式取变换面板同款（objectName `TextTransformSectionTitle` 一类）。
- 控件一律 `ui/custom_widget/` 封装类（输入类禁裸原生类，见 AGENTS.md 双轨机制警示）。

### 3.2 各浮层形态（已拍板）

- **注解浮层**：
  - 连字区（通用/任意/上下文/旧体数字 四个 默认/开/关 下拉）改**四行标签|下拉规范式**（否决 2×2 紧凑网格；浮层总高多约 40px 可接受）。
  - 注音读音保留**应用/移除显式按钮**——这是撤销事务的显式提交点，人工在环语义不改成回车即提交（AI 拍板项，可推翻）。
- **着重号浮层**：符号 + 位置改**两行标签|下拉**（符号下拉带图标预览、拿完整宽度；否决一行两单元）。
- **浮层分合**：注解与着重号**保持两个独立入口**（都是选中级、窄栏中间有组间距）；不做合并。

### 3.3 改动边界

- **逻辑零改动**：信号（`annotation_changed` / `emphasis_changed` / `ruby_remove`）、`set_*` 回显、撤销接线全部原样，纯换皮重排。
- 减法优先：不加功能，只换皮与重排。

## 四、顺序

批次②（效果栈重移植，效果面板按 3.1 规范首写）→ 本改版（注解/着重号重写）→ 批次③（主面板描边行退役 + 闪现弹窗排查）。历史面板视验收反馈决定是否纳入。

## 五、遗留事项

- 与《不常用功能工具箱_规划》的边界：工具箱是纯入口层重组，本计划是浮层内容件重写，二者不耦合但都动窄栏，实施顺序需协调。
