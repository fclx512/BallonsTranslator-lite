## 四、视觉代码在哪里（接手必读）

全部视觉在 `ui/pie_menu.py`。**几何常量在文件顶部**：

CARD_PAD_X = 10.0             # 卡片水平内边距
CARD_PAD_Y = 6.0              # 卡片垂直内边距
ICON_SIZE = 13.0              # 左侧图标边长
ICON_MARGIN = 5.0             # 图标与文本/边缘间距

**配色在 `paintEvent()` 内**（`is_dark_theme()` 分支）：

| 用途 | 深色 | 浅色 |
|------|------|------|
| 菜单底色 disc | `rgba(35,37,46,235)` | `rgba(245,246,250,250)` |
| 中心圆环 | `rgba(130,135,150,220)` | `rgba(100,105,120,160)` |
| 卡片底 | `rgba(55,58,70,200)` | `rgba(255,255,255,235)` |
| 卡片描边 | `rgba(255,255,255,70)` | `rgba(0,0,0,55)` |
| 扇区数字 | `rgba(255,255,255,140)` | `rgba(0,0,0,120)` |
| 文本 | 主题变量 `@textColor` | 同左 |
| 高亮 | 主题变量 `@accentPrimary`（填充 alpha 230，白色描边 1.2px，白色文字/数字/图标） | 同左 |
| 禁用文本 | 同文本色 alpha 110 | 同左 |

- 卡片圆角 8px；文本保持水平可读，左侧可选 SVG 图标，右侧显示扇区数字 1-8
- 中心圆环 + 无高亮时中心点；高亮时画指向卡片的箭头 + 细径向指示线
- 高亮扇区底层画低透明度 wedge 作为背景提示
- 多卡片扇区在 `_card_angle(sector, idx)` 里按 `FAN_SPACING` 均分该扇区 45° 角域；卡片本身仍轴对齐
- 命中判定：优先检测轴对齐卡片矩形（限制在同扇区），否则回退到角度扇区选择

## 五、已知 Qt 坑（改渲染时必须知道）

1. **卡片改为轴对齐、文本水平排布**：旧版曾将文本沿径向旋转，需要预渲染到 `QPixmap` 来规避 `drawText` 在旋转坐标系下的错位。新版卡片保持轴对齐，文本直接 `drawText` 绘制即可。图标通过 `QSvgRenderer` 渲染到 `QPixmap` 并按当前文字色做 `CompositionMode_SourceIn` 着色缓存。
2. **PyQt6 `QKeyEvent` 没有 `globalPosition()`**：取光标全局位置用 `QCursor.pos()`（mainwindow.py 已处理，若改触发逻辑留意）。
3. **`QTextEdit` 默认 `tabChangesFocus=False`**：在源/译文输入框按 Tab 默认会插入制表符而非弹菜单。已处理：纯文本输入控件内 Tab 被 app 级 filter 吞掉（惰性）。若调整 Tab 行为注意这一点。
4. **离屏平台字体渲染异常**：`scripts/_pie_preview.py` 已去掉 `QT_QPA_PLATFORM=offscreen`，使用默认 windows 平台插件才能正确渲染中文/英文字体。

## 六、视觉修缮结果

本轮已完成的主要改进：

1. **卡片视觉**：圆角从 6px 增至 8px，背景更不透明，描边更明显；卡片改为轴对齐，文本水平可读。
2. **高亮反馈**：hover 改为实色填充（alpha 230）+ 白色描边/文字/数字/图标，对比度接近 Blender。
3. **中心圆与方向箭头**：中心圆环 + 无高亮时中心点；hover 时画指向卡片的箭头 + 细径向指示线。
4. **间距与尺寸**：菜单半径从 172 增至 210，中心圆缩小至 42，卡片选择环外扩，整体比例更舒展。
5. **深/浅主题**：两套配色已重新调整并生成预览图。
6. **图标与数字**：`CmdDef` 新增可选 `icon` 字段，部分命令已映射现有 SVG 图标；右侧显示扇区数字 1-8。
7. **扇区空余方向**：保持空白，与 Blender 一致；高亮时底层画低透明度 wedge 提示方向。

仍可适当继续的方向（非本轮必须）：

- 高亮过渡动画 / 卡片微缩放
- 为更多命令补充图标
- 高分屏 DPR 适配
- 同扇区 3 张及以上长标签卡片的 further 防重叠优化
