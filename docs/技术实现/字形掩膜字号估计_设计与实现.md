# 字形掩膜字号估计 设计与实现

> 状态：已实现（2026-10-18）。只读验证数据来自织姬工程副本 24 页 / 127 块，探针未入库。

## 目标与非目标

**目标**：利用 `ysg_ctd` 的 CTD 精细字形掩膜，在 OCR 之后、翻译之前为每个文字块估一个原文字号（像素），让下游可以「固定字号 + 按文本框宽度折行」，而不是统一回退全局字号。

**非目标**：
- 不改渲染引擎。`ui/text_engine/` 已经支持固定字号与按块宽折行。
- 不做 shrink-to-fit。内容超出文本框时沿用现有撑框 / `utils/config.py::clip_text_overflow` 裁剪。
- 不改变其它检测器的字号逻辑。
- 逐块 OCR 路径（单框翻译、区域再检测）不挂字号估计；只有整页管线（当前页／全部／区间）生效。

## 解耦设计

实现拆成三层，任何一层失效都不会影响原流程：

1. **纯函数层** `utils/font_size_estimate.py`：只依赖 numpy/cv2 和 block 的鸭子类型属性，不导入 Qt、`pcfg`、`modules` 或 `ui`。
2. **能力声明**：`modules/textdetector/detector_ysg.py::YSGYoloCTDDetector` 声明 `provides_glyph_mask = True`。其它检测器没有该标记，`apply_mask_font_sizes_from_detector` 直接返回空列表。
3. **管线挂点**：`ui/module_manager.py::_imgtrans_pipeline` 与 `ui/pipeline_runner.py::_process_page` 在 OCR 完成后调用一次。掩膜为空、没有文本、或检测器未声明能力时都是空操作。

**测量数据在检测阶段挂、OCR 之后消费**（关键坑）：管线保存的页级掩膜是各行合并后再膨胀的，CTD 未参与精修的行会被整行多边形填充，直接拿它测量会把大量块跳过（织姬 096 页 9 块中 7 块被跳过）。因此 `modules/textdetector/detector_ysg.py::_detect` 在合并**之前**对每个块原始 CTD fine_mask 调 `utils/font_size_estimate.py::attach_glyph_font_metrics`，把每行短边/长度/填充率汇总成 `block._glyph_font_metrics`（只挂内存；`utils/textblock.py::to_dict` 显式排除，不落工程 JSON；指标带行数与 bbox 校验，块被移动或合并后自动失效）。OCR 后的挂点优先消费该指标——任一行未测到则整块不挂、回退页级合并掩膜兜底（此时才逐行跳过填充行）。

字号写回沿用现有字段：`blk.font_size` 与 `blk._detected_font_size`；`font size multiplier` / `font size min` / `font size max` 由 `utils/font_size_estimate.py::params_from_detector` 从检测器参数读取。用户选择「用全局字号」时仍由现有后处理覆盖。

## 算法

### 每块两个口径

对每个检测行四边形内的掩膜墨迹：

- `ink_short`：短边（竖排取列宽，横排取行高）。
- `ink_long`：沿阅读方向的长度。
- 管线里的掩膜已按 `mask dilate size`（默认 8px）膨胀，测量前每侧减掉该膨胀量。
- 兜底路径（页级掩膜）里整行多边形被填充（填充率 > 0.75）说明该行没有被 CTD 精修，跳过该行；指标路径里任一行未测到则整块回退兜底。

得到：

```
em_short = median(ink_short) × 1.103
em_len   = Σ(ink_long) / (加权字符数 - 0.1 × 有墨行数)
```

`1.103` 是合成图校准的字形墨迹 → em 比例。字符数按排版宽度加权：全角空格 `U+3000` 计 1.0、半角空格计 0.5、首尾空白不计、换行不计。

### 取小与置信度

```
em = min(em_short, em_len)
```

两个口径的失败方向相反：

- **字距偏大**：`em_len` 被抬高，`em_short` 不受影响；
- **装饰字体/粗描边**：`em_short` 被抬高，`em_len` 不受影响。

合成验证：字距 0.5em 时 `em_len` 误差 39.9%，`em_short` 2.9%，取小后 2.9%；字距 1.0em 时取小仍是 2.9%。

`em_len < 0.5 × em_short` 视为 OCR 字符数异常或掩膜长度被截断，回退 `em_short`。置信度按两口径比值与文本长度分 high/medium/low，只用于吸附容差，不写进项目数据。

### 逐页规范字号

原文字号通常按页/场景成组，不同页的基础字号可以不同。因此只在**当前页**内聚类：

1. 长文本块（加权字符数 ≥ 8）作为锚点，短块不参与定锚；锚点不足 2 个时退化为用全部有效块定锚。
2. 按字符数加权做 Gaussian KDE，带宽取锚点中位数的 6%（最小 2px）。
3. 保留权重占比 ≥ 15% 的 1～3 个模式；每个模式用成员加权中位数作为中心。
4. 短块在 ±12%、长块在 ±9% 内吸附到最近模式；长块超出容差保留原值（常见于文本量多而有意缩小的气泡）。低置信块容差放宽到 ±15%。

## 已知限制

- CTD 漏检/掩膜为空的块不估字号，保留检测器原值；织姬样本覆盖约 98.4%。
- 字形是白字黑边、装饰字体或极细笔画时，两个口径都可能偏；逐页规范字号吸附是最后一道兜底。
- 大幅旋转/弧形排列的文字目前按外接框测量，未做多边形旋转校正；横竖排常规页面不受影响。
- OCR 文本多字/缺字会直接影响 `em_len`；取小与规范字号吸附可兜住大多数，但极端情况仍可能偏差。
- 规范字号按页聚类，不跨页统一；页面只有 1 个有效块时不做吸附。

## 验证

- 单元测试 `tests/test_font_size_estimate.py`：字距、全/半角空格、膨胀修正、填充行跳过、逐页规范字号、参数读取与能力闸门。
- 合成集：`em_short` 平均误差 2.7%（85% 在 ±5% 内）；`em_len` 平均 2.3%，基本无系统偏差。
- 真机（织姬 24 页）：`em` 与人工成品字号比值中位 0.979（IQR 0.874–1.054）；逐页聚类 83% 的块可吸附，长文本离群保留。
