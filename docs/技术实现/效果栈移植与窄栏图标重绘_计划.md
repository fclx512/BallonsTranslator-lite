### 推论



这次移植不是"新增几个控件"，而是 **◐ 文本样式浮层的内容被整套取代**：不透明度/阴影/渐变从"独立字段 + 独立浮层"迁移为"效果栈内的卡片"。



## 三、放置决策（已与用户确认）



1. **效果栈整栈一个入口，不拆散。** 效果栈是顺序敏感的堆栈（卡片排序影响渲染），拆成"主面板留常用 + 浮层放长尾"会破坏排序模型。

2. **◐ 退役**：窄栏新增第 5 个入口"效果"（新图标 `rail_effects.svg`），浮层整装效果栈；`pcfg.textstyle_dock_open` 开合记忆迁移为 `pcfg.effects_dock_open`。旧文本样式浮层（原 TextStyleGroup，已登记 deprecated）被取代后删除。

3. **主面板描边行退役**：整栈移植后描边只在栈内调整（交互统一，减法导向）。

4. **窄栏按作用域排序分组**：选中级（注解、着重号）在上，块级（变换、效果）在下，中间以间距分隔（`ui/panel_rail.py::add_launcher` 顺序控制，宽度不变）。

5. **移植范围裁剪不影响放置结构**：AI 生成图、Alpha 遮罩编辑会话、滤镜族若暂缓，效果卡种类相应减少，栈式面板结构不变（范围见第六节定稿）。

6. **角标机制照旧**：当前块带任意非默认效果时点亮 `ui/panel_rail.py::set_dot`，浮层标题加 " •"。



## 四、图标重绘专节（SVG，替代字体字形）



### 4.1 为什么字体符号不合适（现状问题）



现按钮用 `drawText` 画字体字形（`あ`/`●`/`⤢`/`◐`），问题：



- **语义模糊**：`あ` 是日文特定字符，中文用户未必联想到"注解"；`⤢`/`◐` 更是"看图标猜功能"。

- **字体回退不可控**：字形最终由系统字体回退链渲染，跨平台/跨主题字形粗细、基线、缺字（tofu）风险都不可控。

- **状态混排**：`deco="dots"`（注解的 ruby 点）靠 `paintEvent` 手绘叠加，与字形排版耦合脆弱。

- **与全局图标语言割裂**：项目其余部分已是统一 SVG 集（`icons/fontfmt_*`、`icons/drawingtools_*`），窄栏是唯一的字体字形孤岛。



### 4.2 技术规范（必须遵守项目既有约定）



- **单色纯 fill**：所有形状只用 `fill="#96a4cd"`，**禁止 `stroke=` 属性**——`ui/misc.py::set_icon_theme` 只对 `fill="…"` 字面量做主题替换，stroke 不会跟着换色，深浅主题下必坏。需要"线条"的形状一律用填充路径勾勒。

- **无渐变、无多色、无内嵌 CSS/`<style>`**。

- **24×24 Material 网格**：`viewBox="0 0 24 24"`（与 `icons/drawingtools_ai.svg` 一致），坐标取整数或 .5 半像素，手绘几何形状好算；渲染时缩到 16–18px 仍清晰。

- **命名**（阶段 A 新增，路径如下）：



  ```text

  icons/rail_annotation.svg   icons/rail_emphasis.svg

  icons/rail_transform.svg    icons/rail_effects.svg

  ```

- **不加 `*_activate` 变体**：窄栏选中态保持现有视觉语言（accent 圆角底 + 白色图形），不用全局 `*_activate`（accent 色图形在 accent 底上会消失）。



### 4.3 渲染管线改造（`RailLauncherButton`）



- `paintEvent` 从 `drawText` 改为经 `ui/icon_rendering.py::render_svg_pixmap` 渲染 SVG（已有 lru_cache + devicePixelRatio 感知，直接复用）。

- **扩展 `render_svg_pixmap` 增加状态色覆盖参数**（如 `override_fill`）：渲染前对 SVG 源串做 `fill="#96a4cd"` → 目标色替换后交给 `QSvgRenderer`。正常态 = 主题前景色，选中态 = 白色，禁用态 = 前景色降 alpha——取代现在对字形颜色的处理，`QColor("white")` 分支逻辑平移。

- accent 选中底、hover 1px 描边、右上角 dot 角标的自绘逻辑全部保留不动。

- `deco="dots"` 参数取消：ruby 点直接画进 `rail_annotation.svg` 本体。



### 4.4 每个图标的设计草案



设计原则：形状 ≤3 个元素、几何构成（条/点/框/箭头），语义靠"结构关系"表达而非字符。



**`rail_annotation`（注解/ruby）**

- 构成：上方 3 个小圆点（ruby 着重记号，即原 deco dots）+ 下方一条粗圆角横条（正文行）。

- 语义：点在上、正文在下 = 注音标在字头，与画布渲染实际效果一致。

- 几何草案（24 网格）：点 r=1.5，圆心 y=7，x=5/12/19；横条 x=4→20、y=14→17、rx=1.5。



**`rail_emphasis`（着重号）**

- 构成：一个圆角方框（字身）+ 正下方一个实心圆点（着重号）。

- 语义：横排着重号在字下，竖排在字侧，用"字身框 + 点"的组合表达"给字加点"，比孤零零一个 `●` 多一层关系。

- 几何草案：方框 x=6→18、y=4→16、rx=2、1.8 宽描边轮廓（以填充路径实现外框）；点圆心 (12, 20.5)、r=2。



**`rail_transform`（文本变换）**

- 构成：一个旋转 12–15° 的圆角方框（变换后的字形）+ 从框右下角指出的对角箭头（变换手柄意象，延续原 `⤢` 的方向暗示）。

- 语义：歪的字 + 变换箭头 = 旋转/斜切/缩放一类几何变换。

- 几何草案：方框 8×8、rx=2、中心 (11,10)、rotate(14 11 10)；箭头线段 (14,14)→(19,19) 加三角箭头头部（全部填充路径）。



**`rail_effects`（效果，新入口）**

- 构成：前后两片错位圆角方片——后片实心表达"层/阴影"，前片中心挖一个小圆孔表达"发光点"。层叠意象直接对应"效果堆栈"。

- 已定稿用层叠方片（AI 生成图暂缓移植，sparkle 的"AI 魔法"语义暂不需要；后续若移植 AI 生成图卡可再换）。

- 几何草案：后片 x=8→19、y=4→15、rx=2；前片 x=4→15、y=8→19、rx=2；前片中心挖 r=2 圆孔（`fill-rule="evenodd"`）。

### 阶段 C 实机验收缺陷：面板写入断链（✅ 2026-08-31 修复）



实机确认描边/阴影/渐变设置全部无效（引擎层与测试层均正常）。根因是 **fork 双格式惯例与新渲染器读栈来源的错位**：



- fork 惯例：选中块时 `ui/text_panel.py::set_textblk_item` 经 `get_fontformat()` 重建 `C.active_format`，失焦/切换时 `self.textblk_item.fontformat = copy.deepcopy(...)` 回写——`item.fontformat`（渲染副本）与 `item.blk.fontformat`（模型/canonical）是两个对象，面板的效果参数写入只落在渲染副本。

- 旧渲染器（v1.5.9）读 `self.fontformat`（渲染副本）→ 有效；阶段 C 渲染器按上游语义读 `item.blk.fontformat.text_effects`（canonical）→ 面板写入不可见 → 设置失效。



**修复（上游顺从）**：`ui/text_engine/item.py` 新增 `_commit_effect_fields`——对 canonical 栈做 FontFormat 深拷贝探针、经 legacy 视图写入目标字段后以 `ui/text_engine/effects/renderer.py::set_text_effects` 提交（同时写 model+render 两格式，自带 `_finish_effect_transition` 完整失效链：opacity 应用、描边对齐、padding、缓存策略、repaint、update）。接入范围：



- `setStrokeWidth`/`setStrokeColor`/`setShadow`/`setBGAttribute`/`setGradientAttribute`/`setGradientEnabled`/`setOpacity` 七个 setter（后两者 `setOpacity` 为上游模式——native 透明度由 `_apply_effective_opacity` 应用；`setBGAttribute`/`setGradientAttribute` 对非 legacy 名保留原通道）。

- `set_fontformat` bulk 路径：描边宽+色合并一次提交（色只随非零宽度进栈，无描边块保持无卡语义；0 宽卡是 neutral，`paint_item` 已短路，无伪影）。



回归：`tests/test_textblkitem_effect.py::test_legacy_setters_reach_canonical_stack_after_panel_decoupling`（解耦后七 setter 写透 canonical + 渲染像素跟进）；全量 pytest 479 passed + 1 skipped、`verify.py --full` 全绿。排查期实证脚本已转该正式测试后删除。
