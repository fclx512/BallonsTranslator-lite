## 分页结构

6 个页面，QStackedWidget（`ConfigPanel.pageStack`，`configpanel.py:1351`）。页面内容包裹在 `QScrollArea` + `AnimatedScrollBar` 中（`_wrap_page`，`configpanel.py:2198`）。

导航使用 `ConfigTable`（树形控件，`configpanel.py:547`），不再使用上游的 `NavList`。

```
导航树（6 条目）                   PageStack 索引
────────────────────────────────────────────────
DL Module（标题，灰显不可选，可展开）
  Models                                0
  Pipeline                              1
General（标题，灰显不可选，可展开）
  Project                               2
  Typesetting                           3
  Performance                           4
  Interface                             5
```

### 页面创建机制

原先的代码用 `dlConfigPanel.addGroupedBlock(...)` 将 section 添加到两个 `ConfigBlock`（dl/general）的 vlayout 中。重构后引入了两个中间类：

```python
class _DeadLayout:                              # configpanel.py:1289
    """存根：addWidget(head_widget) 委托给 _active_panel._add_page（添加为独立页面）"""

class _DeadBlock:                               # configpanel.py:1296
    """存根：addGroupedBlock 委托给 _active_panel._add_grouped_page"""
```

`ConfigPanel._active_panel`（类属性，`configpanel.py:1335`）在 `__init__` 开始时设为 `self`，确保构建期间 `_DeadBlock`/`_DeadLayout` 能找到正确的面板实例。构建期间：

- `models_group`（`configpanel.py:1369-1370`）直接经 `self._add_page(models_group)` 注册为页面 0
- `dl_container`（含 detect/ocr/inpaint/trans 4 个 group）→ `_add_page(dl_container)` → 页面 1
- `generalConfigPanel.addGroupedBlock(...)` → page 2, 3, 4, 5（project → typesetting → interface → performance）

`_wrap_page(content: QWidget) -> QScrollArea`（`configpanel.py:2198`）将每个 section 的 PanelGroupBox 包裹为带 `CONFIGBLOCK_CONTENT_MARGINS`（24,24,24,24）的滚动页面。内容 widget 的垂直策略设为 `Fixed` 防止短页面被拉满窗口。

### ConfigSubBlock 容器

所有设置项统一使用 `ConfigSubBlock` 包裹（`configpanel.py:162`，2026-06-26 收编了全部裸 widget）：

```python
class ConfigSubBlock(Widget):
    def __init__(self, widget=None, name=None, description=None, note=None,
                 vertical_layout=True, insert_stretch=False,
                 content_margins=(24,6,24,6))
```

- `widget`：控件或布局，`None` 时仅渲染标题行（用于分组标题如 "输出"、"行为"）
- `name`：名称标签（16px Normal）
- `description`：简述（14px 灰色）
- `note`：**备注文本**，提供时名称旁出现 `?` 按钮，点击弹出 `ConfigNotePopup`
- `vertical_layout`：`True` 时标签上控件下，`False` 时标签左控件右

## OverlayModal 机制

### 载体

`ui/overlay_modal.py` 的 `OverlayModal(QObject)`（`overlay_modal.py:109`）。它在 `cover_widget`（`centralStackWidget`）上方创建一个 `_Scrim(QWidget)`（`overlay_modal.py:66`），面板（ConfigPanel）位于 scrim 之上居中。

### 核心参数

```python
_PANEL_W = 1000      # 面板固定宽（cover 小则缩）
_PANEL_H = 700       # 面板固定高
_SCRIM_ALPHA = 0.55  # 遮罩不透明度目标值
_DEFAULT_DURATION = 350  # 动画时长 ms
```

### 动画

scrim 和 panel 各有 `QGraphicsOpacityEffect`，用 QTimer 按 `_detect_interval()`（= `pcfg.animation_fps` 换算的帧间隔）驱动，`QEasingCurve.InOutExpo` 插值。

`pcfg.animation_fps < 0` 或 `duration ≤ 0` 时跳过动画：

- `show()`：直接 `panel_effect.setOpacity(1.0)` + `scrim.set_alpha_target(0.55)`
- `hide()`：直接 `panel.hide()` + 销毁 scrim

在动画过程中收到反向操作（show 时收到 hide，hide 时收到 show）会**平滑反转**（`_reverse` 方法）。

### 关闭路径

- **scrim 点击**：`_Scrim.mousePressEvent` 检查 `_closable`，为 True 时调用 `OverlayModal.hide()`（通过 `on_click_outside` 回调）。子对话框打开期间 `_closable=False`。
- **配置图标再次点击**：`leftBar.configChecker` 互斥 → `setupConfigUI()` → 已在显示时 `_hideConfigOverlay()`。
- **imgTrans 互斥切换**：`leftBar.imgTransChecker` 被点 → `_hideConfigOverlay()`。
- **不设 ESC 关闭**（设计决定）。

### scrim 范围

scrim 只覆盖 `cover_widget`（`centralStackWidget`，即 canvas 区域 + 右侧翻译面板）。**左栏 leftBar、底栏 bottomBar、标题栏 titleBar 在 scrim 外部**，仍可点击。底栏 cfg 按钮点击后可直接切到对应分页，左栏 imgTrans 图标点击会使设置关闭再切换到翻译面板。

## 子对话框 backdrop 屏蔽

4 处 `dialog.exec()` 调用改为经 `_run_modal_dialog(dialog)`（`configpanel.py:2440`）：

```python
def _run_modal_dialog(self, dialog) -> int:
    if self._modal_ref is not None:
        self._modal_ref.set_backdrop_closable(False)
    result = dialog.exec()
    if self._modal_ref is not None:
        self._modal_ref.set_backdrop_closable(True)
    return result
```

## i18n 注意事项

1. 所有 UI 文字都用 `self.tr("English")`。
2. ts 中 `<context>` 对应类名。ConfigPanel context 包含 Models、Detect 等字符串。
3. 新增导航行 `label_models = self.tr("Models")` 与 PanelGroupBox 标题共用同一翻译字符串，ts 中无需新条目。
4. `_ShortcutRow`（`configpanel.py:842`）使用 `self.tr(_ACTION_NAMES[id])` 间接调用，i18n_check 始终报 orphan（假阳性）。
5. **QM 编码陷阱**：qm_compile 的 `_iso8859_str()` 须用 utf-8（已修复），否则 `—/→/✓` 被替成 `?` 导致 Qt 哈希查找失败。
6. 编译验证：
   ```bash
   python scripts/qm_compile.py translate/zh_CN.ts translate/zh_CN.qm
   python scripts/i18n_check.py          # 日常
   python scripts/i18n_check.py --ci     # 发版（对 orphan 退出码 4）
   ```

## 统一样式规则（2026-06-26）

以下规则适用于所有设置面板内的控件：

| 规则 | 实现方式 |
|------|---------|
| **按钮宽度** | `QPushButton#ConfigButton { max-width: 280px }`，所有设置页按钮均设此 objectName |
| **下拉栏滚轮屏蔽** | 所有 `ConfigComboBox` 指定 `scrollWidget=self`，未聚焦时滚轮转发至页面滚动 |
| **SpinBox 去箭头** | 所有 `QSpinBox` 设 `setButtonSymbols(QAbstractSpinBox.NoButtons)` |
| **统一容器** | 所有设置项包裹在 `ConfigSubBlock` 中，边距统一（24,6,24,6） |

## 已知瑕疵 / 待现场微调

1. **Panel 固定 1000×700**：字体委派网格等宽控件的布局在窄裁切窗口下可能溢出。已在代码中预留 `fit window` 判据（cover 小于 1000 则缩）。
2. **导航树层级**：Models 的 PanelGroupBox 顶边与导航树顶部无对齐约束，由左右独立布局控制。
3. **`_is_canvas_mode`**：读取 `panel.isVisible()` 抑制画布快捷键，行为不变（`mainwindow.py:803`）。
4. **备注系统暂无消费者**：`ConfigSubBlock.note` 和 `ConfigNotePopup` 基础设施已就绪，后续功能添加备注时直接传 `note="..."` 即可。
5. **管线页体量已改善**：拆出 Models 后管线页 4 个 group，滚动需求大幅降低。

## 测试流程（供后续 AI 参考）

### 离屏快速验证（弱模型友好版）

以下脚本模拟了软重建+面板切换+动画隐现等流程。复制为 `.py` 文件执行：

```python
import os
os.environ.setdefault('QT_QPA_PLATFORM', 'offscreen')
import time
from qtpy.QtWidgets import QApplication
from utils.config import load_config, pcfg

app = QApplication([])
# Monkey-patch 跳过平台窗口的额外初始化（frameless toggle 在 offscreen 会失败）
import ui.framelesswindow as fw
fw.FramelessMoveResize.toggleMaxState = staticmethod(lambda *a, **k: None)

from ui.mainwindow import MainWindow
w = MainWindow(app, load_config())
w.show()
w.resize(1400, 900)
app.processEvents()

pcfg.animation_fps = -1   # 跳过动画加快验证

# —— 测试模态显隐
w._showConfigOverlay()
app.processEvents()
assert w.configPanel.isVisible(), "SHOW: panel should be visible"
assert w._configModal._scrim is not None, "scrim should exist"
assert w._configModal._scrim._closable, "backdrop should be closable default"

w._hideConfigOverlay()
app.processEvents()
assert not w.configPanel.isVisible(), "HIDE: panel should not be visible"

# —— 测试 focusOn 路径（底栏 cfg 入口调用）
for fn in ('focusOnDetect', 'focusOnOCR', 'focusOnInpaint', 'focusOnTranslator'):
    getattr(w.configPanel, fn)()
    app.processEvents()
    idx = w.configPanel.pageStack.currentIndex()
    assert 1 <= idx <= 4, f"{fn} resulted in page {idx}, expected 1-4"

# —— 测试 backdrop 暂停（模拟子对话框屏蔽）
w._showConfigOverlay()
scrim = w._configModal._scrim
w._configModal.set_backdrop_closable(False)
assert not scrim._closable, "after suspend, _closable should be False"
w._configModal.set_backdrop_closable(True)
assert scrim._closable, "after resume, _closable should be True"

# —— 测试动画路径（非跳过）
pcfg.animation_fps = 60
w._showConfigOverlay()
app.processEvents()
time.sleep(0.6)
app.processEvents()
assert w._configModal._panel_effect.opacity() == 1.0, "anim show should set opacity 1.0"
w._hideConfigOverlay()
time.sleep(0.6)
app.processEvents()
assert not w.configPanel.isVisible(), "anim hide should close panel"

# —— 每页都是 QScrollArea（包裹 _wrap_page）
from qtpy.QtWidgets import QScrollArea
for i in range(w.configPanel.pageStack.count()):
    assert isinstance(w.configPanel.pageStack.widget(i), QScrollArea), \
        f"page {i} should be QScrollArea"

print("ALL CHECKS PASSED")
```

### 人工验收清单

1. **启动**：`python launch.py` 正常打开。
2. **打开/关闭设置**：点 LeftBar 设置图标 → **淡入**（无侧滑）；点遮罩空白区关闭、再点设置图标切换、再点 imgTrans 图标——均应淡出关闭。
3. **分页切换**：导航树点 Models / Pipeline / Project / Typesetting / Performance / Interface → 右侧各自换页，无滚动。
4. **底栏 cfg 入口**：点底栏 4 个 selector 的 cfg → 打开并直接跳到对应页（Mixin `to_*_config` 路径直达）。
5. **子对话框**：打开 Shortcuts / Exclude Fonts / Network Settings 等任一 → 点遮罩**不应**关闭设置；关掉子对话框后点遮罩应正常关。
6. **保存**：改任意设置 → 关闭面板 → 重启/查 `config.json` 确认落盘。
7. **动画开关**：Interface 区 Animation 切 Off → 开关设置无动画；切回 Auto → 淡入淡出恢复。
8. **快捷键抑制**：设置打开时画布快捷键（T/W/P/Tab 等）应被抑制（`_is_canvas_mode` 返回 False）。
9. **scrim 范围**：设置打开时点 LeftBar imgTrans 图标能响应（关闭设置）、点底栏 cfg 按钮能跳页——确认只压暗中央画布区，LeftBar/BottomBar 可点。
10. **i18n**：中英 UI 切换无明显回退。
