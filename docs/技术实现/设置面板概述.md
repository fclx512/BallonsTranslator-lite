## 分页结构

9 个页面，`QStackedWidget`（`ConfigPanel.pageStack`，`ui/configpanel.py::pageStack`）。页面内容包裹在 `QScrollArea` + `ConfigScrollBar` 中（`_wrap_page`，`ui/configpanel.py::_wrap_page`）。

导航使用 `ConfigTable`（树形控件，`ui/configpanel.py::ConfigTable`），不再使用上游的 `NavList`。

```
导航树（2 个 header，9 条目）             PageStack 索引
────────────────────────────────────────────────
Modules（header）
  Models                                      0
  Pipeline（4 个阶段标签）                     1
  LLM Profile                                 2
General（header）
  Project                                     3
  Typesetting                                 4
  Interface                                   5
  Shortcuts                                   6
  Quick Menus                                 7
  App（更新 + 外部编辑器 + 工作台 + 配置导入导出） 8
```

> 说明：2026-08-13 之后管线曾被拆成 4 个独立页面（Detect/OCR/Inpaint/Translator），新增 Shortcuts、Quick Menus、App 三个页面；原「Pipeline」「Performance」两页已不存在。2026-09-09 起 LLM Profile 页改为卡片式（`ui/llm_profile_cards.py::LLMProfileListWidget`），数据层留在 `utils/profile_manager.py`。2026-09-10 四个管线页**合并回一个 Pipeline 页**（页内 `QTabBar` + `QStackedWidget` 切标签），模块选择移出设置面板（改由底部栏选择，各标签只读显示当前引擎）。同日稍后，从管线页搬出的杂项（Photoshop 路径、工作台确认开关）并入 App 页（「应用级、配置一次后不常改」的归属地）；导航第一项由 `Module Actions` 改回 `Models`，与页内 `PanelGroupBox` 标题一致。

### App 页

App 页（`ConfigPanel.config_mgmt_block`，导航键 `config_mgmt`）收纳「应用级、配置一次后不常改」的项，按以下顺序分节：

- **Updates** → 启动时检查更新、更新状态、Developer channel 按钮及其常显的 `⚠` 风险行；
- **External Editor** → Photoshop 路径（`ConfigPanel.ps_path_edit` + `ConfigPanel.on_ps_path_changed` / `ConfigPanel.on_ps_browse`，写 `pcfg.drawpanel.photoshop_path`）。画布修复工具的「在 Photoshop 中编辑」用它启动外部程序；`ui/drawingpanel.py` 的「未找到 Photoshop」提示同步指向 `Settings → App → Photoshop Path`；
- **Workbench** → `ConfigPanel.confirm_costly_checker`，写 `pcfg.workbench_confirm_costly`。取消勾选等同于术语工作台弹窗里的「不再提示」；术语面板写入后会同向回写这个复选框，否则设置页会停在启动时的旧值（`ConfigPanel.setupConfig` 只在启动跑一次）；
- **Export Config / Import Config** → 配置文件的导出与导入。


### 合并的 Pipeline 页

`ConfigPanel._build_pipeline_page`（`ui/configpanel.py::_build_pipeline_page`）构建：外层一个裸 `QWidget`（`ConfigPanel.pipeline_page`）直接注册进 `pageStack`（不套外层滚动区，标签栏才不会被卷走），内含 `ConfigPanel.pipeline_tab_bar`（`QTabBar`）+ `ConfigPanel.pipeline_stack`（`QStackedWidget`）；每个标签内容是该阶段 `ModuleConfigParseWidget` 的 `_wrap_page` 滚动页。

- 四个阶段面板实例（`ConfigPanel.detect_config_panel` / `ocr_config_panel` / `inpaint_config_panel` / `trans_config_panel`）**对象与信号链原样保留**——底部栏、`ui/module_manager.py`、`ui/drawingpanel.py` 都持有它们的引用。
- 各标签顶栏是 `[模块名][引擎下拉][? 备注][…]`：引擎下拉即面板自带的 `module_combobox`，在这里切换会经 `ui/module_manager.py` 的 `set*` 槽真正换引擎并镜像回底部栏。
- 备注按钮由 `_build_pipeline_page` 锚定在 `module_combobox` 之后插入（不能用固定下标：各阶段面板会往同一行插自己的控件）。
- 画布修复工具面板（`ui/drawingpanel.py::InpaintPanel` / `ui/drawingpanel.py::RectPanel`）不共享真值源下拉，而是经 `ui/module_parse_widgets.py::create_mirror_selector` 各持一个镜像：show 时 `sync_items` 同步条目、`activated` 回流 `setCurrentText` 触发正常切换链。旧的「借走再搬回」reparent hack 已删。

### 页面创建机制

`ConfigPanel` 的构建分成两条路径：

- **`_add_page(content)`**（`ui/configpanel.py::_add_page`）：把裸 widget（如 Models 组、LLM Profile 页）直接注册为独立页面。
- **`_add_grouped_page(...)`**（`ui/configpanel.py::_add_grouped_page`）：构建 `PanelGroupBox` + `ConfigSubBlock`，把 `section_widget` 注册为页面（General 组的 Project/Typesetting/Interface/App 走这条路）。
- **`_DeadBlock.addGroupedBlock(...)`**（`ui/configpanel.py::_DeadBlock`）：General 组的 legacy 风格构建经它注册，内部路由到 `pageStack`。

`_wrap_page(content, margins=None) -> QScrollArea`（`ui/configpanel.py::_wrap_page`）将每个 section 包裹为带 `CONFIGBLOCK_CONTENT_MARGINS` 的滚动页面（`margins` 可覆盖，合并页的标签内容就用它去掉左右留白，避免与外层边距叠加）。内容 widget 的垂直策略设为 `Fixed` 防止短页面被拉满窗口。

页面注册顺序（决定 `pageStack` 索引）：

```text
0  models_group             _add_page
1  pipeline_page            pageStack.addWidget（裸注册，页内含标签栏 + 嵌套滚动区）
2  llm_profiles_panel       _add_page
3  project_block            addGroupedBlock
4  typesetting_block        addGroupedBlock
5  interface_block          addGroupedBlock
6  shortcuts_editor         _add_page
7  quick_menus_editor       _add_page
8  config_mgmt_block        addGroupedBlock
```

- **`ConfigFormRow`**（`ui/configpanel.py::ConfigFormRow`，继承 ConfigSubBlock）：2026-08-13 引入的**两列表单**容器（左列固定宽度右对齐 label + 右列控件 + 可选 `?` 帮助按钮）。布局约定详见 `docs/基础速查/设置面板排版思路.md`。

## 导航树分页连线

导航使用 `ConfigTable`（树形 `QTreeView` 子类，`ui/configpanel.py::ConfigTable`）：

- `configTable.section_pressed`（信号，`ui/configpanel.py::section_pressed`）→ `_on_nav_section_pressed(key)`（`ui/configpanel.py::_on_nav_section_pressed`）：读取 `_nav_section_to_widget[key]`（`ui/configpanel.py::_nav_section_to_widget`）取出对应 section_widget，通过 `pageStack` 的 section→index 映射切换。
- `focusOnDetect/OCR/Inpaint/Translator`（`ui/configpanel.py::focusOnDetect` 等）：都经 `_focus_pipeline_stage(stage)`（`ui/configpanel.py::_focus_pipeline_stage`）——先选中 Pipeline 导航项，再把页内标签切到对应阶段（下标见 `ui/configpanel.py::PIPELINE_STAGE_DETECT` 等四个类常量）。底部栏四个齿轮（`ui/mainwindowbars.py::BottomBar` 的 `cfg_clicked` → `ui/mainwindow.py::to_trans_config` 等）走的就是这条路。
- `focusOnLLMProfile(profile_id)`（`ui/configpanel.py::focusOnLLMProfile`）：切到 LLM Profile 页。
- Models 页默认选中。

`_nav_section_to_widget` 的 key：`models` / `pipeline` / `llm_profile` / `project` / `typesetting` / `interface` / `shortcuts` / `quick_menus` / `config_mgmt`。

## OverlayModal 机制

### 载体

`ui/overlay_modal.py` 的 `OverlayModal(QObject)`（`ui/overlay_modal.py::OverlayModal`）。它在 `cover_widget`（`centralStackWidget`）上方创建一个 `_Scrim(QWidget)`（`ui/overlay_modal.py::_Scrim`），面板（ConfigPanel）位于 scrim 之上居中。

### 核心参数

```python
_PANEL_W = 1000      # 面板固定宽（cover 小则缩）
_PANEL_H = 700       # 面板固定高
_SCRIM_ALPHA = 0.55  # 遮罩不透明度目标值
_DEFAULT_DURATION = 350  # 动画时长 ms
```

### 动画

scrim 和 panel 各有 `QGraphicsOpacityEffect`，用 QTimer 按 `_detect_interval()`（= `pcfg.animation_fps` 换算的帧间隔）驱动，`QEasingCurve.InOutExpo` 插值。

`pcfg.animation_fps < 0` 或 `duration ≤ 0` 时跳过动画。动画过程中收到反向操作会平滑反转（`_reverse`）。

### 关闭路径

- **scrim 点击**：`_Scrim.mousePressEvent` 检查 `_closable`，为 True 时调用 `OverlayModal.hide()`（通过 `on_click_outside` 回调）。子对话框打开期间 `_closable=False`。
- **配置图标再次点击**：`leftBar.configChecker` 互斥 → `setupConfigUI()` → 已在显示时 `_hideConfigOverlay()`。
- **imgTrans 互斥切换**：`leftBar.imgTransChecker` 被点 → `_hideConfigOverlay()`。
- **Esc 关闭**：ConfigPanel 内 `QShortcut(Qt.Key_Escape)` → `_close_via_esc`。
- **outside-click 自动隐藏**：ConfigPanel 通过全局 eventFilter（`_installOutsideClickFilter` / `_removeOutsideClickFilter`）拦截点击面板外的鼠标事件。

### scrim 范围

scrim 只覆盖 `cover_widget`（`centralStackWidget`，即 canvas 区域 + 右侧翻译面板）。**左栏 leftBar、底栏 bottomBar、标题栏 titleBar 在 scrim 外部**，仍可点击。

### MainWindow 接入点

| `from .overlay_modal import OverlayModal` | `ui/mainwindow.py` |
| OverlayModal 创建、`_modal_ref` 注入 | `ui/mainwindow.py`（`self.configPanel._modal_ref = self._configModal`） |

## 子对话框 backdrop 屏蔽

模态子对话框调用统一经 `_run_modal_dialog(dialog)`（`ui/configpanel.py::_run_modal_dialog`）：

```python
def _run_modal_dialog(self, dialog) -> int:
    if self._modal_ref is not None:
        self._modal_ref.set_backdrop_closable(False)
    result = dialog.exec()
    if self._modal_ref is not None:
        self._modal_ref.set_backdrop_closable(True)
    return result
```

涉及对话框：`on_exclude_fonts_clicked`（`ui/configpanel.py::on_exclude_fonts_clicked`）、`_open_network_settings`（`ui/configpanel.py::_open_network_settings`）。

注：`_open_shortcut_dialog` 已于 Shortcuts 页面化后删除；`_open_profile_manager` 已于 LLM 配置内联后删除。

## i18n 注意事项

1. 所有 UI 文字都用 `self.tr("English")`。
2. ts 中 `<context>` 对应类名。
3. `_ShortcutRow`（`ui/configpanel.py::_ShortcutRow`）使用 `self.tr(_ACTION_NAMES[id])` 间接调用，i18n_check 始终报 orphan（假阳性），需在 ts 对应 context 手工维护。
4. **QM 编码陷阱**：qm_compile 的 `_iso8859_str()` 须用 utf-8（已修复），否则 `—/→/✓` 被替成 `?` 导致 Qt 哈希查找失败。
5. 编译验证：
   ```bash
   python scripts/qm_compile.py translate/zh_CN.ts translate/zh_CN.qm
   python scripts/i18n_check.py          # 日常
   python scripts/i18n_check.py --ci     # 发版（对 orphan 退出码 4）
   ```

## 统一样式规则

以下规则适用于所有设置面板内的控件：

| 规则 | 实现方式 |
|------|---------|
| **按钮宽度** | `QPushButton#ConfigButton`，所有设置页按钮均设此 objectName |
| **下拉栏滚轮屏蔽** | 所有 `ConfigComboBox` 指定 `scrollWidget=self`，未聚焦时滚轮转发至页面滚动 |
| **SpinBox 去箭头** | 所有 `QSpinBox` 设 `setButtonSymbols(QAbstractSpinBox.NoButtons)` |
| **统一容器** | 表单行用 `ConfigFormRow`，模块选择页用 `ConfigSubBlock`，章节头用 `_section_header`（`ui/configpanel.py::_section_header`） |

## 已知瑕疵 / 待现场微调

1. **Panel 固定 1000×700**：字体委派网格等宽控件的布局在窄裁切窗口下可能溢出。已在代码中预留 `fit window` 判据（cover 小于 1000 则缩）。
2. **导航树层级**：Models 的 PanelGroupBox 顶边与导航树顶部无对齐约束，由左右独立布局控制。
3. **`_is_canvas_mode`**：读取 `panel.isVisible()` 抑制画布快捷键（`ui/mainwindow.py::_is_canvas_mode`）。

## LLM Profile 页（卡片式）

`ui/llm_profile_cards.py` 承接整页 UI，形态对齐上游 1.5.14 的 `ballontranslator/ui/llm_profile_widgets.py`（卡片列表 + 折叠详情 + 能力徽章分节），但**数据层仍是 fork 的 dict 模型**（name 作主键、`pcfg.module.model_profiles` 存 JSON 字符串），不引入上游的 `LLMProfile` dataclass / SecretStore / id 主键。

| 符号 | 职责 |
|------|------|
| `ui/llm_profile_cards.py::LLMProfileListWidget` | 整页：工具栏（`+ Add` / `Restore Built-ins`）+ 卡片列表；持有 `profiles_changed` 信号；`focus_profile(name)` 供跨页定位；`showEvent` 在外部改过 `pcfg.module.model_profiles` 时重载（画布 AI 修图的模型栏会写同一个 profile） |
| `ui/llm_profile_cards.py::LLMProfileCardWidget` | 单张卡：折叠态摘要（名字 + 能力徽章 + host + key 状态）+ 常驻模型下拉 + 展开态详情；删除按钮内置 profile 禁用 |
| `ui/llm_profile_cards.py::_ModelSelector` | 摘要行的模型选择器：`ConfigComboBox` 下拉 + `+` 手填 / `−` 删当前；清单字段由 `MODEL_OPTION_FIELDS` 映射；宽度按内容自适应（`AdjustToContents`，不拉伸撑满整行） |
| `ui/llm_profile_cards.py::LLMProfileDetailsWidget` | 连接信息块 + 通用参数 + 三个能力分节，每节一个 `ui/module_parse_widgets.py::ParamWidget`；分节显隐用 `set_section_visible` |
| `ui/llm_profile_cards.py::_ConnectionBlock` | 连接信息块：`api_host` / `api_key` / `image_base_url` 三个整行加高输入框（`CONNECTION_PARAM_KEYS` 定序）；图像端口随 `image_support` 显隐；改字段即写 `card.profile`（落盘仍走页面级时机） |
| `ui/llm_profile_cards.py::LLMProfileBadge` | 能力徽章：点击切换 `vision_support` / `image_support`；文本徽章恒亮不可点 |
| `ui/llm_profile_cards.py::PROFILE_COMMON_PARAM_DEFS` / `PROFILE_SECTION_PARAM_DEFS` | 声明式参数定义（镜像上游 `PROFILE_COMMON_PARAM_DEFS` / `PROFILE_MODALITY_PARAM_DEFS`）；`model` / `image_model` 由摘要行下拉负责，`api_host` / `api_key` / `image_base_url` 由 `_ConnectionBlock` 负责，都不在参数定义里 |

**模型清单**：profile 带 `model_options` / `image_model_options` 两份清单，**不预置供应商模型表**——只由 Fetch Models 多选（`utils/profile_manager.py::FilterableListDialog` 的 `multi_select=True`）或下拉旁的 `+` 手填产生；`utils/profile_manager.py::normalize_model_options` 在加载时保证当前值在列。切换 / 增删模型是离散操作，立即 `persist_requested` 落盘。

**保存时机（不能改）**：字段编辑只写内存，仅在 增删 / 恢复内置 / Fetch 成功 / 模型切换 / 离开页面（`hideEvent`）时经 `save_all_profiles` 落盘并发 `profiles_changed`。每次敲键就落盘会触发 `ui/module_manager.py::_on_profiles_changed` 重建 OCR / 翻译的 `ParamWidget`。

**ParamWidget 的约束**：它没有字段级刷新 API，且会原地改写传入的 params dict（因此 `LLMProfileDetailsWidget._add_params` 传副本）。

## 运行窗口（Run）

`ui/run_pipeline_dialog.py` 自 `ui/mainwindow.py::run_imgtrans` 抽出并重做（2026-09-10，形态对齐上游 `ballontranslator/ui/run_pipeline_dialog.py`）。`MainWindow` 只负责创建、接线与结果分支。

| 符号 | 职责 |
|------|------|
| `ui/run_pipeline_dialog.py::RunPipelineDialog` | 对话框本体：`QTabBar`（Pipeline / Render Only）+ `QStackedWidget`；信号 `stage_toggled` / `module_selected` / `translate_source_changed` / `translate_target_changed` |
| `ui/run_pipeline_dialog.py::PipelineModuleActivator` | 一个阶段 = 图标开关 + 模块下拉；点未启用的行也能重新启用 |
| `ui/run_pipeline_dialog.py::PipelineModuleButton` | 阶段图标开关：开启时按该阶段强调色着色 + 同色淡底，停用时用 `@disabledForegroundColor` |

**启用模块网格**：四个阶段按管线顺序排列（检测 / OCR / 修复 / 翻译），阶段强调色取 `config/themes.json` 的 `@accentDetect` / `@accentOCR` / `@accentInpaint` / `@accentTranslate`（与 LLM Profile 徽章同一套主题色，**没有**移植上游硬编码的 modality 调色板）。模块下拉写回底部栏选择器（`ui/module_tool_button.py::setSelectedValue` 传 `block_signals=False`）→ 走既有 `on_textdet_changed` / `on_ocr_changed` / `on_trans_changed` / `on_inpaint_changed` 链路，**底部栏是唯一真值源**，没有新增 ModuleManager 接口。

**折叠选项区**：每阶段一个 `ui/custom_widget/push_button.py::ExpandingToolButton` 折叠头 + 隐藏体，展开状态记在类属性 `RunPipelineDialog._sections_expanded`（进程内记忆）。选项直接读写 `pcfg`：

| 阶段 | 选项 | 配置字段 |
|------|------|---------|
| 检测 | Keep Existing Lines | `utils/config.py::keep_exist_textlines` |
| OCR | 无（占位说明） | — |
| 修复 | Skip simple cases | `utils/config.py::check_need_inpaint`（同时写入 `modules/inpaint/base.py::check_need_inpaint`） |
| 翻译 | Source / Target、单块翻译模式、LLM 上下文与术语表整块 | `translate_source` / `translate_target` / `single_blk_translate_mode` / `llm_*` |

**刻意不移植**：上游的无边框外壳与 `DialogCloseButton`（fork 保留原生标题栏）、每阶段 hover 齿轮（运行窗口是模态的，无法在其上再拉起设置浮层；底部栏四个齿轮已承担该入口）、`PipelineModuleActivator` 的停用「×」（与图标开关重复）。

**页码区间**：上游 `ballontranslator/ui/page_range_progress.py` 已复刻为 `ui/custom_widget/page_range_progress.py`（2026-09-17），运行窗口用它替换掉原来的 `RangeSlider` + 起止 `NoArrowsSpinBox` + All Pages——上游那套的满区间即全部页面，不需要「全部页面」复选框。

**启动期状态同步**：`InpainterBase.check_need_inpaint` 的初值由 `ui/module_manager.py` 在构造面板后直接从 `pcfg.module.check_need_inpaint` 推入（原先靠设置页复选框的 `checker_changed`）。翻译器异步加载完成后，`ui/mainwindow.py::finishSetTranslator` 会调用 `MainWindow._sync_run_dialog_translator` 刷新对话框里的语言下拉。
