## 0. 目标与边界

漫画里气泡被修复流程抹掉、或原文气泡太脏需要重画时，能**直接画一个新的**：

| 模式 | 说明 | 尺寸来源 |
|---|---|---|
| 跟随文本块 | 气泡挂在文字块上，充当该块的背景框 | 块自身 `unpadRect(boundingRect())`，随块缩放/改字号自动跟随 |
| 自定义区域 | 同一个气泡，但覆盖到框外的任意矩形（自由气泡） | 面板里的偏移 + 尺寸，相对块内容区左上角 |

v1 **不做**：曲线尾巴、多条尾巴、自定义多边形顶点、气泡样式库、按掩膜批量生成（见 §7）。

## 1. 统一模型（这是「减少理解成本」的核心）

**不要做两套东西。** 一套参数、一个几何函数、一个图元类，两处挂载：

```text
BubbleStyle  ──┬─→ bubble_path(rect, style) ──→ BubbleItem(QGraphicsPathItem)
               ├─ 宿主 A：页面级列表（自带 rect）
               └─ 宿主 B：TextBlkItem 的子项（rect 由块算）
```

`BubbleStyle` 字段（全部有默认值，非默认才落盘）：

| 字段 | 默认 | 说明 |
|---|---|---|
| `shape` | `'rect'` | `rect` / `ellipse`。**只有两项** |
| `corner` | `0` | 圆角半径（px）。**矩形 + 圆角>0 就是圆角矩形，不再单列一种形状** |
| `fill` | `'#ffffff'` | 填充色 |
| `alpha` | `255` | 0~255，UI 显示百分比 |
| `border` | `False` | 描边开关 |
| `border_width` | `4` | 描边宽（px），只往内画 |
| `border_color` | `'#000000'` | 描边色 |
| `tail` | `None` | `{angle, length, width}`；`None` = 无尾巴。默认 `angle=90`（正下）、`length=0.35`、`width=0.32` |

形状清单从「10 种」收敛到「2 种 + 圆角」，理由是形状下拉每多一项都是一次选择成本，而漫画气泡 95% 是椭圆或圆角矩形。

## 2. 几何规格

### 2.1 主体 + 尾巴是同一条路径

```text
path = body(rect, shape, corner)
if tail: path = path.united(tail_triangle(...))     # 布尔并，不是 addPath
描边 = stroker(path, width*2) ∩ path                 # 只留内侧一半
```

必须是 `united()`：`addPath` 会在尾巴根部留一条内部边线，描边环沿它画出来就是「气泡上多一道横线」。并集后根部消失，描边自然连续。

### 2.2 尾巴：单条直边三角（已实现，两处实装细节与原稿不同）

- 参数三个：`angle`（0=正右，顺时针，0~359）、`length`（外推量，占 `min(w,h)` 比例）、`width`（根部宽，同样占 `min(w,h)` 比例）
- 尖点 = 锚点沿 `angle` 外推 `length × min(w, h)`；越出页面时沿锚点→尖点回退
- **锚点不是「尾巴轴与边界的交点」那么简单**，要按形状分开处理：
  - 矩形：先按射线求与边的交点，再把沿边坐标钳进**直段**（`[left+corner, right-corner]`），嘴沿**边方向**展开。不钳的话斜向尾巴长在圆角弧上，嘴一半在体外，并集只剩细刺
  - 椭圆：没有直边，先在边界上二分出一段**内接弦**（目标宽度 = `width × min(w,h)`），再取两端。直接沿切线偏移的点都在椭圆外，收回去后尾巴会变成一根针
- 嘴两端一律向体内收 2px：与主体相切会退化成零面积并集，内收后 V 形干净
- 嘴贴到角上时**对称收窄**而不是单侧截断（否则尾巴看着是歪的）；窄于 3px 直接不画

实测结论（`scripts/probes/bubble_geometry_probe.py` 出图核对）：
- 默认 `width=0.32` 是配 `border_width≤8` 调出来的；**描边宽超过嘴宽一半时尾巴会被描边填满**（看起来是一根黑刺）。加粗描边就要同时加宽尾巴

### 2.3 描边环（沿用参考文档的成熟做法）

```python
if width * 2 >= min(rect.w, rect.h):   # 再描就翻出洞
    return outline
stroker.setWidth(width * 2); stroker.setJoinStyle(MiterJoin)
return stroker.createStroke(outline).intersected(outline)
```

参考文档坑 #5/#6 两条（描边溢出、圆角过大畸形）直接适用；圆角半径要钳到 `min(w,h)/2`。

### 2.4 渲染：矢量直画，不预渲染成 QImage

`BubbleItem` 就是 `QGraphicsPathItem`（`setPen` / `setBrush` / 开抗锯齿）。参考文档那套 `shape_fill_image()` 是为「一次性压进绘图层」设计的，只有批量生成时才需要；单图元不需要，也不会因缩放糊掉。

## 3. 两个宿主

### 3.1 自由气泡：块气泡的自定义区域模式（2026-11-04 合并）

原先这里是「页面级独立气泡」：另一套图层、另一个工具钮、另一个工程顶层键、另一个撤销栈。
**已整体删除**。理由是同一条需求被做成了两个入口，用户要学两遍，而两者的实质区别只有一个
「几何从哪来」——这点差异不值得一套并行系统：

| 原始问题（旧独立气泡实测） | 结果 |
|---|---|
| 拖动只改 `pos()`，`payloads()` 写 `rect()` | 画面动了但**不落盘**，切页/保存即弹回 |
| 改参数走 `rebuild()` 清空重建 | **选中态丢失**，第二次拖滑块只写进 `_pending_bubble_style` |
| 取消勾选 = 删除气泡，但 `bubble_to_payload(rect, None)` 抛 AttributeError | **删不掉** |
| 面板首次打开「先 sync 后建 dock」 | 打开时停在空态 |
| 退出绘图页后 `set_interactive` 没跟着关 | 气泡**抢走文字块的点击** |
| 数据跨页（`page_bubbles`）但撤销走页级绘制栈 | 切页回来 Ctrl+Z 撤不掉 |

现在统一成：**气泡永远是文字块的一个属性**，几何有两种来源。

- **跟随文本块**（缺省）：`unpadRect(boundingRect())`，随块缩放/改字号自动跟随
- **自定义区域**：载荷里多一个 `"region": [dx, dy, w, h]`（相对块内容区左上角的偏移 + 尺寸，页面像素）
- **数据**：仍只落 `TextBlock.bubble`，`region` 是该 dict 里的一个键。**旧数据不需要迁移**——
  `ui/bubble.py::BubbleStyle.from_payload` 对未知键「宽进忽略」，纯样式载荷照原样解析成「跟随块」
- **撤销**：走文本命令栈（`ui/textedit_commands.py::SetBlockBubbleCommand`）。文本栈**跨页存活**，
  于是「切页回来还能撤销」自动成立，不需要另立机制
- **入口**：只有文本编辑区左缘窄栏那一个气泡图标，块气泡与自由气泡共用同一面板
  （`ui/block_bubble_panel.py::BlockBubblePanel` 的「区域」行）

区域相对块内容区、而不是页面绝对坐标：块移动/缩放时自定义气泡跟着走，不会漂到别的格子上。
`ui/textitem.py::TextBlkItem` 的 `_sync_bubble_geometry` 是唯一的几何换算点。

### 3.2 块气泡（挂在文字块上）

- **字段**：`TextBlock.bubble: dict | None`（只有非默认值才写入工程）
- **挂载**：`BubbleItem` 作为 `TextBlkItem` 的子项，`setAcceptedMouseButtons(NoButton)`。**不改 `TextBlkItem.paint()`**——子项自动随块移动/缩放/旋转，且不干扰现有 `_paint_native` 的裁剪与效果合成顺序
- **⚠ z 序必须用 `ItemStacksBehindParent`，`setZValue(-1)` 无效**（2026-11-04 离屏实测）：Qt 的**子项永远画在父项之上**，`zValue` 只管兄弟之间排序。不加这个 flag 的话，白底气泡会整块盖住译文，而且不报任何错——只有目视或像素比对能发现。现已由 `tests/test_block_bubble.py` 的 `test_text_visible_above_full_rect_bubble` 双向钉住（正面：气泡下文字像素数 == 无气泡基线；反面：去掉 flag 后立即掉到接近 0）
- **尺寸**：`unpadRect(self.boundingRect())`（与选中框、描边框同一口径，含 padding）。块拖动/缩放/字号变化后 `refresh_block_bubble()` 经 `visual_geometry_changed` 自动同步
- **撤销**：走**文本命令栈**（`push_text_command`），与块的其他属性一致——`ui/textedit_commands.py::SetBlockBubbleCommand` 存前后载荷快照，redo/undo 都只改 `blk.bubble` 再调同一个 `refresh_block_bubble()` 入口，保证撤销与用户操作走同一份代码
- **入口**：左缘窄栏第 5 个图标（`RailDockPanel`）→ `ui/block_bubble_panel.py::BlockBubblePanel`，开合记忆 `pcfg.bubble_dock_open`

### 3.3 上游兼容（已核实，不是推断）

- `utils/structures.py:28-38` 的 `nested_dataclass` **忽略未知 kwargs**，并把它们塞进 `deprecated_attributes`。因此上游打开含 `bubble` 的工程**不会崩**，下次保存即丢失——符合「载荷保留不崩、上游打开时丢失」的既定方针

## 4. 界面

**入口只有一个**：文本编辑区左缘窄栏的气泡图标（`ui/text_panel.py::FontFormatPanel` 的 `install_bubble_launcher`）。
绘图区不再有气泡工具钮（`ImageEditMode.BubbleTool` 已删）。

气泡面板控件清单（一屏放下，不分折叠区）：

| 行 | 控件 |
|---|---|
| 启用 | 复选框（取消 = 移除气泡） |
| 区域 | 下拉：跟随文本块 / 自定义；自定义时显示 X / Y / 宽 / 高 四个数值格 |
| 形状 | 分段钮：矩形 / 椭圆 |
| 圆角 | 滑块（仅矩形可用，`shape == 'ellipse'` 时整行禁用） |
| 填充 | 取色器 + 透明度滑块 |
| 描边 | 开关 + 宽 + 色（关闭时三件禁用，沿用 `ShapeFillPanel.sync_border_controls` 的写法） |
| 尾巴 | 开关 + 方向（角度盘/滑块）+ 长度 + 宽度（关闭时禁用） |

块气泡入口：文本块属性面板里加一组「气泡」开关 + 参数（与描边/阴影视觉并列），但数据**不进** `text_effects` 栈——那个栈的输出是**字形像素**，气泡是**块背景形状**，混进去会污染 `FontFormat` 与大样式（`utils/base_styles.py` 把 `text_effects` 当整体原子复制）。

## 5. 落盘与数据流

```text
面板改动：BlockBubblePanel.bubble_changed(BubbleSpec)
          → SetBlockBubbleCommand（存前后载荷快照）→ push_text_command
          → blk.bubble（含可选 region，保存时随 pages 落盘）
          → TextBlkItem.refresh_block_bubble() → 子项自绘
```

文本命令栈**跨页存活**（`ui/canvas.py::prepare_page_switch` 只清绘制栈），所以气泡的
撤销天然跨页——这正是当初砍掉独立气泡（页级绘制栈、切页即丢）的另一个理由。

关键语义（必须写进文档，否则以后会当 bug 查）：

| 产物 | 含气泡 |
|---|---|---|
| 结果图 `result/` | ✅（场景重绘） |
| 中间图 `inpainted/` | ❌ |
| `mask/` | ❌ |

原因：气泡是矢量数据，每次导出重画；`inpainted/` 只存像素修复结果。**任何读 `inpainted/` 的下游（批量纯色修复等）都看不到气泡**，这是设计意图，不是遗漏。
