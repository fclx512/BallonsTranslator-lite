> 状态：已实现并通过离线验证（2026-08-12，半环多面板重做版）。
> 面向读者：① 后续接手此功能的开发者；② 未来承担**视觉修缮**的多模态 AI。记录设计思路、数据模型、竖排视觉常量位置、交互定位/钳制、已知 Qt 坑、待修缮/扩展清单。环形样式仍见 `多菜单环形菜单_设计与交接.md`。

## 一、一句话现状

快捷菜单（原「环形菜单」设置页）的每个菜单有 **Ring / List 两种样式**：环形保持 Blender 式扇区；**竖排（List）= 半环多面板**——把环形竖着砍一半，在光标一侧（`direction` 可配，默认右侧）的 3 个扇区锚点位置（上斜 / 正侧 / 下斜）各放一个小型连续面板（标准右键菜单观感：行与行无间隙、整行悬停高亮、圆角面板）。每个面板最多 3 行（对齐环形扇区容量），空面板运行时不渲染。触发/状态机零改动（长按释放提交、短按 PIN、Esc/右键/点击外部取消）。

**用户拍板的设计哲学：面板内没有分隔线。分组靠"一个菜单 = 一个功能组"，想分割不同功能就拆成新菜单。** 面板本身只是空间分组（保留环形的方位记忆），不是功能分组。

> 历史：2026-08-12 上午曾实现过"单面板卡片列"（扁平 `items` 列表），同日经用户确认改为半环多面板（`panels` 模型），旧 `items` 配置由 normalize 按 3 个一组自动迁移。

## 三、设计思路（为什么这样做）

核心决策链（均经用户逐点确认）：

1. **竖排无分隔线**。一个菜单 = 一个功能组；想分割就拆新菜单。→ 命令池无伪条目、面板内无分隔 UI。
2. **半环多面板而非单列**（2026-08-12 用户拍板）："把扇形竖着砍一半，在预定位置上放简化版的右键菜单"。保留环形的方位/肌肉记忆，同时消除卡片堆叠的空间浪费。3 个锚点 = 8 扇区环的侧向半环（右侧：扇区 1/2/3，即 45°/90°/135°；左侧：7/6/5）。
3. **样式切换复用 `layout` 扩展位**，环形路径（渲染/命中/拖放）零改动，竖排是并行的第二套几何，靠 `PieMenu._is_list()` 分支。MainWindow 触发流与布局无关，一行不用改。
4. **数据模型 `panels`：3 组 × 每组 ≤3**。面板就是"侧向半环的扇区"，因此 ring→list 转换 = 按 `direction` 取侧向半环扇区（`slots_to_panels`），list→ring = 写回 8 扇区布局的对应扇区（`panels_to_slots`）。双向保命令（容量对称：3×3 = 半环 3 扇区 × 3）。
5. **命中必须落在面板行上**（无环形"整扇区热区"方向回退）。光标停在面板间隙/空面板（运行时）= 无悬停 = 松开即取消，天然防误触。
6. **竖排窗口几何**：3 个面板矩形（空面板也算 1 行高的幽灵矩形，保证编辑/运行时几何一致）取包围盒 + `LIST_MARGIN`，光标在窗口内的位置 `_list_cursor` 固定 → 窗口定位 = 全局光标 - `_list_cursor`，再按 `availableGeometry` 钳制。方向 left 时面板 x 镜像。

## 四、数据模型与转换

`pcfg.pie_menus[*]` 字段（`ui/pie_menu.py::normalize_pie_menu` 恒输出全部字段）：

```python
{
    "id": ..., "name": ..., "trigger": ...,
    "layout": "ring" | "list",      # 合法值校验，非法回退 "ring"
    "sectors": 8,                    # ring 用（恒归一化保留）
    "slots": [ [...], ... ],         # ring 用（恒归一化保留）
    "direction": "right" | "left",   # list 用，默认 right，非法回退 right
    "panels": [ [...], [...], [...] ],  # list 用：恒 3 组，每组 ≤ LIST_PANEL_MAX_ITEMS(3)
}
```

- **双表示并存**：`slots` 与 `panels` 都归一化保留，样式切换时按需重算对方，运行时只读当前 layout 对应的那份。
- **迁移**：旧配置只有扁平 `items` 时，normalize 按 3 个一组 chunk 成 panels（2026-08-12 上午版遗留）。`panels` 已存在则忽略 `items`。
- 转换函数（导出供编辑器与测试复用）：
  - `slots_to_panels(slots, direction)`：按扇区中心角 x 分量符号取侧向半环，顶→底排序（左侧需反转）；不足 3 组补空。4/6 扇区环同样适用（取到的侧向扇区更少）。
  - `panels_to_slots(panels, direction)`：恒写回 8 扇区布局（右：扇区 1/2/3；左：7/6/5）。
- **信号复用**：竖排复用环形的 `slot_selected` / `slot_remove_requested` / `command_dropped`，**sector 参数承载面板号**（0=上斜，1=正侧，2=下斜）。编辑器按当前 layout 解释存储键（`panels` / `slots`）。mime `x-pie-src = "{panel},{idx}"`，拖回命令池由 `CommandPalette.dropEvent` 解析为 `remove_requested(panel, idx)`。
- 默认菜单不动（`DEFAULT_PIE_MENUS` 全是 ring）；配置页实时保存模式不变。

## 五、代码结构与实现索引（接手必读）

| 文件 | 职责 |
|------|------|
| `ui/pie_menu.py` | 竖排几何/命中/绘制/拖放 + 定位钳制；`normalize_pie_menu` + 转换函数；新常量 |
| `ui/pie_menu_editor.py` | 属性行二段式（Row1 名称/触发键/冲突 pill，Row2 样式/扇区数/方向）；`_on_style_changed`/`_on_direction_changed`；预览区直挂（无内嵌滚动区） |
| `translate/zh_CN.ts` | `PieMenuEditor` context（样式/环形/竖排/方向/左/右/拖拽提示） |
| `scripts/pie_menu_test.py` | 竖排章节断言（panels 模型） |
| `scripts/_list_preview.py` / `_pie_editor_preview.py` / `_ring_editor_preview.py` | 离屏截图脚本 |

**竖排内部方法**（`PieMenu`）：

| 方法/字段 | 作用 |
|------|------|
| `_is_list()` | layout 分支开关 |
| `_relayout_list()` | 核心几何：统一面板宽（最宽 label + 2×`LIST_PAD_X`，`LIST_MIN_W`~`LIST_MAX_W` 钳制）→ 3 个锚点矩形 → 包围盒 + 偏移 → `_list_rects` / `_list_cursor` / `_list_w` / `_list_h` |
| `_list_row_rect(panel, row)` | 行矩形（命中与绘制共用，单一事实来源） |
| `_hit_test_list(pos)` | → `(panel, row)` 或 None；**空面板运行时不可命中** |
| `_list_drop_pos(pos)` | → `(panel, insert_row)` 或 (-1,-1)；空面板（幽灵框）是合法放置目标；行中线上下决定插前/插后 |
| `_slot_at(sector, idx)` | 布局感知：list 时读 `_list_panels`——因此 `_update_hover`/`_commit`/点击/拖拽与环形完全共用 |
| `_move_list_at(global_pos)` | 窗口 = 光标 - `_list_cursor`，再屏幕钳制 |
| `changeEvent` | `FontChange` 时重算几何（面板宽由 label 量出，字体变了必须重排） |
| `_paint_list` / `_paint_list_drop_line` | 面板（圆角 + 裁切行绘制）+ 编辑态幽灵虚框 + 选中虚线圈 + 插入线（满员红色） |
| `set_list_drop_target(panel, row, rejected)` | 编辑态插入线高亮 |

**编辑器 UI**：样式下拉恒显；**扇区数** 仅 ring 可见；**方向** 仅 list 可见。`_on_direction_changed` 只改方向并重刷预览（面板内容不动，几何自动镜像）。

## 六、视觉常量与配色位置（视觉修缮必读）

竖排常量在 `ui/pie_menu.py` 顶部（环形常量之后，独立成段注释）：

```python
LIST_PANELS = 3               # 锚点位数（上斜/正侧/下斜）
LIST_PANEL_MAX_ITEMS = 3      # 每面板行数上限（对齐 SECTOR_MAX_CARDS）
LIST_ANCHOR_DIST = 120.0      # 光标 → 面板锚点距离
LIST_PANEL_RADIUS = 6.0       # 面板圆角
LIST_ROW_H = 26.0             # 行高
LIST_PAD_X = 14.0             # 面板内左右 padding
LIST_PAD_Y = 4.0              # 面板内顶/底 padding
LIST_MIN_W = 120.0            # 面板宽下限
LIST_MAX_W = 240.0            # 面板宽上限（超出 elide 省略号）
LIST_MARGIN = 8.0             # 包围盒外透明边距
```

- **锚点几何**（direction=right，光标为原点）：上斜面板左下角在 `(d, -d)`、正侧面板左边中点在 `(D, 0)`、下斜面板左上角在 `(d, d)`，其中 `D = LIST_ANCHOR_DIST`、`d = D/√2`。left 时 x 镜像。三个面板**宽度统一**（按全菜单最宽 label），视觉上是错位的整体而非三个孤立块。
- 面板配色与环形卡片**同一套**：`_card_palette(dark)`（深 `QColor(55,58,70,200)` / 浅 `QColor(255,255,255,235)`，独立白/黑描边 α70/55，悬停 accent 填充 + 白字，禁用 `@textColor` α110）。改环形卡片样式会同步竖排——**有意为之**。
- 长 label 用 `elidedText` 右省略（2026-08-12 修复：此前超宽直接硬裁）。
- 竖排**无标题行**（面板太小放不下；用户按触发键即知是哪个菜单）。环形仍有标题。
- 编辑态独有：空面板幽灵虚框（`@textColor` α45 虚线）、选中行 accent 虚线圈、插入线（accent α220 2px，满员红 `QColor(220,60,60,200)`）。

**预览缩放**：`set_preview_scale` 按缩放重设 `setFixedSize`，painter scale 统一缩放逻辑坐标——与环形同机制。

## 七、已知 Qt 坑（改渲染/交互时必须知道）

1. 环形章节 §七 的全部坑依然适用（`QPen` 无 `setAlpha`、`QDrag` 在 `qtpy.QtGui`、离屏字体等）。
2. **离屏截图豆腐块**：`QT_QPA_PLATFORM=offscreen` 下 `drawText` 渲染不出字形，截图脚本必须用默认平台。
3. **`save_config` 偶发 WinError 5**：`os.replace` 被同步盘/杀毒占用时抛 `PermissionError`，重跑即可；测试前删掉残留的 `_pie_test_config.json(.tmp)`。
4. **竖排定位依赖 `QApplication.screenAt(global_pos)`**：多显示器钳制用光标所在屏；`screenAt` 返回 None 回退 `primaryScreen`。
5. **短按 PIN 判定依赖 `_press_timer`**：测试里先跑过长按用例（monkeypatch elapsed）后，短按用例需换新 `QElapsedTimer`。
6. **样式切换的数据方向**：`_on_style_changed` 只在 layout 真正变化时转换，避免 `_load_current_props` 的 `blockSignals` 回环。
7. **设置页预览不要套内嵌 QScrollArea**：预览是 `setFixedSize` 的 Fixed 控件，直挂布局即可（页面本身在 ConfigPanel 滚动区内）。2026-08-12 前的内嵌滚动区在纵向空间不足时会被压成一条缝（环形/竖排预览同时受害），且 `palette_hint` 单行长文本会把整页撑出横向滚动——已改 `setWordWrap(True)`。
8. **⚠️ 窗口尺寸必须随 layout 同步（2026-08-12 晚修复的真实 bug）**：`set_menu_config` 早期只在 list 分支 `setFixedSize`，环形分支不恢复尺寸。运行时 `PieMenu` 构造即按 `pcfg.pie_menus[0]` 定型——若首个菜单是竖排，窗口被缩成竖排大小，之后触发任何环形菜单时环形中心 (250,250) 落在小窗口外 → 渲染全透明，表现为"按触发键毫无反应"；编辑器里从竖排切环形同样只剩左上一条。修复：抽 `_sync_fixed_size()`，`set_menu_config` / `set_preview_scale` / `changeEvent` 三处统一调用。回归断言：`pie_menu_test.py` 的 "ring window restored after list" / "list window restored after ring"。

## 八、待修缮 / 扩展清单

**视觉/体验（可交给多模态 AI）：**

- 弹出动画（淡入 + 轻微位移动画，~80ms）——环形同样未做
- 面板 hover 过渡动画（环形待修缮项，共用配色会同步受益）
- 插入线的视觉细节（当前 2px 横线，可做渐变/箭头）
- 面板锚点可微调（`LIST_ANCHOR_DIST` 一个常量控制聚散）

**功能/架构扩展位（数据模型已留）：**

- `layout` 将来可加更多形态，每个形态 = normalize 合法值 + `_is_list` 式分支 + 一套几何/命中/绘制
- 每面板行数上限目前是 3（对齐环形扇区容量，保证双向转换无损）；要加行需先想清楚转换语义
- 更多锚点位（如正上/正下）= 改 `_relayout_list` 的锚点表 + `LIST_PANELS` + 转换函数映射
- 命令池继续扩：任何带 `run_fn` + `category` 的命令自动进池，环形/竖排通用

**已知开放行为：**

- 允许命令重复出现（与环形一致，不去重）
- ring→list 只取侧向半环扇区（上/下/对侧扇区的命令不会带进竖排）；list→ring 写回侧向扇区，其余扇区清空——符合"竖排=半环"的定义
- 空菜单（3 面板全空）运行时弹出只剩透明窗口，任何操作即取消；编辑器中显示 3 个幽灵框
