# 侧栏图标 + 悬浮面板草案（注解功能 UI 放置思路）

> 状态：**草案，待讨论**。2026-08-23 用户提出方向，本文为第一版整理，未实现。
> 背景：上游 v1.5.12 移植后右侧文本格式面板功能密度大增（注解/Ruby/连字/竖排等），
> 右栏定宽 348px（`rightComicTransStackPanel.setFixedWidth(360)`）已无横向余量；
> 折叠胶囊（`ui/custom_widget/view_panel.py::ViewWidget`）解决了纵向拥挤，但
> 低频功能的"发现性"与"展开后的操作空间"仍有矛盾。

## 1. 参考：Photoshop 的交互模型

PS 的右侧面板区左侧有一条窄图标栏（icon rail）：

- 每个图标对应一个功能板块（图层/颜色/历史记录/字符…），悬停显示名称；
- 点击图标在图标栏右侧展开对应面板（折叠态收起为纯图标栏，几乎不占空间）；
- 展开面板**可自由拉伸**（拖边缘调宽高），且支持拖出成独立浮动窗口、多面板停靠编组；
- 用户可完全自定义哪些板块进栏、什么展开状态——"极其自由"。

PS 敢这么做是因为它的面板区整体是自由停靠系统；我们为排版美观禁用了右栏拉伸，
主面板保持固定网格。**但"图标栏 + 展开面板"这一个局部交互不依赖整个停靠系统**，
可以单独借用，且展开面板做自由拉伸符合设计直觉（它本来就是浮层，不参与主网格）。

## 2. 提议的形态（最小版）

```
┌─┬──────────────────────────────┐   ┌─┬─────────────────┐
│█│  全局字体样式 (胶囊)          │   │█│ ← 主面板（不变） │
│█│  基本选项（字体/图标/量测）    │   │█│                 │
│█│  …主面板内容…                │   │█├─────────────────┴──────────┐
│█│                              │   │█│  ◉ 悬浮面板（自由拉伸）      │
│栏│                              │   │栏│  Ruby / 连字 / 着重号 …     │
│ │                              │   │ │                            │
└─┴──────────────────────────────┘   └─┴────────────────────────────┘
```

- **图标栏**：右栏内侧一条 ~32px 宽的垂直 `QToolButton` 列（checkable、互斥或
  独立开关均可讨论），常驻可见；无任何激活时仅占一列图标宽度。
- **悬浮面板**：点击图标弹出，锚定在图标栏右侧（或跟随上次位置），浮于画布之上；
  **允许自由拉伸**（`QSizeGrip` 或窗口 resize），这是与主面板定宽原则的唯一例外，
  理由：浮层不参与主网格排版，拉伸不会破坏对齐。
- **落位候选**（讨论项）：注解类整组迁入——Ruby/着重号/连字/旧式数字/縦中横；
  乃至变换、文本样式（阴影/渐变）等低频大块。图标栏即"功能板块目录"。

## 3. 与现状的关系

- 现行注解折叠胶囊（`pcfg.expand_annotation_panel` + Annotations ViewWidget）是
  图标栏方案落地后的**直接替代对象**——胶囊展开仍受 348px 宽度约束（连字只能 2×2、
  Ruby 编辑行偏挤），迁入浮层后宽度解放。
- `ViewWidget`/`ExpandLabel` 的折叠语义可复用为图标栏按钮的激活态记忆
  （`config_expand_name` 同款持久化思路）。
- 引擎侧休眠的上游面板（`ui/text_engine/formatting/panel.py`，见
  `docs/技术实现/上游v1.5.12移植_完成记录.md` 分歧表）可作为浮层内容的参考实现，
  但仍以 fork 自有控件为准。

## 4. 技术要点（预研结论，待验证）

- 浮层形态二选一：**无边框子窗口**（`Qt.Window` flag 的 QWidget，独立可拖动拉伸，
  需处理 z 序/失焦关闭/随主窗口移动）或 **overlay 内嵌浮层**（挂在主窗口内，
  位置锚定简单，但"自由拉伸"只能在主窗口范围内）。倾向前者，PS 语义更完整。
- 激活态与全局/选中态门控沿用 `_sync_annotation_controls` 逻辑（全局模式下禁用或隐藏）。
- 持久化：`pcfg` 增图标栏可见性与各面板的展开/几何记忆（pos/size）。
- 互斥 vs 叠开：PS 支持多面板同时展开停靠；首版建议**单开**（点击切换），降低复杂度。
