# 快捷菜单（环形 + 竖排）实现总结

> 本文是画布快捷菜单（原「环形菜单」，设置页导航条目 **General → Quick Menus**）的**归档总结**，
> 由 4 篇过程性交接文档（Blender 样式复刻方案、视觉修缮交接、多菜单设计交接、竖排样式设计交接）压缩而来。
> 功能已实现并提交。面向后续接手此功能 / 承担视觉修缮的开发者。
> 记录日期：2026-08-14。

---

## 一、一句话现状

画布快捷菜单是**多菜单可配置**的：默认 3 个菜单（Tab=编辑 / X=对齐 / C=管线），每个菜单绑定一个触发键、可配置样式。每个菜单有 **Ring / List 两种样式**：

- **Ring（环形）**：Blender 式透明扇区菜单。光标为中心，扇区数可调（4/6/8），每扇区最高 3 张卡片堆叠——左右扇区沿切线垂直堆叠；顶/底扇区若横排会互相遮挡宽卡片文本，改为屏幕纵向堆叠（2026-08-14），堆叠永不自重叠。长标签卡片撞到相邻扇区堆叠时，**hover 到的卡片置顶绘制**保证始终可读。中心圆环 + 扇区填充指示 hover 方向。
- **List（竖排）**：光标一侧（`direction` 可配，默认右侧）的 5 个锚点（上/上斜/正侧/下斜/下）各放一个小型连续面板（标准右键菜单观感），每面板最多 3 行。**Ring 与 List 是同一菜单的两套独立布局**，切换样式只换显示、绝不互转（2026-08-16）。

**设计哲学（用户拍板）：一个菜单 = 一个功能组，面板内没有分隔线**；想分割不同功能就拆成新菜单。面板只是空间分组（保留环形的方位记忆），不是功能分组。

交互状态机两种样式完全共用：长按释放提交、短按 PIN、Esc/右键/点击外部取消。命令池复用右键菜单的 `COMMAND_REGISTRY`（单一事实来源）。2026-08-14 起 undo/redo/翻页/缩放不再进池（自带 Ctrl+Z/Y、PgUp/PgDn、滚轮等通用快捷键，占菜单位不值，旧配置里已有的仍可触发），`fit_window` 保留；新增 `CAT_TOGGLE` 勾选式命令（`snap_alignment` 吸附对齐：`is_toggle` + `checked_fn`），菜单内渲染为复选框，命令池中独立成段、独立徽标色。

## 二、数据模型

`pcfg.pie_menus: List[dict]`（`utils/config.py`），默认值 `DEFAULT_PIE_MENUS`，归一化由 `ui/pie_menu.py::normalize_pie_menu` 恒输出全部字段：

```python
{
    "id": ..., "name": ..., "trigger": ...,      # trigger 为空串 = 不可用触发键
    "layout": "ring" | "list",                   # 非法值回退 "ring"
    "sectors": 8,                                 # ring 用（4/6/8）
    "slots": [ [...], ... ],                      # ring 用：恰好 sectors 个列表，每列表 ≤3 命令 id
    "direction": "right" | "left",                # list 用，非法回退 right
    "panels": [ [...], [...], [...] ],            # list 用：恒 5 组，每组 ≤ LIST_PANEL_MAX_ITEMS(3)
}
```

- **双表示独立并存（2026-08-16 起）**：`slots`（Ring）与 `panels`（List）是同一菜单的**两套独立布局**，各自单独编辑、单独保存；切换样式只换显示，**绝不互转/合并/覆盖**。早期版本做过环形↔竖排双向转换与「无损往返」，但竖排只有半边、无法表达左右两侧都有卡片的环形，转换必然出现复制/丢失，故废弃（2026-08-16 用户拍板独立）。
- **迁移**（`ProgramConfig.load` → `utils/config.py::migrate_legacy_pie`）：旧配置 `pie_sectors` 为默认值 → 整体换 3 菜单模板；用户自定义过 → 内容作为第一个「编辑」菜单（其 list 布局由旧环形右半侧播种，`normalize_pie_menu` 负责收尾） + 补 2 个默认菜单。
- 旧配置只有扁平 `items`（竖排早期版）→ normalize 按 3 个一组 chunk 成 panels。

## 三、代码结构与实现索引

| 文件 | 职责 |
|------|------|
| `ui/pie_menu.py` | 菜单本体：状态机 + 两套几何/命中/绘制/拖放 + `normalize_pie_menu` + 全部视觉常量 |
| `ui/pie_menu_editor.py` | 配置页编辑器：菜单 tab 管理 + 触发键/名称/样式/扇区数/方向 + 实时预览 + 分类命令池（勾选式开关独立成段）+ 拖放编排 |
| `ui/context_menu_config.py` | `CmdDef`（含 `category`）、`COMMAND_REGISTRY`、`run_cmd(mw, id)`/`cmd_enabled(mw, id)` |
| `ui/mainwindow.py` | `_pie_menu_for_event` 按键查表触发；`_pie_handle_*` 泛化（Tab 类/字母类规则） |
| `utils/config.py` | `pie_menus` + `DEFAULT_PIE_MENUS` + `migrate_legacy_pie` |
| `utils/shortcut_conflicts.py` | `find_conflict_keys(mapping)` 纯函数，快捷键面板与触发键校验共用 |
| `ui/canvas.py` | 公开 `fitToWindow()`（薄封装私有 `_fitToWindow`） |

**环形关键方法**（`PieMenu`）：`_card_center`（卡片中心）、`_hit_test`（优先卡片矩形，回退整扇区方向）、`sector_at`（仅角度）、`_stack_vertical`（顶/底扇区纵向堆叠判定）、`_drop_insert_index`（落点投影到堆叠轴得插入下标）。

**竖排关键方法**（`PieMenu`，`_is_list()` 分支开关）：

| 方法/字段 | 作用 |
|------|------|
| `_is_list()` | layout 分支开关 |
| `_relayout_list()` | 核心几何：统一面板宽 → 5 个锚点矩形（上/上斜/正侧/下斜/下）→ 包围盒 + 偏移 → `_list_rects`/`_list_cursor`/`_list_w`/`_list_h` |
| `_list_row_rect(panel, row)` | 行矩形（命中与绘制共用，单一事实来源） |
| `_hit_test_list(pos)` | → `(panel, row)` 或 None；**空面板运行时不可命中** |
| `_list_drop_pos(pos)` | → `(panel, insert_row)` 或 (-1,-1)；空面板（幽灵框）是合法放置目标 |
| `_slot_at(sector, idx)` | 布局感知：list 时读 `_list_panels`，使 hover/commit/点击/拖拽与环形共用 |
| `_move_list_at(global_pos)` | 窗口 = 光标 - `_list_cursor`，再屏幕钳制 |
| `_paint_list` / `_paint_list_drop_line` | 面板 + 编辑态幽灵虚框 + 选中虚线圈 + 插入线（满员红色） |
| `set_list_drop_target(panel, row, rejected)` | 编辑态插入线高亮 |

**编辑态信号**（`PieMenu` preview 模式对外）：`command_dropped(sector, idx, cmd_id, src_sector, src_idx)`、`slot_remove_requested(sector, idx)`、`slot_selected(sector, idx)`。竖排复用环形信号，**sector 参数承载面板号**（0=上，1=上斜，2=正侧，3=下斜，4=下）。mime：`application/x-pie-cmd`（命令 id）+ `application/x-pie-src`（"sector,idx" / "{panel},{idx}"）。


**配色**：两种样式共用 `_card_palette(dark)`（深 `QColor(55,58,70,200)` / 浅 `QColor(255,255,255,235)`，独立白/黑描边 α70/55，悬停 accent 填充 + 白字，禁用 `@textColor` α110）。强调色用主题变量 `@accentPrimary`，文本 `@textColor`。改环形卡片样式会同步竖排——**有意为之**。

**编辑态独有绘制**（仅 `preview=True` 且 `set_edit_mode(True)`）：虚线扇区引导（`_paint_edit_guides`）、拖放目标高亮（`_paint_drop_target`，满 3 红色）、选中环（`_paint_cards` 内虚线）、竖排空面板幽灵虚框 + 插入线。

**预览缩放**：`set_preview_scale` 按缩放重设 `setFixedSize`，painter scale 统一缩放逻辑坐标——两样式同机制。配置页环形用 0.72。

## 五、已知 Qt 坑（改渲染/交互时必须知道）

1. **`QPen` 没有 `setAlpha`**——透明度设在 `QColor` 上再传给 QPen（否则 paint 里抛异常导致 grab 硬崩、无回溯）。
2. **`QDrag` 在 Qt6 属 `qtpy.QtGui`**（不是 QtWidgets）。
3. **`QTabBar` 没有 `clear()`**——重建 tabs 需循环 `removeTab(0)`。
4. **`self.tr()` 返回 Python str**，无 `.arg()`；`%1` 占位符用 `.replace("%1", ...)`。
5. **PyQt6 `KeyboardModifier` 是 Flag 枚举，`int()` 不可用**——触发键匹配需 `getattr(mods, "value", mods)`。
6. **PyQt6 `QKeyEvent` 无 `globalPosition()`**——用 `QCursor.pos()`（既有约定）。
7. **离屏平台字体渲染异常**：`QT_QPA_PLATFORM=offscreen` 下 `drawText` 渲染不出字形（豆腐块），截图脚本必须用默认 windows 平台插件。
8. **i18n 隐式拼接盲区**：`self.tr("a" "b")` 跨行拼接检测不到（本项目规范禁用）。命令 label 与分类名全是 `tr(variable)` 间接调用 → i18n_check 恒报 orphan，需按惯例在 ts 对应 context 手动加 `<message>`（`PieMenuEditor`/`Canvas`/`ConfigPanel` context）。
9. **`save_config` 偶发 WinError 5**：`os.replace` 被同步盘/杀毒占用时抛 `PermissionError`，重跑即可。
10. **竖排定位依赖 `QApplication.screenAt(global_pos)`**：多显示器钳制用光标所在屏；返回 None 回退 `primaryScreen`。
11. **短按 PIN 判定依赖 `_press_timer`**：测试里先跑过长按用例（monkeypatch elapsed）后，短按用例需换新 `QElapsedTimer`。
12. **样式切换数据方向**：`_on_style_changed` 只在 layout 真正变化时切换显示（Ring/List 独立布局、不互转），避免 `_load_current_props` 的 `blockSignals` 回环。
13. **设置页预览不要套内嵌 QScrollArea**：预览是 `setFixedSize` 的 Fixed 控件，直挂布局即可（页面本身在 ConfigPanel 滚动区内），否则纵向空间不足时被压成一条缝。
14. **⚠️ 窗口尺寸必须随 layout 同步**：`set_menu_config` 早期只在 list 分支 `setFixedSize`，环形分支不恢复尺寸 → 首个菜单是竖排时环形中心 (250,250) 落在小窗口外 → 渲染全透明，表现为「按触发键毫无反应」。修复：抽 `_sync_fixed_size()`，`set_menu_config` / `set_preview_scale` / `changeEvent` 三处统一调用。
15. **`QTextEdit` 默认 `tabChangesFocus=False`**：源/译文输入框按 Tab 默认插制表符。已处理：纯文本输入控件内 Tab 被 app 级 filter 惰性吞掉；字母/组合键触发键完全放行（否则把 X 设成触发键后翻译框打不出 x）。

## 六、待修缮 / 扩展清单

**视觉/体验（可交给多模态 AI）：**

- 弹出动画（淡入 + 轻微位移动画，~80ms）——环形与竖排均未做
- 面板/卡片 hover 过渡动画
- 插入线视觉细节（当前 2px 横线，可做渐变/箭头）
- 高分屏 DPR 高清文本适配（未做，草案）
- 配置页预览区容器观感（目前居中裸预览，无面板底/投影）

**功能/架构扩展位（数据模型已留）：**

- `layout` 将来可加更多形态，每个形态 = normalize 合法值 + `_is_list` 式分支 + 一套几何/命中/绘制
- 嵌套子菜单（hover 扇区滑出子饼）——状态机需加一层
- 每面板行数上限 3（匹配 SECTOR_MAX_CARDS）；Ring/List 两布局独立，改行数上限只影响 List
- 命令池继续扩：任何带 `run_fn` + `category` 的命令自动进常规池；带 `is_toggle` + `checked_fn` 的进独立勾选式段落（菜单内渲染复选框）

**已知开放行为：**

- 允许命令重复出现（不去重）
- **Ring 与 List 完全独立（2026-08-16 起）**：切换样式只是换显示，不转换；左右两侧都有卡片的环形在竖排里不显示也不受影响，各自布局原样保留
- 空菜单（3 面板全空）运行时弹出只剩透明窗口，任何操作即取消；编辑器中显示 3 个幽灵框
- 菜单打开期间按**其它**菜单的触发键会取消当前菜单
- 删除全部菜单后 `pie_menus` 为空数组，运行时查表为空 = 饼菜单关闭（预期行为）
