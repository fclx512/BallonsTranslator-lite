# 效果栈移植与窄栏图标重绘_计划

> 状态：已完结归档（2026-09-08）——本篇为压缩存档，只留结论与指针；实施过程见 git 历史。

## 一、结论与决策

### 效果栈（上游 `text_effects` / `TextEffectStack`）

1. **整栈一个入口，不拆散**：效果栈是顺序敏感的堆栈（卡片排序影响渲染），拆成「主面板留常用 + 浮层放长尾」会破坏排序模型。
2. **落点＝右栏格式面板内的可折叠 Section**：`ui/text_panel.py` 挂载 `ui/text_engine/effects/panel.py::TextEffectPanel`（上游同款 `view_widget` 结构、默认收起）。
   - 放弃窄栏浮层方案的原因：窄栏浮层 + 340px 狭栏反复「放不下卡片」——卡内容宽度下限（Shadow 卡最小 382px）超过右栏内宽 348px，且浮层盖住画布、反复调布局无法收敛。选择器改可压缩后卡最小宽 382→352（`ui/text_engine/effects/cards.py::_set_effect_selector_width` 弃 `Long / Extrude` 样本），可被布局压进 348 不裁切；该函数另有 72px 下限，防止 Fill 类型选择器（Ignored 策略）与 stretch-1 色块同行时被压成 0 宽静默消失。
   - **已退役（防复活）**：窄栏「效果」入口 + 效果浮层 + `pcfg.effects_dock_open` 开合记忆；旧文本样式浮层（原 TextStyleGroup，已删文件登记于 `scripts/audit_registry.json` 的 deprecated 区）由 `TextEffectPanel` 承接。
3. **描边只走栈**：删除右栏常驻描边行（`ui/text_panel.py::FontFormatPanel` 的宽度框/取色器，行距类型下拉独立成行），`utils/config.py::ProgramConfig` 的 `stroke_width_presets` 与设置面板预设行一并退役；`ui/text_engine/effects/cards.py::StrokeEffectCard` 与 Add 菜单「描边」项恢复（`icons/text-effect-stroke.svg` 取消 deprecated 登记）。理由：常驻轮廓行与卡片双视图的分离方案实现起来别扭。
   - 留痕：同日早些时候曾拍板「独立描边效果卡退役」（卡删除 + Add 菜单项移除 + 卡图标 SVG 登记 deprecated），当日二批推翻为上条口径。
   - 旧字段写入不再凭空建描边卡（`utils/fontformat.py::FontFormat`）；Add→描边白名单补 `'stroke'`。
4. **卡片渐进披露**：每卡参数区底部 20px「高级」折叠行（`ui/text_engine/effects/cards.py::_AdvancedDisclosure`），低频项默认收起、**展开状态不记忆**（卡片每次重建回到收起），高级项含非默认值时点亮标记点（收起状态可见）。描边卡常显宽度/颜色，混合模式等低频项收进高级。效果区折叠栏关闭按钮退役（`ui/custom_widget/view_panel.py::ExpandLabel` 保留 `hide_button` 开关）。逐卡参数归属见 `docs/技术实现/效果卡渐进披露_验收清单_存档.md`。
5. **取色器＝fork 自研** `ui/custom_widget/color_picker.py::ColorPickerDialog`（PS 式 + 屏幕吸色管）：渐变停点色块与效果卡 solid 色块不再走 win 原生 QColorDialog；描边取色即视为手动覆盖（`stroke_color_custom`），避免改字色被自动反色冲掉。渐变卡（`TextFillEffectCard`）改为常显——`InlineLinearGradientEditor` 曾被 `_connect_gradient_editor` 的初始 `hide()` 永久隐藏，导致选色交互整体缺失。
6. **数值交互**：效果卡数值框改 Blender 式箱体拖拽（`ui/text_engine/effects/cards.py::EffectNumericControl`，标签退为纯描述）；无单位效果参数上限统一 1（`utils/text_effects.py::EFFECT_MAGNITUDE_LIMIT`）。
7. **格式条件接入**：所有特效视为**一个预合成**（AE pre-comp）——效果参数太多，不为条件编辑器提供细粒度效果编辑；条件/替换 UI 中效果只以整体条目出现、不展开细节，允许的操作仅限逐参数复制粘贴。`utils/base_styles.py` / `utils/style_query.py` 的 `text_effects` 感知按该口径落地。

### 移植范围

- 已落地：填充（含 `ui/text_engine/effects/gradient_editor.py::InlineLinearGradientEditor`）、描边、阴影、发光、镂空、整体不透明度、滤镜族五件套（bloom／高斯模糊／glitch／颗粒／噪点，`ui/text_engine/effects/filters/` + `FilterEffectCard` + `icons/text-effect-filter.svg`）。滤镜纯 cv2/numpy，不引入资产子系统。
- **长期搁置／取消（勿复活）**：
  - 图像纹理：看似「恢复裁剪」，实则 fork 缺整套项目资产持久层——`utils/raster_assets.py` 只有 `RasterAssetRef` 结构，`utils/proj_imgtrans.py` 无 `load/import_raster_asset`／`assets_dir`／哈希／解码缓存／GC，差值 ~500 行几乎就是该子系统；落 `<project>/assets/` + 哈希去重 + 孤儿 GC 与 fork 减法导向冲突。
  - AI 生成图：需 API 传输层，且用户判断用处不大、不稳定。
- Alpha 遮罩：第二批范围含它但未落地；重启时从 `utils/text_effects.py::TextEffectStack` 现状重新评估。
- 上游关键信号：上游把 `opacity`／`stroke_width`／`srgb` 标为 `_LEGACY_EFFECT_VIEW_NAMES`（`ballontranslator/utils/fontformat.py`）——这些参数在其数据模型中已并入效果栈，旧字段只是兼容视图。

### 窄栏图标重绘（阶段 A）

- 落盘图标：`icons/rail_annotation.svg`、`icons/rail_emphasis.svg`、`icons/rail_transform.svg`、`icons/rail_effects.svg`（第 5 个入口用图标）。`rail_effects` 定稿为层叠方片（AI 生成图暂缓，sparkle 的「AI 魔法」语义暂不需要；后续若移植 AI 生成图卡可再换）。
- 各图标构成与语义（几何数值见 SVG 本体）：`rail_annotation` ＝ 上方 3 个小圆点（ruby 记号）+ 下方粗圆角横条（正文行）；`rail_emphasis` ＝ 圆角方框（字身）+ 正下方实心圆点；`rail_transform` ＝ 旋转 12–15° 的圆角方框 + 右下对角箭头；`rail_effects` ＝ 前后错位圆角方片、前片中心挖圆孔（层叠＝效果堆栈）。
- 窄栏分组：选中级（注解、着重号）在上，块级（变换）在下，以间距分隔（`ui/panel_rail.py::add_launcher` 顺序控制，宽度不变）。角标机制照旧：当前块带任意非默认效果时点亮 `ui/panel_rail.py::set_dot`，浮层标题加 " •"。
- 弃字体字形的理由：语义模糊（`あ`／`●`／`⤢`／`◐` 靠猜）、系统字体回退不可控（粗细/基线/tofu）、`deco="dots"` 靠 `paintEvent` 手绘与字形排版耦合脆弱、与项目统一 SVG 集（`icons/fontfmt_*`、`icons/drawingtools_*`）割裂。

## 二、图标 SVG 规范（约束）

- **单色纯 fill**：只用 `fill="#96a4cd"`，**禁止 `stroke=`**——`ui/misc.py::set_icon_theme` 只对 `fill="…"` 字面量做主题替换，stroke 不跟着换色，深浅主题下必坏；需要「线条」的形状一律用填充路径勾勒。
- 无渐变、无多色、无内嵌 CSS／`<style>`。
- **24×24 Material 网格**：`viewBox="0 0 24 24"`（同 `icons/drawingtools_ai.svg`），坐标取整数或 .5；缩到 16–18px 仍清晰。
- **不加 `*_activate` 变体**：窄栏选中态保持现有视觉语言（accent 圆角底 + 白色图形）；全局 `*_activate` 的 accent 色图形在 accent 底上会消失。
- 渲染管线：`ui/panel_rail.py::RailLauncherButton` 的 `paintEvent` 从 `drawText` 改为经 `ui/icon_rendering.py::render_svg_pixmap` 渲染 SVG（已有 lru_cache + DPR 感知，直接复用）；`render_svg_pixmap` 增状态色覆盖参数（`override_fill`，渲染前替换 SVG 源串的 `fill` 字面量）：正常态＝主题前景色、选中态＝白色、禁用态＝前景色降 alpha。accent 选中底、hover 1px 描边、右上角 dot 角标的自绘逻辑保留不动。
- `deco="dots"` 参数取消，ruby 点直接画进 `rail_annotation.svg` 本体；删除后须同步清理 `ui/text_panel.py::install_annotation_launcher` 调用点。
- 验收口径：三套主题（浅/深/自定义）下 `set_icon_theme` 替换后颜色正确（重点验证「禁 stroke」约定未破）；正常/hover/选中/禁用四态正确；HiDPI 下无锯齿；18px 内形状可辨识；窄栏图标 + 分组间距在 28px 宽内视觉均衡。

## 三、约束与坑

### 数据层

- `utils/text_effects.py`（纯冻结 dataclass）与 `utils/raster_assets.py` 从上游逐字移植，import 路径零改动（`.logger` 同名存在）。
- `utils/fontformat.py::FontFormat` 接入：`text_effects` 哨兵字段 + `opacity`／`stroke_width`／`srgb` 三个 legacy 视图（`__getattribute__`／`__setattr__` 直读直写栈）+ `__post_init__` 迁移（无载荷时从旧字段合成栈）+ `to_serializable_dict` 双写兼容视图 + `merge` 感知。测试 `tests/test_text_effects_data.py` 7 例钉住。
- **显式 `text_effects` 载荷权威**（压制 legacy 字段）；无效载荷逐项告警降级。
- **偏差（原因）**：`utils/base_styles.py` 的 `text_effects` 感知（DIFF_FIELDS／量化）不能与 legacy 视图同期入列——会产生关联重复的 override 条目（opacity≠1 同时出 `opacity` 与 `text_effects` 两条），且变体面板当时无该字段编辑控件；与效果面板一起落。

### 渲染层

- 移植上游 `ballontranslator/ui/text_engine/effects/` 渲染部分（`renderer.py` 3427 行、`blend.py`、`paint.py` 裁纹理分支、`shadow.py`、`paint_numba.py` 纯 Python 回退）接入本地 `ui/text_engine/`（v1.5.12 tier 光栅架构之上）；**排序敏感的栈渲染顺序必须与上游一致**。
- **坑（转换脚本丢 import 行）**：一次性转换脚本（临时未入库，已清理）丢独立装饰器／import 行 → `paint_stroke` 引用未导入的 `EngineVerticalTextDocumentLayout`（本地对 `ui/text_engine/vertical_layout.py::VerticalTextDocumentLayout` 的别名）与 `LOGGER` 未导入 → **NameError 经 Qt 虚回调表现为 exit 127 fast-fail，faulthandler 抓不到**；修后须做全文件未定义名扫描清零。
- 宿主接入：`ui/text_engine/rendering/glyph.py` 增 `GLYPH_DILATED_STROKE_FORMAT_PROPERTY`／`GLYPH_FEEDBACK_ONLY_FORMAT_PROPERTY` 与膨胀描边、feedback-only 分支；`ui/text_engine/layout.py` 增 `paint_context_observer`；`ui/text_engine/geometry.py` 增 preview-surface 桩（完整移植顺延）与 `paint_deferred_cursor`；`ui/text_engine/item.py` 委托 `set_text_effects` 等并删除梯度旧路径；旧渲染器（v1.5.9 TextEffectRenderer 移植版）已删除并登记 deprecated。
- 惰性重绘语义：新 `finalize_neutral_cache` 与上游逐字一致、只标脏缓存不再同步 repaint——测试须在 patch 块内补一次渲染触发重建，断言用 `ui/text_engine/effects/renderer.py::_preview_effect_raster_state`（原 `_transformed_effect_state`）；见 `tests/test_text_transform_engine.py::test_zero_glyph_slant_restores_effects_inside_nonlinear_stack`。
- **坑（面板写入断链）**：症状＝描边／阴影／渐变设置全部无效（引擎层与测试层正常）。根因是 **fork 双格式惯例与新渲染器读栈来源错位**：`ui/text_panel.py::set_textblk_item` 经 `get_fontformat()` 重建 `C.active_format`，失焦／切换时回写 `self.textblk_item.fontformat`（渲染副本），与 `item.blk.fontformat`（模型／canonical）是两个对象；旧渲染器读渲染副本故有效，阶段 C 渲染器按上游语义读 canonical 的 `text_effects` → 面板写入不可见。
  - 修复（上游顺从）：`ui/text_engine/item.py::_commit_effect_fields`——对 canonical 栈做 FontFormat 深拷贝探针、经 legacy 视图写入目标字段后以 `ui/text_engine/effects/renderer.py::set_text_effects` 提交（同时写 model + render 两格式，自带 `_finish_effect_transition` 完整失效链：opacity 应用、描边对齐、padding、缓存策略、repaint、update）。
  - 接入面：`ui/text_engine/item.py` 七个 setter `setStrokeWidth`／`setStrokeColor`／`setShadow`／`setBGAttribute`／`setGradientAttribute`／`setGradientEnabled`／`setOpacity`（`setOpacity` 走上游模式——native 透明度由 `_apply_effective_opacity` 应用；`setBGAttribute`／`setGradientAttribute` 对非 legacy 名保留原通道），以及 `set_fontformat` bulk 路径：描边宽 + 色合并一次提交（色只随非零宽度进栈，无描边块保持无卡语义；0 宽卡是 neutral、`paint_item` 已短路、无伪影）。
  - 回归：`tests/test_textblkitem_effect.py::test_legacy_setters_reach_canonical_stack_after_panel_decoupling`。
- **坑（噪点／颗粒「无效果」）**：两者只改字形内部像素，在修复前的完成正面契约下被未滤镜原文字精确盖回（实测边缘像素 129／76 不可感知）；模糊／光晕有字形外晕故可见。修复＝`ui/text_engine/effects/renderer.py::_renders_completed_foreground` 把 enabled Filter 计入「拥有正面」；`tests/test_text_effects_filter.py::test_in_glyph_filters_replace_native_foreground` 钉住。上游同结构（用户核对），**反向移植须带上该修复**。
- **坑（快速预览幽灵小号文本）**：`ui/textitem.py::_draw_effects_pixmap` 的点绘制依赖 DPR，而渲染器在 `render_scale < 1.0` 时不设 DPR，0.5 档缓存被 1:1 画出；修法是补矩形拉伸绘制（兼防大表面降档同类问题）。
- **坑（Add 按钮无响应）**：Add 按钮漏 `setMenu()` → 点击无任何响应（加卡／撤销命令链路本身正常）。
- **i18n**：mixin 里 `self.tr('Fill'/'Solid'/'Gradient')` 运行时上下文是各卡类名，而提取器归到 `_EffectCardMixin` → 词条永不命中（Fill 漏翻实锤）；按项目惯例改 `QCoreApplication.translate('TextEffectPanel', …)` 显式上下文。

### 已撤回与顺延（留痕）

- 阶段 A–D／D-2 的 UI 实现曾于 2026-09-04 **整体撤回**（提交 116880e），仅保留方案文档与一处 VisitedLink 一行修复；原因：实机存在无法修复的问题。旧文本样式浮层与 `pcfg.textstyle_dock_open` 当时随撤回恢复，`utils/base_styles.py`／`utils/style_query.py` 的 `text_effects` 感知一并退回。批次②（2026-09-06）按下方实施记录重新落地；方案与调研内容（放置决策／图标规范／范围定稿）在重启时仍有效。
- 阶段 D 偏差：preview surface 完整保留（`surface_cache_key`／`_remap_key_is_current`）依赖上游 v1.5.13 渲染器的 final-surface cache 子系统（`cached_pixmap`／`cached_remap`，上游侧名字），**顺延至 v1.5.13 吸收批次**；现 stub 维持 preview 走渲染器侧缓存。
- D-2 面板重做（信号协议与 `ui/text_engine/effects/edit_session.py` 逻辑不动）：卡片头部瘦身、参数区对齐 `TransformParameterPanel` 规范（标签右对齐、22px 填充输入框、两列网格）、卡片包 `GroupFrame`（空栈隐藏）、混合模式保留上游变暗／变亮二级菜单、渐变编辑器砍停点「不透明度／位置」数值框（保留渐变条 + 时钟表盘 + 停点色块 + 角度/缩放行）、下游 QSS 全部改 fork 填充输入框风格（原上游下划线风）；首版直译上游布局在 340px 窄栏不适配，故重做。
