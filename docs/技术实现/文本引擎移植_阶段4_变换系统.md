# 文本引擎移植 · 阶段 4 进度（变换系统）

> 阶段范围：`docs/技术实现/文本引擎架构跟进.md` 路线图中的阶段 4（变换系统：
> 移植 `transforms/`（mapping + registry + bend/sine/grid）、`rendering/`
> （glyph 完整版 + glyph_slant + surface）、`editing/commands.py` 的
> `SetTextTransformCommand`）。
> 状态：进行中（节点 A 完成，B–F 待办）
> 上游参照：`git show v1.5.9:ui/text_engine/transforms/*`、
> `git show v1.5.9:ui/text_engine/rendering/{glyph,glyph_slant,surface}.py`、
> `git show v1.5.9:ui/text_engine/editing/commands.py`

## 问题 / 需求

本地控制器（`ui/text_engine/geometry.py`）自阶段 2 起就按上游
`CompiledTextTransform` / `CompiledTransformStage` / `TransformStageContext`
契约消费 `ui/text_engine/_stubs.py` 的桩实现。本阶段把桩替换为上游真实实现，
并补齐渲染层（glyph slant + surface warp）与命令层（SetTextTransformCommand），
使变换栈从"仅模型可存"推进到"真实编译 + 渲染 + 可撤销编辑"。

**中性态（空变换栈 + glyph_slant 0）= 零行为变更**。每个节点独立验收并记录本文档。

## 实施方案与路线图偏差（已与用户确认）

1. **grid_numba.py 不移植**：`grid.py` 自带 numba 懒加载探测，本地无
   `grid_numba.py` 时自动回退纯 NumPy Newton–Jacobi 逆解路径，接口与上游一致。
2. **glyph_slant 加縦中横守卫（本地特有）**：上游 glyph_slant 旋转判定不识别
   tatechuyoko；本地 `draw()` 用 `per_char_records[...]["tatechuyoko"]` 阻止旋转。
   为保证 `glyph_slant_angle != 0` 时縦中横行为一致，glyph_slant 两处旋转判定
   同步加守卫。中性态（angle=0 不 attach render_delegate）不受影响。
3. **`SetTextTransformCommand` 精简移植**：只移植该类到
   `ui/text_engine/editing/commands.py`，import 裁剪到本地依赖。
4. **ffmt no-op 激活形态**：`ffmt_change_text_transform` /
   `ffmt_change_glyph_slant_angle` 从 `pass` 改为真实快照式提交，
   **保持 `push_undostack=False`**（完整可撤销编辑路径由阶段 5 变换编辑器经
   `SetTextTransformCommand` 提供）。
5. **测试移植范围**：只移植不依赖阶段 5 UI 的用例。

- ⚠️ **dict payload 键为 `transform_type`**（非 `type`），且持久化 dict 必须
  canonical（`normalized()` 往返相等），否则 `coerce_text_transform` 抛错。
- `has_projective_mapping` 语义 = "surface_mapper is None 且 非仿射" —— 只有真投影

### 与 stub 语义的差异（已核对，非回归）

- **`geometry_key` 中性值**：stub 对 identity 返回 `None`；真实实现返回
  `('matrix', 1,0,0,0,1,0,0,0,1)`。该键只用作缓存比较键（`refresh_compiled_geometry`/
  布局 namespace），跨编译确定、跨版本不持久化 → 无兼容风险。
- **`requires_no_cache`/`requires_custom_resize`**：stub 只对投影/非线性为 True；
  真实实现为 `not is_identity`（**任何**非 identity，含纯仿射旋转/缩放）。中性态
  两者均为 False，零变更；affine 非中性态语义差异是阶段 4 的**预期**行为
  （`geometry.py:1142` `_apply_box` 按 `requires_custom_resize` 挂
  `ItemSendsGeometryChanges`，`sync_origin` 用其选 pivot）。
- **`needs_local_handle_frames`**：真实实现 = `surface_mapper is not None or
  has_projective_mapping`（stub 只查 projective）。中性态 False，一致。
- `compensated_native_transform_matrix` 真实版新增 pivot/系数有限性校验，identity
  输入直接短路返回，中性路径不变。

