## 改动要点（5 个文件）

### 1. `utils/fontformat.py`（176 → 855 行）— 核心移植

**新增 `TextTransform` 类族**（frozen dataclass，与上游一致）：

- `TextTransform` 抽象基类：`transform_type`（`field(init=False)`）、
  `is_nonlinear`（ClassVar）、`normalized()` / `is_neutral()` / `with_value()`。
- 四个变体 + `TEXT_TRANSFORM_TYPES` 注册表（`type → class`）：
  | 变体 | 字段 | 非线性 |
  |---|---|---|
  | `ProjectiveTextTransform` | hs/vs 缩放、水平/垂直 slant、绕 X/Y/Z 旋转、perspective | 否 |
  | `BendTextTransform` | `bend`（±1 有符号圆弧） | 是 |
  | `SineTextTransform` | x/y freq（整数 0–64）、phase、amplitude | 是 |
  | `GridTextTransform` | 归一化控制点 + division + 插值类型 | 是 |
- `TextTransformStack`：不可变有序元组；neutral 条目保留但运行时跳过；`has_nonlinear`。
- `TextTransformState`：stack + `glyph_slant_angle`（undo 快照单位）。
- `normalize_text_transform_value(v, min, max)`：有限性校验 + clamp + round(6)，
  模型/UI/undo/持久化共用（`TEXT_TRANSFORM_PRECISION = 6`）。
- 工厂/转换函数：`create_text_transform`、`coerce_text_transform`、
  `coerce_text_transform_stack`。
- 全部 `TEXT_TRANSFORM_*` 常量（各字段 min/max、插值类型元组）。

**`FontFormat` 新增字段**（放在 `punctuation_alignment` 之后、`deprecated_attributes` 之前）：

```python
# Direct in-memory owner; persistence stores an ordered list of payloads.
text_transform: Union[TextTransformStack, List] = field(default_factory=TextTransformStack)
glyph_slant_angle: float = 0.0
```

**容错加载**（`__post_init__` 新增，在 `deprecated_attributes = {}` 之前）：
- `text_transform` 为 list/tuple：逐条 `coerce_text_transform`，非法条目**逐个丢弃并告警**（`LOGGER.warning`），非全丢弃。
- 非 list/tuple（如旧值）：warning + 回退空栈。
- `glyph_slant_angle`：`normalize_text_transform_value` 失败回退 0.0。
- 依赖 `nested_dataclass` 的既有行为：`Union[TextTransformStack, List]` 注解不是
  单个 dataclass，不会被 `utils/structures.py` 自动 dict→dataclass 转换，因此由
  `__post_init__` 处理——**不要**把注解改成裸 `TextTransformStack` 期望自动转换。

**新增 `to_serializable_dict()`**：`vars(self).copy()` + 把 `text_transform` 换成
`[asdict(t) for t in self.text_transform]`（payload dict 列表，与上游 JSON 格式一致）。

**保留全部本地独有字段/行为**：`shadow_include_stroke`、`punctuation_alignment`
（弃用字段，兼容旧配置/样式预设）、`PunctuationPosition`/`PunctuationAlignment` 枚举、
`size_pt` 的 `max(px2pt(self.font_size), 1.0)` 守卫、`foreground_color`/`stroke_color` 的 clamp。

### 2. `utils/proj_imgtrans.py`（+1/-1）— 项目保存路径

`TextBlock` 分支不变（仍走 `to_dict()`）；`load_from_dict` 用 `TextBlock(**blk_dict)`

### 3. `utils/io_utils.py`（+2）— 样式预设保存路径

`json_dump_nested_obj._default` 在 `obj.__dict__` 兜底前加
`if hasattr(obj, "to_serializable_dict"): return obj.to_serializable_dict()`。
样式预设（`utils/config.py:485` 调用）中的变换字段以此序列化。

### 4. `utils/config.py`（+2）— 全局配置保存路径

`json_dump_program_config` 在 ModuleConfig 分支之后、`obj.__dict__` 之前加同样的
`to_serializable_dict` 钩子。config.json 含 `global_fontformat`，变换字段以此序列化。

### 5. `ui/fontformat_commands.py`（+32）— funcmaps 联动

`ui/funcmaps.py` 按 `FontFormat.params()` 自动拼接 `ffmt_change_<param>` 命令名，
新字段自动要求对应命令。补两个 no-op 桩：

- `ffmt_change_text_transform`（L355）
- `ffmt_change_glyph_slant_angle`（L372）

均用 `@font_formating(push_undostack=False, is_property=False)`——`is_property=False`
保证包装器**不把值写入 act_ffmt**（变换字段的编辑走阶段 4+ 的状态快照命令，
这里只占位防 funcmaps 回退到 `empty_func` 打警告）。阶段 4 移植变换编辑器后删除这两个桩。

## 设计决策记录

1. **持久化格式**：变换栈存「payload dict 有序列表」（`asdict(transform)`），
   与上游 v1.5.9 一致；`TextTransformStack` 仅在内存中持有。
2. **容错策略**：不引入上游 `TEXT_TRANSFORM_SCHEMA_VERSION` 迁移方案，
   沿用本地 AGENTS.md 容错策略（非法条目逐个丢弃 + 告警，部分保留非全丢弃）——
   与本地项目加载策略一致，也符合阶段 0 决策。
3. **序列化路径收敛**：三条序列化路径（项目 TextBlkEncoder / 样式预设 /
   config.json）统一通过 `to_serializable_dict()` 钩子，避免 `vars(obj)` 直接展开
   `TextTransformStack` 元组（会把 tuple 变成 list、且破坏 payload 语义）。
4. **`nested_dataclass` 不自动转换**：`Union[...]` 注解保持原样，
   由 `__post_init__` 显式容错（见改动 1 的注意点）。
