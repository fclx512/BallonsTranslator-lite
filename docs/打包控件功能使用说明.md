## §1 ConfigSubBlock 禁用自动变灰

`ConfigSubBlock`（`ui/configpanel.py`）已通过 `changeEvent` 实现了禁用状态自动样式化。

### 原理

```python
class ConfigSubBlock(Widget):
    _disabled_color = None  # 类级缓存，仅首次从主题加载

    def changeEvent(self, e):
        if e.type() == QEvent.Type.EnabledChange and self.name_label is not None:
            if self.isEnabled():
                self.name_label.setStyleSheet("")
            else:
                # 应用 @disabledForegroundColor（浅色 #9d9d9f / 深色 #5d6170）
                self.name_label.setStyleSheet(f"color: {self._disabled_color};")
        super().changeEvent(e)
```

### 使用方式

```python
# 禁用 — label 自动变灰，子控件 Qt 自带禁用渲染
some_sublock.setEnabled(False)

# 启用 — label 恢复
some_sublock.setEnabled(True)
```

无需额外写 stylesheet，`changeEvent` 自动处理。

### 适用范围

- `ConfigSubBlock` 的 `name_label`（即构造时传了 `name` 参数时创建的标签）
- 子控件（`QLineEdit` / `QComboBox` 等）的禁用外观由 Qt 默认渲染 + 下方 CSS 规则覆盖
- `?` 帮助按钮不受影响（不应用灰色样式）

## §2 ConfigContent 内控件禁用 CSS

`config/stylesheet.css` 中已添加以下规则，作用域限定在 `ConfigContent`（配置面板内容区），不会影响其他模块：

```css
ConfigContent QLineEdit:disabled {
    border-bottom: 1px solid @disabledForegroundColor;
    color: @disabledForegroundColor;
}

ConfigContent QComboBox:disabled {
    color: @disabledForegroundColor;
}
```

这些规则在 `setEnabled(False)` 时自动生效，无需额外操作。

## §3 数值/文本字段的 "—" 占位符模式

当禁用某个数值输入字段时（如 PNG 格式下的 Quality），用 "—" 代替数值以直观表明"不适用"。

### 实现模式

```python
def _set_field_visual_state(self, field_widget, enabled: bool, restore_value: str):
    """Toggle field with '—' placeholder when disabled."""
    field_widget.blockSignals(True)
    if enabled:
        field_widget.setText(restore_value)
    else:
        field_widget.setText("—")
    field_widget.blockSignals(False)
```

### 使用场景

- 当前用于 Quality（`PercentageLineEdit`）：PNG 格式下显示 "—"
- 适用于任何 `QLineEdit` 子类字段

### 注意事项

- 切换前必须 `blockSignals`，防止 textChanged 等信号触发持久化逻辑
- 启用时从配置恢复原始值，避免丢失用户设置

## §4 NoArrowsSpinBox / NoArrowsDoubleSpinBox（无箭头数字输入框）

隐藏上下箭头按钮、半透明圆角背景的 `QSpinBox`（`NoArrowsSpinBox`）和 `QDoubleSpinBox`（`NoArrowsDoubleSpinBox`），放置在 `ui/custom_widget/spinbox.py`。

样式通过模块级常量 `_SPIN_STYLE` 统一管理，两个类共用同一套 CSS（仅选择器不同）。

### 使用方式

```python
from .custom_widget import NoArrowsDoubleSpinBox, NoArrowsSpinBox

# 整数输入
spin = NoArrowsSpinBox()
spin.setRange(0, 100)
spin.setValue(50)
spin.setFixedWidth(70)

# 浮点输入
dspin = NoArrowsDoubleSpinBox()
dspin.setRange(0, 60)
dspin.setSingleStep(0.1)
dspin.setDecimals(2)
dspin.setValue(0.3)
```

样式在 `__init__` 中一次性设置，调用方只需设 range / value / fixedWidth 等标准属性。

### 样式内容

- 背景 `rgba(128,128,128,0.13)`，边框 `1px solid rgba(128,128,128,0.25)`，圆角 4px
- `up-button` / `down-button` 宽高均为 0
- 禁用态背景透明、边框淡化

### 替换来源

此前多处 QSS / `setButtonSymbols` 重复：

| 原位置 | 原样式变量 |
|--------|-----------|
| `ui/custom_widget/color_picker.py` | `_NO_BTN_STYLE` 常量 |
| `ui/mainwindow.py` | `no_btn_style` 局部变量 |
| `ui/configpanel.py` | 2 处 `QSpinBox()` + `setButtonSymbols(QAbstractSpinBox.NoButtons)` → 统一替换为 `NoArrowsSpinBox()` |

### QSpinBox → NoArrowsSpinBox 迁移范围

主题设置面板（`ConfigPanel`）中所有 `QSpinBox` 均替换为 `NoArrowsSpinBox`：

| 控件 | 所属页面 | 说明 |
|------|---------|------|
| `max_font_size_edit` | 排版 → 最大字号 | 数值范围 10–1000 |
| `orig_opacity_toggle_spin` | 界面 → 原图对照预设 | 数值范围 0–99 |

LLM 配置页面（`utils/profile_manager.py`）中的数字输入框已统一替换：

| 控件 | 所属类 | 替换为 | 说明 |
|------|--------|--------|------|
| `rpm_spin` | `ProfileManagerDialog` / `ProfileManagerWidget` | `NoArrowsSpinBox` | 请求数/分钟，范围 0–10000 |
| `delay_spin` | `ProfileManagerDialog` / `ProfileManagerWidget` | `NoArrowsDoubleSpinBox` | 延迟（秒），浮点数步进 0.1 |
| `ocr_maxtok_spin` | `ProfileManagerDialog` / `ProfileManagerWidget` | `NoArrowsSpinBox` | OCR 最大 token 数，范围 64–131072 |

**不影响** LLM 提示词等 `QPlainTextEdit` / `QTextEdit` 大文本字段——`NoArrowsSpinBox` 仅适用于数字输入框。

## §5 ColorSwatchBtn（色块按钮）

显示色块的 `QPushButton`，带 `setColor()` / `color()` 方法和 `colorChanged` 信号。放置在 `ui/custom_widget/color_button.py`。

### 使用方式

```python
from .custom_widget import ColorSwatchBtn

btn = ColorSwatchBtn(QColor(255, 0, 0))
btn.setFixedSize(24, 24)
btn.clicked.connect(lambda: pick_color(btn))
# btn.color() → QColor

# 以列表 [r,g,b] 设置
btn.setColor([100, 200, 50])
```

### 信号

- `colorChanged(QColor)` — 调用 `setColor()` 时发射

### 注意事项

- 按钮本身**不打开取色器**，仅负责色块样式。取色器逻辑由调用方在 `clicked` 信号中处理
- 用 `setFixedSize` 控制尺寸（常见值：`fontstyle_manager.py` 用 24×24，`shadow_gradient_dialog.py` 用 32×22）
- `color()` 返回 `QColor` 副本，修改副本不影响按钮状态

### 替换来源

此前三处行内样式重复：

| 原位置 | 原写法 |
|--------|--------|
| `ui/fontstyle_manager.py` | `_fg_btn` / `_stroke_color_btn` 各两处 `setStyleSheet(f"background-color: rgb(…); border: 1px solid #888; border-radius: 3px;")` |
| `ui/shadow_gradient_dialog.py` | `ColorButton._update_style()` 方法 |

## §7 get_theme_color(key)（主题色取值）

从当前已解析的主题中读取任意 `@variable` 颜色的 QColor 值。放置在 `ui/misc.py`。

统一了此前分散在 `model_check_dialog.py`、`dependency_dialog.py`、`module_manager.py`、`update_checker.py` 等文件中的硬编码状态色。

### 使用方式

```python
from ..misc import get_theme_color

# 取成功色（绿色），返回 QColor
success = get_theme_color(key="@successColor")
label.setStyleSheet(f"color: {success.name()};")

# 取警告色
warn = get_theme_color(key="@warningColor")
label.setStyleSheet(f"color: {warn.name()}; font-weight: bold;")

# 取危险色（带透明度背景）
danger = get_theme_color(key="@dangerColor")
label.setStyleSheet(
    f"color: {danger.name()}; "
    f"background: rgba({danger.red()},{danger.green()},{danger.blue()},20);"
)
```

### 可用 key

参考 `config/themes.json`，常用状态色：

| key | 用途 | light | dark |
|-----|------|-------|------|
| `@successColor` | 成功/已安装 | `#27ae60` | `#27ae60` |
| `@warningColor` | 警告 | `#f39c12` | `#f39c12` |
| `@dangerColor` | 危险/错误 | `#e74c3c` | `#FF605C` |
| `@accentPrimary` | 主色（默认） | `#1e93e5` | `#5dade2` |
| `@borderColor` | 边框色 | `#b3b6bf` | `#535671` |
| `@qwidgetForegroundColor` | 前景文字色 | `#5d5d5f` | `#8e99b1` |

### 注意事项

- 该函数读取 `pcfg.darkmode` 自动切换 dark/light 主题，无需手动判断
- **不在模块导入时调用**，应在控件构造时调用（此时配置已加载）
- 返回的是 `QColor`，用 `.name()` 转 `#rrggbb` 字符串，或用 `.red()/.green()/.blue()` 取分量
- 此前 hardcode 状态色的文件已全部迁移至此统一入口

## §8 新增打包控件的原则

1. 优先考虑能否在现有类中通过 `changeEvent` / CSS 等方式自动处理
2. 若无法自动，再考虑辅助方法或独立函数
3. 添加到本文档，说明使用方式和场景

## §9 ConfigCheckBox（配置面板复选框）

自动设置 `objectName='ConfigCheckBox'` 的 `QCheckBox`，使 `config/stylesheet.css` 中 `QCheckBox#ConfigCheckBox` 主题选择器自动生效。放置在 `ui/custom_widget/checkbox.py`。

### 使用方式

```python
from .custom_widget import ConfigCheckBox

# 无文本
cb = ConfigCheckBox()

# 带文本（构造时传入）
cb = ConfigCheckBox(self.tr("Some option"))

# 设置描述性字体
font = cb.font()
font.setPointSizeF(CONFIG_FONTSIZE_CONTENT * 0.8)
cb.setFont(font)
```

### 替换来源

此前所有 `QCheckBox()` + `setObjectName('ConfigCheckBox')` 的重复模式已统一替换为此类。

| 原位置 | 原写法 |
|--------|--------|
| `ui/configpanel.py` 中所有配置复选框 | `QCheckBox()` / `QCheckBox(text)` + `setObjectName('ConfigCheckBox')` |

### 样式定义

样式集中在 `config/stylesheet.css` 的 `QCheckBox#ConfigCheckBox` 选择器：

```css
QCheckBox#ConfigCheckBox::indicator {
    width: 13px;
    height: 13px;
    border: 1px solid @borderColor;
    border-radius: 4px;
    background-color: @inputBackgroundColor;
}
```

无需额外设置即可获得一致的复选框外观。

## §10 ConfigLineEdit / ConfigTextEdit（NoArrowsSpinBox 风格文本输入框）

与 `NoArrowsSpinBox` 保持视觉一致的文本输入控件，覆盖单行和多行场景。放置在 `ui/custom_widget/text_input.py`。

### ConfigLineEdit（单行）

```python
from .custom_widget import ConfigLineEdit

# 无文本
edit = ConfigLineEdit()

# 带文本（构造时传入）
edit = ConfigLineEdit("default value")

# 设置占位符
edit.setPlaceholderText(self.tr("Type here..."))

# 设置验证器（数字、文本等）
edit.setValidator(QIntValidator(0, 100))
```

替换 `QLineEdit()` 即可，所有现有方法兼容。

### ConfigTextEdit（多行，LLM 提示词等）

```python
from .custom_widget import ConfigTextEdit

edit = ConfigTextEdit()
edit.setPlaceholderText(self.tr("Translate to {to_lang}:\n{input_json}"))
edit.setMinimumHeight(80)
```

适用于 LLM 提示词模板、Few-Shot 示例等大文本区域。

### 样式内容

与 `NoArrowsSpinBox` 一致的半透明圆角设计：

- 背景 `rgba(128,128,128,0.13)`，边框 `1px solid rgba(128,128,128,0.25)`
- 圆角 4px
- Focus 态边框加亮至 `rgba(128,128,128,0.5)`
- 禁用态背景透明、边框淡化

### 替换来源

设置面板（`ConfigContent`）中所有 `QLineEdit` / `QTextEdit` / `QPlainTextEdit` 已统一替换：

| 文件 | 替换内容 | 数量 |
|------|---------|------|
| `ui/configpanel.py` | `PercentageLineEdit` 基类改为 `ConfigLineEdit` | 1 |
| `ui/configpanel.py` | `addLineEdit()` / `_make_preset_row()` / 对话框搜索框 | 4 |
| `utils/profile_manager.py` | LLM 配置表单所有 `QLineEdit` → `ConfigLineEdit` | 28 |
| `utils/profile_manager.py` | 提示词/OCR 等 `QTextEdit` → `ConfigTextEdit` | 12 |
| `ui/module_parse_widgets.py` | `ParamLineEditor` 基类改为 `ConfigLineEdit` | 1 |
| `ui/module_parse_widgets.py` | `ParamEditor` 基类改为 `ConfigTextEdit` | 1 |
| `ui/network_settings_dialog.py` | `_SourceRow.custom_field` + `NetworkSettingsDialog` 中 4 处 `QLineEdit` → `ConfigLineEdit` | 4 |

**不影响**：`QKeySequenceEdit`（快捷键编辑控件）、`QComboBox` 输入框（已有独立样式）。

### 注意事项

- 与 `ConfigContent` 下划线样式表不冲突——控件自身 `setStyleSheet` 优先级更高
	- 大文本区域（`ConfigTextEdit`）在滚动时表现正常，已验证 LLM 提示词场景

## §11 ConfigComboBox / ParamComboBox（NoArrowsSpinBox 风格下拉框）

原有的 `ConfigComboBox` 和 `ParamComboBox` 现已自带 `NoArrowsSpinBox` 风格样式，放置在 `ui/custom_widget/combobox.py`。

### 使用方式

与之前完全一致，无需额外设置：

```python
from .custom_widget import ConfigComboBox, ParamComboBox

# 配置面板下拉框
combo = ConfigComboBox(scrollWidget=self)
combo.addItems(["Option A", "Option B"])
combo.setFixedWidth(300)

# 模块参数下拉框
param_combo = ParamComboBox(
    param_key="model",
    options=["gpt-4", "gpt-3.5"],
    scrollWidget=scrollWidget,
)
```

### 样式内容

与 `NoArrowsSpinBox` / `ConfigLineEdit` 一致的半透明圆角设计：

- 背景 `rgba(128,128,128,0.13)`，边框 `1px solid rgba(128,128,128,0.25)`
- 圆角 4px
- Focus 态边框加亮至 `rgba(128,128,128,0.5)`
- 禁用态背景透明、边框淡化

**保留**的全局 CSS 规则不受影响：`::drop-down`（无左边框）、`::down-arrow`（下拉箭头 SVG 图标）、`::hover`（主题色高亮边框）。

### 弹出列表样式

`QComboBox` 的弹出下拉列表（`QAbstractItemView`）现在也有了主题配套样式，定义在 `config/stylesheet.css` 中（因弹出窗口是独立顶层控件，必须写在全局样式表而非内联样式）：

```css
QComboBox QAbstractItemView {
    background-color: @widgetBackgroundColor;
    border: 1px solid @borderColor;
    border-radius: 4px;
    padding: 4px 0px;
    outline: none;
}

QComboBox QAbstractItemView::item {
    padding: 4px 8px;
    min-height: 24px;
    border-radius: 3px;
}

QComboBox QAbstractItemView::item:hover {
    background-color: @accentPrimary20;
}

QComboBox QAbstractItemView::item:selected {
    background-color: @accentPrimary;
    color: @inverseTextColor;
}
```

这样弹出列表会跟随亮/暗主题，选中项使用 accent 色高亮。

### 替换来源

| 文件 | 替换内容 | 说明 |
|------|---------|------|
| `ui/configpanel.py` | `combobox_with_label()` 已用 `ConfigComboBox` | 自动获得样式 |
| `ui/configpanel.py` | `punctuation_position_combo`：`QComboBox()` → `ConfigComboBox()` | 唯一遗留原始下拉框 |
| `ui/module_parse_widgets.py` | 全部下拉框已用 `ConfigComboBox` / `ParamComboBox` | 自动获得样式 |
| `utils/profile_manager.py` | `ProfileManagerDialog` / `ProfileManagerWidget` 中 7 处 `QComboBox` → `ConfigComboBox` | LLM 配置页面下拉框 |
| `utils/profile_manager.py` | `ProfileManagerDialog` / `ProfileManagerWidget` 中 2 处 `QCheckBox` → `ConfigCheckBox` | LLM 配置页面复选框 |
| `ui/network_settings_dialog.py` | 1 处 `QComboBox` → `ConfigComboBox` | 网络镜像配置下拉框 |

### 注意事项

- 内联 `setStyleSheet` 优先级高于 `ConfigContent QComboBox` 作用域规则，因此会覆盖下划线边框样式
- `SizeComboBox` / `SmallComboBox` / `SmallSizeComboBox` 不受影响，该组字体/尺寸选择器保持原有样式
- 弹出列表（`QAbstractItemView`）样式写在全局 `config/stylesheet.css` 中，对所有 `QComboBox` 生效
