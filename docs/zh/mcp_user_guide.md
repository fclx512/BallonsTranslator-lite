# MCP 功能使用指南（普通用户版）

## 这是什么？

MCP（Model Context Protocol）让 **Claude Code** 这类 AI 编程助手能够直接读取和修改你的 BallonsTranslator 项目文件。

简单说就是：**你口述需求，AI 自动操作项目**——不用手动点来点去。

### 它能做什么

- ✅ 打开项目，列出所有页面
- ✅ 读取页面上的文本块（原文、译文、字体样式）
- ✅ 批量修改字体、颜色、排版
- ✅ 搜索替换文字
- ✅ 保存修改到项目文件

### 它不能做什么

- ❌ 不能自动运行翻译/OCR/修复管线（那是 GUI 的工作）
- ❌ 不能显示图片预览

---

## 准备工作

### 1. 安装 MCP 依赖

打开终端（命令行），在项目目录下运行：

```bash
pip install "mcp>=1.0.0"
```

或者（效果一样）：

```bash
pip install -e ".[mcp]"
```

> 如果你用的是 conda/venv 虚拟环境，记得先激活环境。

### 2. 配置 Claude Code

在项目根目录创建 `.claude/settings.json` 文件，填入以下内容：

```json
{
  "mcpServers": {
    "ballonstranslator": {
      "command": "python",
      "args": ["-m", "mcp_server"],
      "env": {
        "PYTHONPATH": "D:\\ruanjian\\BallonsTranslator-lite"
      }
    }
  }
}
```

> ⚠️ 注意：`PYTHONPATH` 里的路径要改成 **你自己的项目目录**。如果项目放在 `C:\Users\你的用户名\BallonsTranslator-lite`，就改成那个路径。

## 快速上手

配置好之后，在项目目录下启动 Claude Code，就可以用自然语言指挥它操作项目了。

### 第一步：打开项目

```
"打开我的漫画项目，路径是 D:\manga\my_project"
```

Claude 会自动调用 `open_project` 工具。

### 第二步：浏览页面

```
"列出所有页面"
```

它会调用 `list_pages`，返回每页的名称、尺寸和文本块数量。

### 第三步：查看具体内容

```
"读取第 1 页的内容"
```

它会调用 `read_pages`，显示所有文本块的原文和译文。

### 第四步：修改

```
"把第 1 页所有文字块的字体改成 Noto Sans SC，字号 28"
```

它会调用 `set_font` 批量修改。

### 第五步：保存

```
"保存项目"
```

它会调用 `save_project`，修改写入磁盘。

> ⚠️ 每次修改后记得保存！否则改动会丢失。

```

```

```
"第 0 页到第 5 页的所有文本块，字体用 Noto Sans SC，粗体，白色文字黑色描边"

```

```
"当前项目的源语言和目标语言是什么？字体配置呢？"
```

## 注意事项

| 注意点 | 说明 |
|--------|------|
| **先保存再操作** | 在 GUI 中编辑后，先手动保存，再用 MCP 操作，避免冲突 |
| **操作完要保存** | 每次让 AI 改完后，说一声"保存"，否则改动在内存里 |
| **不要同时打开两个** | MCP 和 GUI 不要同时加载同一个项目，可能覆盖 |
| | |
| **块 ID 格式** | `{页码}:{块序号}`，如 `0:3` 表示第 1 页的第 4 个块 |
| **整页操作** | `0:*` 表示第 1 页全部块 |
| **多个块** | `0:0,0:1,1:2` 用逗号分隔 |
| **颜色格式** | RGB 数组字符串，如 `"[255,0,0]"` 表示红色 |

## 故障排除

### "MCP server 连接失败"

检查：
1. `mcp` 包是否已安装：`pip show mcp`
2. `.claude/settings.json` 里的 `PYTHONPATH` 路径是否正确
3. 是否在项目根目录下运行 Claude Code

### "没有项目打开"

你忘记叫 AI 打开项目了。先说 `"打开项目，路径是..."`。

### 保存冲突

如果在 GUI 里改了项目但没保存，MCP 操作的是旧数据。在 GUI 中记得 `Ctrl+S`。

## 进阶：自己写自动化脚本

如果你会用 Claude Code，也可以让它批量执行一系列操作：

```
"打开项目 X，读取第 1-3 页，把所有译文里的 '???' 替换成 '[待翻译]'，然后保存"
```

一次对话就能完成从读取到修改到保存的全流程。

## 和旧版 AI 面板的区别

| 对比项 | 旧版 AI 聊天面板（已移除） | 新版 MCP |
|--------|---------------------------|----------|
| 依赖 | 需要 GUI 运行 | 独立进程，无需 GUI |
| 交互方式 | 内嵌聊天框 | Claude Code 自然语言 |
| 能力 | 有限 | 更强，可组合工具 |
| 安装 | 内置 | 需额外装 `mcp` 包 + 配置文件 |
