# lite-v1.0.0 更新说明

> 本文档汇总 v0.6.0 → lite-v1.0.0 之间的全部改动，**供此前使用旧版本的用户查看**；GitHub 发版页只引用本文档，不另抄正文。

这是本分支改用新版本号格式（`lite-vX.Y.Z`，与上游的 `v1.x.x` 区分开）之后的第一个正式版，距上一个版本 v0.6.0（2026-08-16）约六周、共 139 次提交。

这一版主要做了三件事：让 AI 真正插手最费力的那部分工作（翻译改成带工具的 agent、左栏新增工作台、画布上可逐块让 AI 校对/重译）；把嵌字所需的样式能力补全（项目级大样式、效果栈、全局样式库、按样式条件的查找替换）；以及重做发行方式——从预装一切的大包改成约 30 MB 的引导小包，依赖在首次启动时自动安装。

下载后解压、双击 `launch.bat` 即可开始（首次会自动安装基本依赖并重启）；已有 0.6.0 的用户可直接在应用内升级。

## 主要亮点

1. **下载体积大幅变小**：发行包从预装式的大包改为约 30 MB 的引导小包（源码 + 嵌入式 Python + pip/uv），首次启动自动安装依赖（国内会自动配好镜像），装完本机环境约 600 MB；PatchMatch 的两个原生库（约 53 MB）改为用时后台下载。网盘的一键完整包继续作为离线兜底。
2. **LLM 翻译重写成「agent」**：模型现在能多轮调用只读工具（读任意页、按关键词搜全书、查术语表、取页信息）之后再提交译文，并可自动带上剧情梗概与术语；提交有校验、失败有降级，不再「静默直译」。
3. **左栏新增「工作台」**：把翻译前的准备（术语表、剧情梗概）与清理工作（可疑框、合并相邻框、简单背景修复、原文待校对、译文待重译）收在一处，每项都有 AI 起草、你看过并确认后才落盘。
4. **三个批量任务**：一键清理疑似误识别的框（只删文本框层，不碰你已修好的图）、合并相邻框（按组给审批截图、可反转组方向）、只对「简单背景」的框做纯色覆盖。执行前都会弹窗说明后果，且可整批撤回。
5. **逐块 AI 辅助**：给文字块打标签（稍后校对／稍后重译／手写字／拟声词），选中任意块即出现「校对原文」与「重译」两个现场按钮；AI 只出草稿，你确认才写回，写回与对应待办可一起撤销。
6. **区域再检测**：在画布上拉一个框，只在该框内重跑一次「检测 + OCR」。用来找回第一遍成片漏检的横排文字（实测横排漏检率约为竖排的三倍），一次拉框等于一步撤销，不会打乱你已调好的顺序。
7. **嵌字体系补全**：项目级「大样式」+ 自动派生子样式、跨项目的全局样式库、按样式条件的查找替换，以及可堆叠的文字效果栈（填充/渐变、描边、阴影、发光、镂空、不透明度、滤镜五件套）。
8. **撤销体系重做**：所有编辑走同一条全局撤销栈，跨页编辑保留历史，批量操作整批回退（项目内自动备份），图像修复也并入全局撤销栈，撤销/重做会提示操作名。

## 分组明细

### 翻译

- LLM 翻译改为多轮 agent：只读工具 + 唯一提交出口，本轮可以探索全书再决定译文；每页是独立任务，初始就自动带上本页、邻近已完成页与命中的术语，多数页面一轮即可完成。
- 提交后有统一校验：越界 ID 拒绝、缺块打回补译、空译文与「译文=原文」告警、术语原词残留检测，不静默放过。
- 端点不支持工具调用时自动降级为单次直译，并在界面说明；每次降级都会写入调试日志（可在设置里开启）。
- 新增「单框翻译策略」两档：直译 / 带当前页上下文（在运行窗口的翻译选项里切换）。
- 剧情梗概可由工作台生成并注入翻译上下文（开关在翻译设置区），让同一本书的译名与语气更连贯。
- 删除原「Context Translation (beta)」入口及其整项目分批行为——它正是「只选了几页却翻译了几百框」的来源，现由 agent 模式取代。
- 底部栏翻译器按钮新增「模型」子菜单，可快捷切换当前 LLM 配置里的模型（清单来自你抓取或手填的条目），切换后下一次翻译请求即生效。
- LLM 配置页改为卡片式：摘要行常驻模型下拉、可增删模型清单、视觉/图像能力徽章可点开关；卡片上有「使用」按钮指定全局生效的配置，翻译、OCR、在线修图、工作台都跟随它——配好 key 不会再被忽略。
- 「Fetch Models」升级为多选添加；不维护固化的内置模型表。

### OCR 与文字检测

- 默认文字检测器改为 ysgyolo（它刻意只认清晰的气泡文本）；同时关闭它的「other」标签，避免整只气泡被当成文本块而多出大量框、遮罩也会盖满页面。
- 新增日文漫画专精 OCR「PaddleOCR-VL-For-Manga」：质量优先、需要 NVIDIA 显卡，权重约 1.9 GB 在模型文件页按需下载；实测约 0.2 秒/块、加载约 4 秒。
- 区域再检测：底部栏打开开关后，左键拉框改道为「只在该区域跑检测 + OCR」，检出的新块按阅读顺序插回原来的位置，重叠的旧框会被替换；一次拉框＝一步撤销。
- OCR 跑完自动挂问题标签：低置信度，以及四类疑似误识别（空文本／纯数字／纯符号／无假名汉字），画布上以小徽标提示，供工作台集中审阅。
- CUDA 索引分档收进一处并重写 `install_cuda.bat`：GTX 10/16 系与 RTX 20/30/40 系用 `cu126`，数据中心卡用 `cu130`，RTX 50 系用 `cu132`；不再推荐会把 torch 悄悄降级的 `cu124`，也不推荐版本天天变的 nightly 通道。
- 上游 v1.5.12 / v1.5.13→v1.5.15 的底层修复与竖排引擎已合入（见下节）。

### 嵌字：样式、字体与排版

- 项目级「大样式」+ 自动派生的子样式：同一字体同方向的气泡自动归属一个大样式，参数差异归并成免命名的子样式；改大样式的某个参数会把它推平到全部成员（其他差异保留）；块改字体或横竖排时自动迁移到对应的大样式。
- 全局样式库：一套跨项目复用的样式模板，支持「收藏到库」与「复制到项目」双向拷贝（拷贝语义，各自演化）；库只是模板存储，不会自动套用到任何块。
- 样式管理器重做：左树按「全局样式库 / 本项目样式 / 未分组」分区显示，右栏有真实字体渲染的预览卡与按参数分组的折叠区，改动过的字段会高亮；未选中任何样式时不再挤出一排按钮。
- 子样式详情新增「更换字体」：把该子样式的文本框整体迁到目标大样式（或移回未分组），迁移前按实况重核成员、可一步撤销。
- 查找替换支持按样式条件：可以查找／替换「字号 ≥20 且描边为红」这类自由组合；替换前自动在项目内写一份备份，替换后可整批回滚（备份份数可在设置里调整，默认 1、最多 5）。
- 文字效果栈：填充（含线性渐变）、描边、阴影、发光、镂空、整体不透明度，以及五种滤镜（泛光／模糊／故障／颗粒／噪点），可堆叠排序；低频参数收在每张卡的「高级」里，展开状态不记忆。
- 取色器换成自带屏幕吸色的自研控件；描边颜色改为随文字颜色自动反色（可关）；修好了描边与阴影发虚的问题。
- 竖排引擎重写（移植上游 v1.5.12）：竖排文本、注音（Ruby）、縦中横、连字、旧式数字、着重号等入口集中在嵌字页左侧窄栏的浮层里；自动縦中横接入管线；标点靠边位置独立生效。
- 字体列表按家族名归并、PS 精确名对齐，排除名单不再失效，并提供「一键精简」只保留中文字体；字号输入框的上限跟随设置页的「最大字号」。
- 打字或粘贴时自动合并符号连字（`！！`→`‼`、`！？`→`⁉`），只在聚焦的编辑器里生效、替换处短时高亮，程序性写入与撤销重放不转换（开关在窄栏）。
- 「快捷符号」改为软键盘：聚焦文本框时贴框自动弹出、失焦即收，含假名/符号键区与罗马字转假名输入；插入纳入撤销链。
- 修好了「保存成图与项目里显示不一致」：右侧输入区与画布的文本改为全文差异对账，不再因失焦或位置漂移而永久分叉；同时收敛了溢出裁剪状态，成图不再出现「意外的文本框」。

### 画布与编辑交互

- 画布左键框选、拖拽移动文本块；快捷菜单点空白或失焦即关。
- 单块按住 Alt 拖手柄＝以框中心对称缩放（PS 式即时修饰键，按下的那一刻换算，来回按不累积误差）。
- 拖拽调值的数值框改为 Blender 式（在边框上按下才拖动补间，点进输入框正常编辑）。
- 新增统一的画布通知中心：无字图标识、缩放率、在线修复进度、空态提示都走同一套提示条与活动徽标，外观与行为一致。
- 撤销体系重做：单一全局撤销栈 + 快照命令制；跨页编辑保留历史（切页不再丢历史）；批量操作（查找替换与工作台批量任务）整批回退，与逐块编辑分开记账；图像修复也并入全局撤销栈；撤销/重做会提示操作名，并有 PS 式历史面板与可设的最大撤销步数。
- 文本输入区删掉 Edit/Review 模式切换，常驻左侧编号与拖拽列；多选格式化一次手势只算一步撤销。
- 行拖拽重构：抓取式拖动、实时让位、松手才落账；多选拖拽不再掉帧，也不会再误触发输入框悬停高亮。
- 快捷键系统重构为语义化动作 ID + 单源默认表；新增「运行后自动收缩文本框」等开关。

### 工作台与批量任务

- 左栏新增「工作台」，扁平六项，顺序即推荐流程：可疑框清理 → 合并相邻文本框 → 原文待校对 → 简单背景修复 → 翻译准备 → 译文待重译（不做跳步拦截）。
- **可疑框清理**：列出程序判定的误识别框，可逐个「标记/取消误报」，也可一键批量删除已确认的框——只删文本框层，不动遮罩与你已修复的图片；最容易误伤真实拉丁文本与拟声词的「无假名汉字」一类默认不勾选。
- **合并相邻文本框**：按几何聚组给出合并建议，可按组反转方向、按组查看审批截图（原始比例、可缩放平移）；误聚的大组默认不勾选并带警示标；合并会保留成员上的待办标签与翻译指示。
- **简单背景修复**：只对「简单背景」的框做纯色覆盖，复杂背景完全不动（不加载修复模型）；判据只看原图，避免把已手修过的复杂块误判为简单。注意先合并、再修的效果明显更好（逐行框命中约 8%，合并后约 51%）。
- **原文待校对 / 译文待重译**是两个「待办队列」，不是批量删除：分区显示你自己记下的待办与程序的低置信度建议，出口只有「跳画布」与「从列表移除／忽略」，移除只动这份记录、不改文本。
- 批量任务列表可重扫刷新；画布上改过内容后会提示「列表可能过时」；所有批量执行前一律弹窗告知后果。
- **翻译准备**（术语 + 剧情）：AI 起草术语候选，以及每页摘要与全局梗概；草稿里标明来源（base／AI／你），AI 不会覆盖你手改过的行，全部经「应用」才落盘，并标注了耗时操作的花费提醒。
- 工作台的审批预览改为独立浮层：默认 100% 原比例，滚轮以光标为锚点缩放、拖拽平移、双击适应窗口，点画布或 Esc 关闭，不再挤在工作台里。

### AI 辅助与标签

- 面向用户的标签只有四项：稍后校对、稍后重译（人工待办）与手写字、拟声词（持久指示）；低置信度与疑似误识别是程序挂的问题记录，不提供人工打标入口。
- 画布上以小型徽标显示块上的问题；E／Q 在「上一个／下一个活动待处理问题」之间跨页跳转，扫过去—跳过去—处理掉形成闭环。
- 老项目的旧标记（译文迷惑／译文润色等）只读兼容：不会重写你的项目文件，只在你取消那条待办时顺手清掉。
- 框级动作：单选任意块即出「校对原文」（把逐行摆正的拼图发给视觉模型）与「重译」两个现场按钮，不需要先挂标签；多选时不提供。
- 确认卡里能看到送给模型的同一张图（可放大）、逐行勾选取舍（行对不齐时退化为整块可编辑）、展开可见完整上下文包，还能填一句「补充要求」重跑。
- 点「应用」后，文字写回与对应待办出队是同一条撤销命令——Ctrl+Z 会把文字和那条待办一起复原，不会出现「文字退回去了、待办却永久丢了」。
- 手写字与拟声词会作为逐块翻译指令传给模型（结合上下文推断手写字语义 / 拟声词按发声直译），处理文本不会消除这两个指示。

### 设置与配置

- 设置面板改为卡片式导航（共 10 页），页内分节统一成卡片；四个管线页合并为一项「Pipeline」，页内用标签切换阶段，且只编辑当前引擎的参数。
- 运行窗口独立重做：上半是「启用模块」网格（阶段图标开关 + 模块下拉，写回底部栏），下半是各阶段折叠选项区，页码区与术语表状态指示保留。
- 模型文件管理（设置 → 模型 → 模型文件）：查看每个模块的落盘状态与占用体积，手动下载／取消／删除（走回收站）／打开目录；下载在后台进行，进度只进终端，不弹窗、不阻断操作，大模型不会在加载时同步下载冻住界面。
- 在没有可用加速设备的机器上，GPU-only 模型会被直接拒绝下载并说明原因，不会白下 1.9 GB（只拦下载，不妨碍你手工放入权重后使用）。
- 新增「释放内存」按钮：卸载模型并把内存交回系统，实测可从约 1.5 GB 降到约 110 MB；只在没有任务运行时可用，且不自动触发。
- 新增「工作台」设置页（合并误聚阈值等）；App 页的「导出配置」「导入配置」合并成一节。

### 发行、安装与更新

- 发行物＝引导小包（压缩后约 30 MB）：源码 + 嵌入式 Python + pip/uv，不预装依赖。首次双击 `launch.bat` 会自动安装基本依赖并重启，装完的本机环境约 600 MB；模型后端与权重之后在界面里按需下载。
- PatchMatch 的两个原生库（约 53 MB）不再随包，改为首次选中该修复器时后台自动下载（带哈希校验）；缺失时应用仍可正常启动，只在使用该修复器时提示。
- 发布 tag 改用 `lite-vX.Y.Z` 格式，与上游 `v1.x.x` 区分；应用内的「检查更新」会识别新格式并正确判断版本高低。
- 安装与启动更可靠：Python 3.10+ 闸门、损坏配置自动隔离与备份恢复、崩溃写入 `logs` 日志、首次启动按所在地区自动配置 pip 镜像、重启循环守卫、装完依赖自动重启收尾。
- 依赖与上游解除唯一的版本钉子，补装改为「只增不升」（缺的照装，任何会升级既有包的解析直接失败并留快照交人工决定），可与上游共用同一个依赖库。
- 增加 macOS 源码运行的平台适配（MPS 加速、平台相关路径），但未在 Mac 上做过验证，也没有对应的一键包。

### 性能与稳定性

- 行拖拽逐帧绘制优化（拖拽期间缓存卡片位图），多选拖拽不再明显掉帧；抓住卡片时的放大改为轻微缩放。
- 工作台候选列表改为自绘行列表控件，卡片与表格两套观感统一、主题接入正确；批量备份只保存受影响矩形的像素前图，占用更小。
- 区域再检测默认走 CPU 并在每次手势后卸载检测器——此前一次拉框会让内存涨近 1 GB 且不回落。
- 图像修复区的工具模式不再泄漏到文本编辑页（在编辑页拖拽不会再画修复笔刷）。
- 修掉多起闪退：竖排描边在快速切图时的越界崩溃、效果块框选时闪出原生小窗与掉帧、样式管理器未选中态、批量写备份时不同宽度裁片拼接崩溃。

### 修复（用户可感知）

- 保存的成图与项目内显示不一致（改字后成图不生效、偶发「意外的文本框」）。
- 文字描边／阴影发虚；点脏页（斜体页）点击跳转错乱。
- 「只选了几页却翻译了几百框」——上下文翻译 beta 的整项目分批问题，beta 已删除，由 agent 模式取代。

## 安装与升级

- **新用户**：下载 `lite-v1.0.0` 的发行包，解压到任意目录（路径不要含中文以外的特殊字符亦可，但建议避免超长路径），双击 `launch.bat`。首次启动会自动安装依赖并重启一次，请保持网络畅通；也可从网盘下载含依赖与模型的一键完整包直接使用。
- **从 v0.6.0 升级**：在应用内「设置 → 应用 → 更新 → 检查更新」即可升级（会替换程序源码，`data/`、模型、配置与嵌入式环境不受影响）；无 git 的便携包可用 `launch.bat --update` 增量更新，也可直接下载新源码包覆盖原目录。
- **NVIDIA 显卡用户**：运行 `install_cuda.bat` 安装 CUDA 版 PyTorch 与 onnxruntime-gpu（脚本会自动匹配本机显卡对应的索引），装完照常用 `launch.bat` 启动即可。
- 老项目直接打开即可：标签体系对旧标记只读兼容，不会改写你的项目数据。
