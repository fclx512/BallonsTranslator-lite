# 字体样式局部覆盖技术总结

## 问题描述

文字框（`TextBlkItem`）底层基于 `QTextDocument`，天然支持逐字符字体样式，但字体格式面板和样式预设的"Apply"按钮始终**全框覆盖**，即使只选中了部分文字也会无视选区。

**目标**：选中整框时全框覆盖，只选中部分文字时仅覆盖选中部分。

---

## 改动概述

### 修改一：`setFontFamily` 使用 `_before_set_ffmt` / `_after_set_ffmt` 模式

**文件**: `ui/textitem.py`

原代码在 `setFontFamily` 中强制 `cursor.select(Document)`，导致 `set_selected` 参数形同虚设。修复后改用 `_before_set_ffmt(set_selected, restore_cursor)` 获取携带正确选区的 cursor：

| 场景 | `set_selected` | 光标行为 | 更新块级默认格式 |
|------|:---:|------|:---:|
| 全局模式 | False | 全文档 | ✅ |
| 局部模式，无选区 | True | 扩展为全文档 | ✅ |
| 局部模式，有选区 | True | 保持选区 | ❌ |

格式仅应用到全框时才更新 `self.fontformat.font_family`（块级默认值），局部覆盖时保留原默认值。

### 修改二：`set_fontformat` 新增 `respect_selection` 参数

**文件**: `ui/textitem.py`

```python
def set_fontformat(self, ffmat, set_char_format=False,
                    set_stroke_width=True, set_effect=True,
                    respect_selection=False):
```

- `respect_selection=False`（默认）：行为不变，全框覆盖
- `respect_selection=True`：字符级属性（字体、字号、粗斜体、颜色）仅作用于选区；块级属性（对齐、行距、描边、阴影）仍作用于全框

### 修改三：`ApplyFontformatCommand` 传递选区标志

**文件**: `ui/textedit_commands.py`

`redo()` 传入 `respect_selection=True`；`undo()` 不传（通过 `setHtml()` 全量恢复）。

---

## 涉及文件

| 文件 | 改动 |
|------|------|
| `ui/textitem.py` | `setFontFamily` 重构；`set_fontformat` 新增 `respect_selection` 参数 |
| `ui/textedit_commands.py` | `ApplyFontformatCommand.redo` 传递 `respect_selection=True` |

---

## 无需修改的路径

`setFontWeight`、`setFontItalic`、`setFontUnderline`、`setFontColor`、`setFontSize`、`setGradientEnabled` 已正确使用选区模式。块级属性（`setStrokeWidth`、`setAlignment`、`setLineSpacing`、`setOpacity` 等）不应受选区影响，跳过。
