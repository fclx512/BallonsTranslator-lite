改动明细

区域 改动 Qt 实现
委托网格 包入紧凑容器，加引导文字 QFrame + CSS border-radius + 背景色区分
下拉框宽度 缩小（选项仅 2 个） 从 SHORT 缩短至 ~140px
排版行为区 加"Text formatting"子标签 ConfigTextLabel 作为视觉分隔
Combo Box Presets 整块移除 移至 Interface 组
导航标签 保持 "Typesetting" 不变

优点

  • 委托网格被容器"框住"，视觉上像一个功能块而非散落控件
  • 预设区移除后 Typesetting 信息密度大幅降低
  • 子标签（"Default font format" / "Text formatting"）提供层次引导

缺点

  • 仍保留 8 个下拉框 — 但这是功能性需要，无法进一步削减
